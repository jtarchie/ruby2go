rugaroo

Ruby by day. Go by night.

rugaroo compiles typed Ruby into a single Go file and a static native binary. No interpreter, no runtime library, and the same output as ruby, byte for byte.

Why a werewolf?

🌕

It still runs on MRI

Your source stays plain Ruby with #: type comments. Every program rugaroo accepts runs under ruby unchanged, and the test suite checks they print the same thing.

💎

The core is written in Ruby

String, Array, Hash and friends come from a prelude that is itself Ruby, compiled into your program and pruned down to what it uses.

🐺

One static binary

No interpreter ships with it. A compiled program does no interpretation and runs about 3.6x faster than MRI across the benchmarks.

Real gems, too experimental

The sqlite3 gem's API, unmodified, over libsqlite3. rugaroo compiles the pure-Ruby sqlite3-fiddle in place of the C extension, so the binary still needs no cgo. Gem support works on the gems it is tested with; the core language and standard library are the stable part.

The full tour (blobs, prepared statements, transactions, Ruby-defined SQL functions) is example 122.

Install

go install github.com/jtarchie/rugaroo/cmd/rugaroo@latest
rugaroo run greet.rb

Needs Go 1.26 or newer. Ruby isn't needed to compile. Experimental: it handles a large subset of Ruby, not all of it.

A rougarou is a shape-shifter from Cajun folklore. This one turns Ruby into Go.
