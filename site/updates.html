What's new in rugaroo.

October 27, 2026

A Rails app, compiled to one Go binary experimental

Roundhouse turns a Rails app into plain Ruby with no Rails left in it, written for the Spinel compiler. rugaroo now compiles that output too. Roundhouse's Blog app (articles, nested comments, validations, partials and JSON views) becomes one native binary that serves HTTP, and it answers the same as when the same code runs on Ruby.

The handful of files that only work under Spinel (its HTTP server, its sqlite binding, two crypto helpers) are replaced by Ruby versions in the roundhouse-rugaroo gem. The rest of the app is compiled as roundhouse wrote it.

Try the Blog

You need Go and Ruby 4.0.

git clone https://github.com/jtarchie/rugaroo.git
cd rugaroo
go install ./cmd/rugaroo
bundle install --gemfile examples/135_roundhouse_blog/Gemfile
cd examples/135_roundhouse_blog

ruby main.rb                 # on Ruby
rugaroo run -gem blog/runtime main.rb   # compiled

Both print the same fifteen requests: listing, showing and editing articles, a failed create, a new article and comment, an update and two deletes. -gem blog/runtime tells rugaroo that directory is library code the app carries (roundhouse's runtime), compiled like an installed gem: only what the app reaches.

Your own app

The roundhouse-rugaroo README walks from rails new and a scaffold to a running binary.

Not yet

  • CSS and JavaScript assets aren't served, so pages are unstyled. Forms still work.
  • Live updates over Action Cable (WebSockets) aren't supported.
