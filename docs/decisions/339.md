# Decision 339

**Rule:** Camel-casing marks a digit after `_` as `_n` and escapes a first rune that fails case round-trip as `_<hex>_`; `__` names keep the old mapping.

**`a_1` and `a1`, `ı` and `i` no longer share a Go name** (#109; amends 3, 336; 2026-10-23). *See also decisions 3, 336.* Camel-casing drops `_`, and digits have no case, so `a_1` and `a1` (`utf_8`/`utf8`, `to_i_1`/`to_i1`) were both `A1`; `ı` (dotless i) and `ſ` (long s) upper-case to ASCII `I`, `S`. Fixes, each only for the shape that merged, so no other name changes (the one visible change in the generated-Go snapshot is the minitest-spec `it` methods, `test_0001_x`→`Test_n0001X`):
- **A digit that starts a word after `_` gets `_n` before it** in a user name (`a_1`→`A_n1`, `utf_8`→`Utf_n8`, `test_0001_x`→`Test_n0001X`; `a1` stays `A1`). `_` + lowercase is never camel-cased output (decision 3), so the marker cannot meet another name.
- **Names with two or more leading underscores keep their old mapping** (`__read_1`→`__Read1`, `__call1`→`__Call1`). The prelude's private helpers use both digit shapes (`__mkdir1`, `__msg2str`, `__flatten_nested3`, `__idx_2`, `__sleep_0`) and `prelude/go/*.go` and the compiler spell some by their Go name (`__Read1`, `__Sleep0`), so neither can take the marker. `__a_1` and `__a1` still merge, and the collision error still reports it; `__` is the prelude's private convention. The fuzz skips `__` names with digits.
- **A first rune that does not round-trip through case** (`ToLower(ToUpper(r)) != r`: `ı`, `ſ`, `ς`, `µ`) is written as `_<hex>_` (`ı`→`_131_`), the escape `goIdent` already uses for non-letters, which a letter never gets; the same for an upper-case first rune whose lower case is ASCII (`İ`, Kelvin `K`, under `Cap_`). Capitals mid-name (`foo_bar`/`fooBar`) still merge, as decision 3 says.
- `FuzzGoMethodName` no longer skips the two shapes (only `__` names with digits); `TestGoMethodNameNoMerge` pins the pairs and the prelude names that must not move; `ObjDigitNames` in `testdata/test/object_test.rb` defines `a_1`/`a1`, `ı`/`i`, `ſ`/`s` side by side and runs on MRI. `testdata/errors/objects.txtar`'s inherited-collision case now uses `foo_bar`/`fooBar`.
