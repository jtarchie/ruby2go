# Decision 370

**Rule:** `Errno::X.new(msg)` and `Errno::X.new(msg, location)` written in a program build MRI's message (the error's text first); `SystemCallError.new(msg, errno)` keeps that errno; `SignalException.new(signo, name)`, `FrozenError.new(msg, receiver:)` and `NoMethodError.new(msg, name, args)` take MRI's extra arguments.

**Eighth batch of #114: exception constructors** (2026-10-24). *See also decisions 12, 364, 365.*

- **Errno messages.** rugaroo's own raises build their messages whole (`No such file or directory @ rb_sysopen - path`), so `Exception#initialize` is unchanged. A call in a program (`genNew`'s `sysErrorArgs`, which `useGenNew` sends there for any SystemCallError subclass) wraps its message in `rbSysMessage`, which puts `rbStrerror(errno)` first: `Invalid argument - x`, `Invalid argument` with none, and with a location `Invalid argument @ location - x` (`rbSysLocMessage`). `rbStrerror` is Go's `syscall.Errno` text capitalized, which is C's strerror. Ponytail: `SystemCallError.new("x")` itself keeps "x" (MRI: "unknown error - x").
- **`SystemCallError.new(msg, errno)`** (`self.__new_2`) stores the errno (`@__errno`, which `errno` reads first) and the text for it. Ponytail: MRI answers an instance of the matching `Errno` class (`Errno::ENOPROTOOPT` for 42); this is a SystemCallError.
- **`SignalException.new(signo, name)`**: the name is the message, and a signal name with a second argument is MRI's ArgumentError (`self.__new_2`, `__set_message`). Decision 365 left it out because the setter gave every exception class a forwarder (+129 functions in example 116); function counts are not the limit, run-time speed is (the user, 2026-10-24).
- **`FrozenError.new(msg, receiver: obj)`** and `FrozenError#receiver` (ArgumentError "no receiver is available" without one); **`NoMethodError.new(msg, name, args)`** and `#args`.
- **Proof:** `control_test.rb` `ExceptionConstructorsTest`.
