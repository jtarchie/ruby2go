# Decision 258

**Brew downloads: Array#prepend, join(nil), pairs and to_str** (#100; 2026-10-14).
- `Array#unshift` takes `*objs` and `prepend` is its alias, as in
 MRI (Homebrew's `args.prepend("--time-cond", target.to_s)`).
- `Thread#join(nil)` waits as `join` does (`__join_1` takes
 `Float?`): Homebrew joins with `Utils::Timer.remaining(end_time)`,
 nil without a deadline, and every download raised "no implicit
 conversion of nil into Float".
- In gem code, a tuple (a Hash arm's `|pair|` on an untyped
 receiver) where a non-Array class is wanted is checked at run time
 (`rbAs` of its Array) instead of being a Go type error that stubs
 the whole method: CaskDependent#deps' `formula.map { |f|
 Dependency.new f }`, MacOSRequirement's `map { |s|
 MacOSVersion.from_symbol(s) }`.
- A value-typed class that defines `to_str` converts where a String
 is wanted (Homebrew's `class Pathname; alias to_str to_s; end`, so
 Mktemp#run's `Dir.chdir(@tmpdir)`); only to_int/to_ary/to_hash
 keep decision 179's core-value rule.
- A generic value into a union that has its type variable as a
 member (`U` into `Array | Hash | String | U`) is boxed, not checked
 by a package-level helper that cannot name `U`.
