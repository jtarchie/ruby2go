# Decision 375

**Rule:** `require "ffi"` loads a Ruby port of the ffi gem's API over Fiddle's purego path, and a literal `attach_function` is compiled into a typed module method.

*See also decision 426* (under `--cgo`, `:varargs` and more than 8 arguments compile).

**FFI over Fiddle** (#111; amends 326; 2026-10-25). The ffi gem is the other way Ruby calls C without a C extension, and more gems use it than Fiddle. It cannot be compiled as user code: `lib/ffi.rb` loads `ffi_c`, a C extension, and `attach_function` defines its method at run time (rugaroo has no eval). So `libs.go` maps `ffi` to `prelude/ffi.rb`, loaded only on a literal `require` (155), on `Fiddle::Function`, `Fiddle::Closure` and the helpers in `prelude/go/fiddle.go`. No new Go dependency, no Go change.
- **Compiled `attach_function`.** In a module that `extend FFI::Library`, a literal `attach_function :name, [types], ret` (also `:ruby_name, :c_name, [...], ret`) is read at compile time (`internal/compiler/ffi.go`, hooked beside Fiddle's `collectFiddleCall`) and a `def self.name(a0, ...)` is synthesized, typed by the return type: integers `Integer`, floats `Float`, `:bool` `bool`, `:string` `String?`, `:pointer` and `Struct.by_ref` `FFI::Pointer`, `:void` `nil`, an enum `untyped` (a Symbol or Integer). `typedef`, `callback` and `enum` names are tracked so later literals resolve. The call still runs at load to find the symbol. A non-literal type list, an unknown type, `:varargs`, `Struct.by_value` and more than 8 arguments are compile errors (`testdata/errors/ffi.txtar`).
- **Runtime.** `FFI::Library` (`ffi_lib`, `attach_function`, `typedef`, `callback`, `enum`, `enum_value`), `FFI::Pointer` (every `get_/put_/read_/write_` integer and float type and their `_array_of_` forms, strings, bytes, pointers, arithmetic, `NULL`), `MemoryPointer`, `FFI::Function` (a Ruby callable as a C function pointer), `FFI::Enum`, `FFI::Struct` and `FFI::Union` with a run-time `layout` (LP64 offsets and alignment, explicit offsets, inline arrays, nested structs, `by_ref`), `FFI::LastError` and `FFI.errno` (Fiddle's errno), `FFI::Platform`. A Proc passed where a `callback` type is declared becomes a closure, built once per Proc (a fresh Proc per call builds a fresh closure, and decision 326's cap of 2000 closures per process applies). `attach_function` also defines the gem's private instance method, so a class that extends `FFI::Library` can call it from its own methods; `typedef Struct.by_ref, :name` is a pointer typedef; `ffi_lib` maps names as the gem does (`"c"`, `"sqlite3"`, `libfoo.so.1`).
- **Same limits as 326:** no varargs, at most 8 integer and 8 float arguments, at most 2000 callbacks per process, no float-returning callback. Strings are copied into C memory (136).
- **Differs from the gem.** A `Struct#[]` is `untyped` (the field is looked up at run time; a literal-symbol fold to a typed accessor is the follow-up). An array field reads as a fresh `Array` and cannot be assigned through (`s[:a][0] = 1` writes the copy; the gem returns an InlineArray). `:string` struct fields are read-only. `MemoryPointer` is never freed unless `#free` is called (no finalizers); its block form frees after the block but `new` returns the pointer, not the block's value. An unsigned 64-bit read past 2**63 needs a Bignum, so it raises unless built with `--int-overflow=promote` (372). An enum-typed callback argument arrives as its Integer. A struct by value, `attach_variable`, `FFI::Type`, `FFI::Buffer`, `FFI::DataConverter` and `FFI::AutoPointer` are not provided. `Class.new { extend FFI::Library }` is not supported; use a named module.
- **Proof:** example 127 (`examples/127_ffi`: libc `strlen`/`pow`, a `qsort` callback, `gettimeofday` into a `struct timeval`, a `typedef`), `testdata/test/ffi_test.rb` (14 tests against the real gem: enums, pointers, scalars and strings, `memcpy`, struct and union layout, nested structs, callbacks, errno, missing library), `testdata/errors/ffi.txtar`. `ffi` is in the Gemfile for MRI.
