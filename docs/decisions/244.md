# Decision 244

**Rule:** `class X < self`, nested constant assigns, `$!` in rescue, `case s when /re/` as `=~` chain, and gem leniencies from the optparse.rb probe.

**Toward compiling MRI's own optparse.rb for Homebrew** (#99; 2026-10-13). *See also decision 330* (untyped containers among other classes).
Homebrew's CLI::Parser reaches into OptionParser (`base.long`,
`make_switch`'s Switch, `summary_indent`, `Array` coercion), which
rugaroo's 217-line prelude copy lacks. Following "prefer real gems", the
goal is MRI's unmodified 2,463-line optparse.rb compiled as gem code;
a probe of it (lib copy, gem mode) now builds and runs into
`make_switch`'s inner workings. General features on the way:
- `class NoArgument < self` names the enclosing class.
- A constant assigned inside another's value
 (`NoArgument = [NO_ARGUMENT = :NONE, nil]`) is its own constant,
 initialized just before.
- `$!` in a rescue clause is the exception it handles (elsewhere nil:
 ponytail).
- `case s when /re/` in a frame that reads `$~`/`$1` is an if/elsif
 chain of `re =~ s` tests, in order, so the matching arm reads its own
 match (a non-String subject is tested `String === s` first; `when
 Class` becomes `s.is_a?(Class)`, which narrows a local subject;
 `when *list` is `list.include?(s)`, ponytail: `==` per element).
- `Array === x` in a condition narrows a local x as `x.is_a?(Array)`.
- `q, a = nil` assigns nil to each target.
- `String.try_convert`, `Array.try_convert` (untyped, so no optional
 Array type joins every program's unbox switches), `Enumerable#collect`.
- Gem leniency: a computed send passing a block (an rbBlockArg, and
 every block-taking method a computed name reaches gets a block
 wrapper); an untyped, union or optional receiver's `method(:x)`, and
 an untyped Method's `to_proc` (a variadic Proc calling it
 dynamically); `(o = v).bang!`; a void call's value used is nil; a
 `when` arm that does not compile raises NotImplementedError if
 reached, rather than costing its method; a gem's top-level
 `ARGV.extend(M)` is dropped (ponytail); parameter inference takes a
 gem caller's untyped container over a narrower type from another
 call, and makes a parameter untyped when gem calls pass kinds that do
 not join; a gem's nil-only local is hoisted as untyped.
- Codegen bugs: a failed `try` left the locals its attempt declared in
 scope (an assignment inside a splat argument then had no
 declaration); a stubbed iterator lost its `return func(yield ...)`
 opener; a widened param's copy was taken before its rest param was
 bound. `RUGAROO_GOPOISON_DUMP=path` writes each Go-stubbing round's
 code before stubbing (`path.0`, ...), for debugging.
- Build cost: `05_word_count` and `116_cuba_web` unchanged;
 `64_observable` +8 (its dynamic sends keep every public method of a
 live class: `collect`, `try_convert`).
Not yet: the rest of optparse.rb (lambdas and blocks with rest
parameters on dynamic calls, `$DEBUG`, `compact!` on an untyped Array,
...), and routing brew's `require "optparse"` to it.
