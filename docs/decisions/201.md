# Decision 201

**Rule:** A gem load-time `if`/`unless`/`case` whose arms boot covered only one of compiles as that arm; method bodies never fold.

**Load-time branches fold to what boot ran** (amends 161). Boot runs
with `Coverage.start(branches: true)`; a load-time `if`/`unless`/
`case` in gem code (a class body, a constant initializer) whose arms
boot saw only one of compiles as that arm. Method bodies are never
folded.
