# Decision 303

**Rule:** A gem method `go/types` rejects is stubbed in the Go text by `stubRejected` (signature kept), never by compiling again.

**A gem method Go rejects is stubbed in the Go text, not by compiling again** (amends 205; 2026-10-18). The traced build used to poison each gem method `go/types` rejected and run the whole compile again (prelude parse, link, every inference round, emit, prune, format), then type-check again: one extra pass whenever any method was rejected, which brew always has.
- **What:** `stubRejected` type-checks the output once, replaces each rejected gem func's body with the same `panic(NewNotImplementedError(...))` the compiler emits, keeps its signature, and deletes each import only stubbed bodies used (the check's `types.Info.Uses` says which funcs use each package, so no second check is needed). The warning per method is unchanged.
- **Why it is safe:** the signature stays, so no caller's Go changes and nothing new can fail (a recompile could cascade: the poisoned method's inferred return became `untyped`). Callers keep the method's narrower inferred type, which only matters on a path that already raises.
- **Differences from a recompile:** what only the stubbed body reached stays in the output (brew info: 54 lines fewer in all, so in practice none); a stubbed iterator raises when called rather than when iterated (every iterator call is a `for range`, so the same place). `RB2GO_GOPOISON_DUMP=path` writes `path.0`, the Go before stubbing.
- **Measured** (`brew info wget`, quiet 10-core macOS): gen 56.8 → 33.9 s with a second type-check, 31.5 s with one; peak RSS 4.0 → 1.9 GB; same 25 stubs; `info wget`, `info jq`, `info git`, `info --json=v2 wget` equal MRI. Untraced compiles never ran the loop: small programs unchanged.
- **Proof:** `TestStubGoFuncs` (internal/compiler/gopoison_test.go): a rejected method and free func are stubbed, an import only they used is dropped, one kept code also uses stays, the caller is kept, and the result type-checks.
- **The other passes:** a traced compile runs `compileWith` five times (first try, three inference rounds, final), each from a fresh model. Redoing setup (prelude, user collect, link) cost ~0.95 s a pass; `realPath` is now memoized for the process (resolved paths only), which takes it to ~0.77 s. Keeping the model across passes would save the rest (~3 s of 31) but needs a snapshot of everything the rounds mutate (`m.Ret`, ivars, poison): not done. `RB2GO_TIMING=1` now also ticks `trace`, `boot`, each `round`, `compile` and `gocheck`. Where gen goes now: rounds 7 s, format 9 s, Go check 6 s, setup 3 s, final infer+emit 2.5 s, MRI trace+boot 2.2 s.
