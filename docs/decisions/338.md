# Decision 338

**Rule:** Compiler state uses typed fields and keys (grouped `Compiler` structs, `rbs.ParamKind`, `boot.Loc`), not flag bools or `"path:line"` strings.

**Typed fields and keys instead of flag bools, string kinds and `"path:line"` keys** (#109 phase 3; 2026-10-22). *See also decisions 119, 337.* A behaviour-free change, checked by byte-identical `rb2go gen` output on 171 inputs (the `120_pairing_heap` example is skipped: its `gen` is non-deterministic, #109) and by the full test run.
- **`Compiler` is grouped.** The 170-odd fields are in embedded structs (`dynState`, `memoState`, `bootFacts`, `marshalState`, `instState`, `pathCache`, `tableState`); fields are promoted, so `c.name` is unchanged. `tableInputs()` returns a named struct, not `[14]int`. Fields that tests set in a struct literal stay on `Compiler` itself (a promoted field cannot be named in a literal before Go 1.27).
- **`rbs`**: `Param` has `Kind ParamKind` (positional, rest, keyword, kwrest; `Optional` stays a flag) instead of three bools that could not all be true; `Literal`, `AttrDecl` and `IncludeDecl` kinds are named string types. `TypeParams []string` stays: about 220 references, and the compiler's own `Class.TypeParams` is assigned from it.
- **`boot.Loc{File, Line}`** replaces File/Line pairs in the manifest records (the JSON is unchanged, pinned by a test) and the `"path:line"` string keys of `bootBranches` (with a column), `evalSites`, `evalUnits`, `bootDelegators` and the `define_method` indexes. A malformed include site now skips the include; it used to panic on a negative slice.
- **Narrowed ivars and attr readers** are keyed by `ivarNarrowKey`/`attrNarrowKey` (one place each); the key text is unchanged because they share `scope.vars` with locals. `lookupMissMode` returns a `missMode`. `cmd/rb2go`'s `buildOpts` holds plain values.
- **Not done.** `lexScope{File, Scope}`: `scope []*Class` is a parameter of about 77 signatures in 17 files, next to `f *File`; no map is keyed by the pair, so the gain is smaller than the edit. A typed `TypeParam` (above).
