# Decision 211

**Rule:** A generic primitive's own methods get Go forwarders only for protocol names (`stdMethodNames`, `genericProtocol`, includer calls, universal names).

**A generic primitive's own methods have no forwarders but the
protocol names** (#96 phase 3b, amends 86). Decision 86 gave every
own method of `Array`, `Hash`, `Set`, `Range`, `Enumerator` a one-line
Go method forwarding to its free func, and relied on the pruner to
keep only the ones a kept interface declares. Typed calls never used
them (`callCode`'s `free` is true for a generic primitive), and in an
unpruned program (`RUGAROO_NO_PRUNE=1`, `TestPreludeWhole`, a future
precompiled prelude) all 124 of `Array[E]`'s methods compiled per
instantiation, transitively through every instantiation their bodies
name. `wantsForwarder` now emits a generic primitive's own method as a
Go method only when something reaches it through a Go method set:
`stdMethodNames` (`String`, `Len`, ...), `genericProtocol` (what
prelude Go asserts or calls by method on an unknown instantiation:
`_to_any`, `_from_any`, the `_eq_rec`/`_eql_rec`/`_hash_rec`/
`_inspect_rec` recursion guards, `==`, `eql?`, `hash`, `<=>`, `each`,
`succ`, `to_s`, `inspect`, `to_json`, `pretty_print`), an included
module's self calls (`includerCalls`), or a universal name
(`universalHas`: Kernel/Object/BasicObject define it, so `ObjectI` or
`rbEq` may select it). Dyn dispatch on generic classes already goes
through `_DynGenN` before any shared arm (decision 209), so no
untyped path changes.
- **Measured** (compiled functions; peak compile RSS, `-dwarf=false`):
 unpruned core prelude 63,506 → 34,431, 1,872 → 971 MB, 36 → 6 s,
 archive 127 → 69 MB; `Array[E]` 124 → 31 methods per
 instantiation. Pruned programs move little, as the pruner was
 already dropping these: `116_cuba_web` 33,244 → 31,692 and 1,347
 → 1,288 MB; `64_observable` 32,825 → 32,107.
- **Proof:** suite unchanged (`hash_test`'s recursive equality found
 the `_eq_rec` guard must stay a method, or `rbEq` recurses forever).
- **Next (phase 3b):** the same for generic struct classes
 (`Enumerator` and its subclasses, `Queue`), then the 6,015
 metaclass forwarders of the remaining 9,795.
