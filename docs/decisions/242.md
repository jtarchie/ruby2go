# Decision 242

**Regexps RE2 cannot match run on regexp2** (amends 24; 2026-10-13). *See also decision 326* (purego, the second runtime module), *decision 332* (subjects converted once). *See also decision 347* (simple patterns skip RE2; a regex-to-Go compiler weighed again and declined).
Homebrew writes lookaround 38 times and `\Z` 46 times; decision 24
rejected both, and a hand-made lookaround on the in-house backtracker
would have been one more special case. The user approved one dependency
for this: `github.com/dlclark/regexp2` (a .NET-style backtracking
engine).
- **RE2 first.** `rxCompile` compiles the translated pattern with RE2
 (linear time) and falls back to regexp2 only when RE2 rejects it:
 lookahead and lookbehind, backreferences (`\1`, `\k<n>`, `\k'n'`),
 atomic groups `(?>...)`, inline `(?x)`. regexp2 runs in its RE2 mode,
 so `\w`, `\d` and `\s` stay ASCII as Ruby's; the translator's output
 (`\x{...}`, `\p{...}`, `(?m)`/`(?s)`) reads the same in both.
 Offsets are converted from regexp2's runes to bytes (`rxAlt2`).
- **`\Z` is exact** now: `(?=\n?\z)` (241 matched the newline).
- **Still rejected**: `\g<n>` (regexp2 would read a literal `g`),
 possessive quantifiers, the absent operator, `\G`/`\K`/`\R`/`\X`.
- **Only programs that may need it get it.** `rxalt.go` (the adapter,
 which registers `rxAltCompile`) is emitted into a program, and
 regexp2 imported, only when a pattern literal needs it, an
 interpolated pattern embeds another pattern's text (`.source`, a
 Regexp or untyped value), `Regexp.new`/`compile`/`union` gets
 anything but literals RE2 compiles, or gem code builds patterns at
 run time. Prelude code does not count. Package-level pattern
 variables initialize through `rbRegexpNewAfter(rxAltReady, ...)`, since
 Go runs `init` after them. Every generated module's `go.mod` requires
 regexp2 (`rb2go.WriteModule`, with its `go.sum` lines); Go loads it
 only when `main.go` imports it, from the module cache.
- **Build cost**: `05_word_count` unchanged; `64_observable` +2 (the
 routing in `rxRegexp`); `116_cuba_web` gets the engine (rack builds
 patterns at run time).
- **Kept**: the in-house backtracker for Onigmo's `^` (never after a
 final newline; regexp2's multiline `^` would match there) and its
 Unicode `\b`, and `rxFold`'s multi-character case folds (regexp2
 does not fold `ß`/`SS` either).
- **More of brew's load path** (2026-10-13, after 242):
 `ENV.fetch(k, d)` is `ENV[k] || d` (an ENV value is a String, so this
 is fetch's answer for any d: nil, false, a String; a non-literal d is evaluated first, decision 336); a mixed-in `inherited` calling `super` reaches Class's
 no-op (hook bridges return a zero value); a metaclass carrying a
 mixed-in module's ivars answers `instance_variable_set`/`get`, so an
 `inherited` hook's `child.instance_eval { @env = ... }` works;
 `h.merge(g)` of different value types joins them, as `Array#+` does
 (in gem code an untyped side makes the result untyped); a gem's
 blank-slate `(instance_methods - ...).each { |m| undef_method m }` is
 skipped (ponytail: the methods stay; Homebrew's InstallSteps DSL uses
 it only as a sandbox); a T::Struct's props declared by a load-time
 loop under computed names (Homebrew's FormulaStruct predicates) come
 from the boot snapshot, which now records each T::Struct's props
 (name, Sorbet type text, literal default), and the loop is skipped;
 `def self.included(base) = base.extend(M)` is
 mixes_in_class_methods(M); a class-body call of a class method whose
 body is `extend M` (`safe_initialization!`) extends that class at
 load, and a run-time `extend M` is a check that the class has M;
 `$1`/`$~` inside a `sub`/`gsub` block are that match; a gem block's
 or lambda's `&blk` param is a nil local (ponytail: the caller's block
 is dropped) and a gem lambda's defaults bind as a block's do.
- **`A, B = 1, 2` in a body** declares each constant. **A gem method's
 param guessed from its default** (`level = :FATAL`) that is
 reassigned an untyped value (`const_get(level)`) is widened to
 untyped, as one reassigned another type already was; a signed
 param keeps its type.
