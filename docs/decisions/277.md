# Decision 277

**File provenance is a sealed Origin** (#101; amends 172; 2026-10-14).
- `Origin` (`originSource`/`originUser`/`originGem`/`originPrelude`)
 replaces `File.prelude bool` and `gem *bool`. The prelude origin is
 set at construction (`parseFile` takes an `Origin`) and gates the
 `%x{}` Go escape hatch, prelude-only branches and `dynRaise`. A file
 loaded from disk starts as `originSource`; `gemFile` classifies it
 as user or gem on the first ask and memoizes it, so the gem-dir
 symlink resolution (44% of brew's gen CPU, decision 237) is still
 paid once per file, and only if asked.
- Source re-parsed from a declaration (`Struct`, `delegate`,
 `def_delegators`, `define_method`, anon classes) gets
 `f.synthOrigin()`: prelude stays prelude, anything else starts
 unclassified and classifies through the `path` copied from the
 originating file, so a gem's synthesized code stays gem code
 (decision 172) and a path-less synthetic file is never a gem's.
- Behaviour and positions unchanged (byte-identical `gen` over 730
 inputs and the gem-style fixtures; compiled function counts
 identical).
