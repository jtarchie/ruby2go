# Decision 412

**Rule:** A method whose yields pass another number of values than its inherited signature's block keeps its own block and does not take the inherited iterator's slot; `and`/`or` right operands are branches for hoisting; a free func's `Self` that appears inside a tuple or generic argument is also `comparable`; an `each` seq adapter passes a trailing Symbol, Integer, String or boolean default as written; Integer, Float, Rational and Complex answer `+@`.

**Bundled-gem backfill, third batch: matrix** (2026-10-29). *See also decisions 256, 410, 411.*

`library/matrix` (matrix, vector, and the decomposition dirs) went from not compiling (0 of 300) to 206 of 360 passing. Matrix's first blocker was a three-value block, but the cause was the signature, not Go's two-value iterators:

- **Another block arity is another method.** `Matrix#each_with_index` yields `e, row, col`; it inherited Enumerable's `{ (E, Integer) -> void }` (decision 256 keeps the whole inherited block), so its own yields could not fit and it took the iterator's two-value slot. `inheritSignature` now skips an inherited signature whose block arity disagrees with every yield in the body (`yieldArity`; a splat yield or two disagreeing yields give no answer and keep the old behavior), and `overridesIterator` needs equal block arity. The method keeps its own closure block.
- **`rows = check_range(i) or row = check_int(i)`.** The right operand of `or`/`and` runs only sometimes, so a local first assigned there is hoisted as in an `if` branch (`genRight` enters a block scope); before, the local was declared inside the Go `if` and the later read failed to compile.
- **`[self, other]` from a module method.** A free func whose `Self` appears inside a tuple or a class's type arguments needs `comparable` on it (Tuple2's fields are comparable), so `typeParamDecl` adds it (`selfInContainer`).
- **`each(which = :all)`.** A seq adapter answering Enumerable's `each()` dropped only nil-defaulted params; a literal default (`goLiteralDefault`) is now passed as written, through `Ref` when the param is optional.
- **`+a`.** MRI's `Numeric#+@` (the number itself) was missing on all four numeric classes.
- **Known gaps:** a typed `each(which = :all)` that is a pure iterator (void block, returns nothing) is still a Go iterator with the extra param and does not answer Enumerable's `each()`; matrix's returns `self`, so it goes through the adapter.
- **Proof:** `testdata/test/enumerator_test.rb`'s `GridTest`; `library/matrix`.
