# Decision 234

**Fewer per-class functions for Homebrew's build memory** (#96,
amends 209, 214, 216). The capped brew build was killed at 7.39 GB.
- **`Kernel#exit` is private**, as MRI's is (`exit` and
 `Kernel.exit` work; `obj.exit` is NoMethodError). It was public, and
 a Go-side `Monitor.Exit()` call kept the name out of type-switch
 dispatch, so every class interface listed it with a forwarder:
 about 1.6k functions in brew.
- **A module calling a method of a module it includes reaches that
 method's dispatcher**: decision 214 kept a module method out of
 dispatch when another module including it called it on self
 ("self-called by including module"), so `Utils::Output::Mixin`'s
 30 methods had a forwarder on each of its 278 includers. Everything
 that includes the calling module includes the callee's, so its
 self is asserted to the callee's constraint (`any(self).(M_Self[any])`)
 and passed to the dispatcher.
- **A dispatched module method's Dyn wrapper is one shared arm**: its
 body is instantiated at the module's constraint (decision 208), the
 same text for every includer, with self asserted to it. Without
 this the wrappers grew by what the forwarders shrank.
- Decision 216's class-name guard matches the class's own Go names
 (`A`, `AI`, `A_Meta`, `A_class`), not any substring (`rbArity`
 holds an `A`).
- **Measured** on brew's generated Go: 77,381 → 75,788 functions from
 `exit`; the dispatch change cut forwarders 17.6k → 12.8k. The net
 count with the shared arms, and a capped build, are not measured yet.
