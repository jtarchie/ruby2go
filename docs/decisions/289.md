# Decision 289

**Pathname is an ordinary object** (#100; amends 65; 2026-10-15).
- Pathname was a `@go_type string`: a Go value with no room for state, so a Pathname could not hold instance
 variables, nor could a subclass or an included module with state. Homebrew gives Pathname state in four
 places (`DiskUsageExtension`, `EagerInitializeExtension`, `ObserverPathnameExtension`, `ELFShim`'s caches);
 MRI's Pathname is an ordinary object holding `@path`. Now rb2go's is too: a struct class with `@path:
 String`, its Go escapes reduced to two string helpers (`__join`, `__rel`). The compiler's value-base paths
 (decisions 172, 202) no longer apply to it.
- `self` of a struct class where its class does not fit converts through MRI's implicit protocols
 (`File.basename(self)` in a Pathname: `to_path`, decision 253). The generic Self type fit anything, so it
 was passed unconverted.
- `Pathname#read(length, offset)`, as MRI's.
- Found on the way: `collectBodyConst`/`liftConstWrites` rewrote the parsed prelude's AST in place, which every
 compile shares (a data race, and a second compile saw the first's rewrite). Both are copy-on-write now.
- Cost: `05_word_count` unchanged, `64_observable` −1 function, `116_cuba_web` +105 (+0.4%). Brew's
 Go-rejected/uncompilable methods 209 → 206 (`Pathname#initialize`, disk usage).
- Proof: example 55, `stdlib_test.rb` (`test_pathname_subclass_with_state`), `TestPreludeWholeNoEnv` (no race).
