# Decision 334

**Rule:** `TestGemCorpus` runs kramdown's testcases; bang write-back only into Array/Hash slots; `x and return v` is `return v if x`; nil conditions still run.

**kramdown's own testcases, and the gaps they found** (amends 172, 205, 330, 331; 2026-10-21). Example 123 and the benchmark convert one document each; kramdown 2.5's 216 testcases (`test/testcases/**/*.text`, default options) reach far more of the gem. Through a traced build of one program over all of them, 126 matched MRI; now 212 do. `TestGemCorpus` (`testdata/corpus/kramdown.rb`) keeps it so: each case's HTML must equal MRI's, except those `gemCorpusKnown` lists with a reason, and a listed case that starts to match must leave the list. Every fix is a rule for any gem or program:
- **`scan` with groups from interpolated constants.** `literalGroups` counts an interpolated Regexp constant's groups (`/(?:\A|\s)(?:#{PAIR}|#{REF})/`, whose groups are all PAIR's and REF's), where it counted each interpolation as plain text; and in gem code a pattern whose groups are still unknown takes `__scan_any`, which yields rows or strings as MRI decides at run time, where it raised NotImplementedError (47 cases).
- **Write-back only into shared slots (amends 331).** A bang edit on a local read from `r[i]`, `r.first` or `r.last` writes back into r only when r is an Array or a Hash: for an untyped r that is checked at run time (`rbSlotShared`). A StringScanner's or a String's `[i]` is a new String, so `name = @src[1]; name.downcase!` touches nothing else in MRI, and rb2go called a missing `StringScanner#[]=` (30 cases).
- **Constants a class-body `begin` assigns.** `begin; require 'rouge'; AVAILABLE = true; rescue LoadError; AVAILABLE = false; end` in a module body is declared (the first assignment types it) and assigned where the body runs, as decision 170's body constants are; before, the statement was skipped and `const_defined?(:AVAILABLE)` was false, so kramdown used the highlighter it did not have (14 cases). A statement list stops after a call that never returns (the LoadError's), which go vet calls unreachable.
- **Appends.** `t << a << b` on an attribute (`last.value << joiner << result`) is `t << a`, then `t << b` on t read again (decision 330 only took a local); `$1 << pad` in a block is a concatenation, since each read of `$1` is a new String; `(c ? cells : cells.last) << x` is `c ? cells << x : cells.last << x`, so each branch gets its own rule (Array push, or the last String's write-back) (9 cases).
- **`x and return v`** (and `next`, `break`; `or` for unless) as a statement is `return v if x`, in user code too; not when x is an assignment (`x = v or return`, which would also need narrowing) or typed void.
- **A condition typed nil or void still runs.** `puts "x" if log_it` with `log_it` returning nil compiled to `if false`, dropping the call; the call is now a statement before it.
- **Smaller.** Dynamic `Array#[]`/`[]=` take a Range of `Integer?` (`0...columns`), and `Range#__slice`/`__span` unbox its ends.
- **Left** (`gemCorpusKnown`): `x and return` where x is a method whose last statement is a multiple assignment, which rb2go types void though MRI returns the right side's Array (giving such methods a value would change many gem methods' types; 2 cases, now an error rather than wrong HTML); byte indexing after `force_encoding('ASCII-8BIT')` on valid UTF-8, since Strings carry no encoding (decision 136; 1 case); and `h.each_value { |v| v.gsub!(...) }`, an edit of a block parameter that MRI's shared Strings see through the Hash (1 case).
