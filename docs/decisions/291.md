# Decision 291

**Brew batch 18: one ivar across a module and its includer; a delegator over `Set.new(p)`; true/false answer
their reopened classes dynamically** (#100; amends 147, 241, 284; 2026-10-16). With it and brew patches 0001–0006,
the compiled `brew info wget` prints MRI's output exactly.
- A class declaring an ivar an included module already holds uses the module's field (`declareIvar` walked
 only superclasses): Homebrew's Downloadable `attr_reader :checksum` and Resource `attr_writer :checksum` were
 two Go fields, so a bottle's checksum was nil. Attr readers and writers address the field by `ivarPath`.
- A SimpleDelegator subclass whose annotated initialize does `super(Set.new(p))` wraps `Set[T]` (decision 284
 took `super(p)` only): Homebrew's Requirements.
- Boolean's Dyn wrapper for a name the program's TrueClass or FalseClass reopening defines dispatches on the
 value, as the static call does (decision 241): through an untyped value `false.present?` took Object's and
 was true, which turned on `--debug` and `--verbose` from brew's environment defaults.
- Proof: testdata/boot (`DemoSharedIvar`, `DemoSetDlg`, `DemoBoolDyn`).
