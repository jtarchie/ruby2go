# Decision 379

**Rule:** `%f`, `%e` and `%g` print MRI's digits (a port of its patched `BSD__dtoa`, not Go's correctly rounded ones); `swapcase` uses full case mapping; case maps of a String that is not UTF-8 change ASCII letters only; an interpolation is always a new String.

**Four MRI behaviours, matched** (2026-10-26). *See also decisions 43, 324, 377.* Found while measuring decision 377; each was checked against MRI exhaustively rather than on examples.
- **Float digits.** MRI formats a Float through its own copy of David Gay's dtoa (`missing/dtoa.c`, mode 3 for `%f`, mode 2 for `%e`/`%g`). Like Gay's, it first generates the digits with floating-point arithmetic and falls back to exact bignum arithmetic when the remainder after the last digit is too close to one half to call. Ruby's copy then rounds an *odd* last digit up and keeps an *even* one, whatever the exact remainder: `"%.2f" % 2.675` is `2.68` although 2.675 is 2.67499…, and `"%.2f" % 8.345` is `8.34` although 8.345 is 8.34500…06. Go's `strconv` rounds correctly, so rugaroo printed `2.67` and `8.35`. `rbDtoa` (`prelude/go/format.go`) ports the quick path line for line (the `k` estimate, scaling by `tens`/`bigtens` with `ieps`, `eps`, the `half` case, `bump_up`); the exact path is `strconv` (ties to even, as dtoa's). In the undecided-even case dtoa's round-off branch skips its zero trim when the exact remainder is over a half, and `%g` prints dtoa's digits as given, so `"%g" % 609.8305` is `609.830` (`rbDtoaExactUp`). `rbFmtFloatSpec` lays the digits out with every flag as `BSD_vfprintf` does; `rbFormatOne`, the fast path and the compiled-format helper (377) all use it. Inf and NaN keep their path. `Float#to_s` (shortest digits) and `Float#round` were already MRI's.
- **`swapcase`** mapped one rune by Unicode category. It now uses full case mapping, as `upcase`/`downcase` do (`rbSpecialCasing`: `ß` to `SS`, `İ` to `i̇`, `ﬃ` to `FFI`), swaps by mapping rather than category (so `Ⅰ`, `Ⓐ` and U+0345 swap), and splits the 31 titlecase letters as MRI does (`ǅ` to `dŽ`, `ᾈ` to `ἀΙ`: `rbTitleSwap`, generated from MRI 4.0.7, which Go's `unicode` has no mapping for).
- **Binary Strings.** A String that is not valid UTF-8 is a binary one (decision 324). Its `upcase`, `downcase`, `capitalize` and `swapcase` decoded it as UTF-8, writing U+FFFD for each bad byte and mapping the valid multibyte letters inside. They now change ASCII letters only and keep every other byte, as MRI does for ASCII-8BIT.
- **Interpolation identity.** `"#{a}#{b}"` compiled to Go's `a + b`, which returns its one non-empty operand itself, so `"#{a}#{""}"` was `a` (and frozen with it). By its literal parts, known at compile time: two or more non-empty literal parts cannot alias, so Go's `+` stays; with one, `rbNewStr(lit, ...)` clones a result that is that literal; with none, `rbConcat` (377). No measurable cost (the interpolation-heavy stage of `benchmarks/format.rb` 515M both ways).
- **Checked:** the four case maps of every code point 0 to 0x1FFFF that has one (3,042) and of binary Strings, against MRI: equal. 3,519 Floats (random magnitudes, decimal near-ties, exact binary ties, extremes, denormals, negatives) under 24 specs (`%.0f` to `%.15f`, `%e`, `%.0e`, `%g`, `%.2g`, `%G`, `%#g`, `%#.0f`, `%#.0e`, `+`, space, `0` and `-` flags with widths), through a run-time format string and through literal ones (377's compiled path): equal.
- **Not done:** `inspect` of a binary String still prints a valid multibyte sequence inside it as the character (`"\xFF\xC3\xA9".b` shows `"\xFFé"`; MRI `"\xFF\xC3\xA9"`).
- **Cost:** `"%.2f" % x` 146M to 145M instructions for 100,000 calls (digits and layout append into stack buffers); each stage of `benchmarks/format.rb` equal or lower; the whole program about 3% higher (1,650M to 1,700M over 7 runs), not attributable to any stage.
- **Proof:** `StringMRIQuirksTest` in `testdata/test/string_test.rb`, against MRI.
