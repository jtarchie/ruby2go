# Decision 309

**Rule:** A generic class's superclass takes type arguments (`< Heap #[E, P]`); each instance embeds its parent instance, appended after it (345).

**A generic superclass takes type arguments** (#104 phase 2; amends 308, 305, 8; 2026-10-18). rbs-inline's `class MinQ < Heap #[E, P]` (the `#[...]` on the class line, read as `include X #[...]` is) or a sig's `class MinQ[E, P] < Heap[E, P]` (`ClassDecl.Super`) names the superclass's arguments (`superArgs`).
- **Templates.** A generic class whose superclass is a struct class (Object, a template, or a plain struct class) is a template too (`markTemplates`, before link: `isTemplate` no longer requires no superclass). A template's own `Super` is the parent template, typed generically and never emitted.
- **Instances embed the parent instance.** An instance resolves `superArgs` in its own scope (so `Flipped[A, B] < Heap #[B, A]` remaps, and arguments may be any closed type), and its superclass is that parent instance (`superInst`, made with it in `makeInstances`): `MinQ[String, Integer]` embeds `Heap[String, Integer]` as any struct subclass embeds its parent, so `super`, inherited calls, overrides (decision 8's adapters), `is_a?(Heap)` and the parent's interface all work unchanged. Two subclass instances over the same arguments share one parent instance, which then dispatches over both (decision 212). A non-generic child (`class IntHeap < Heap #[Integer, Integer]`) is an ordinary class whose superclass is `Heap[Integer, Integer]`.
- **Class objects.** `metaFor` of any instance is its template's metaclass, so `MinQ.superclass` is `Heap` and `IntHeap.ancestors` is `[IntHeap, Heap, Object, ...]`, as MRI answers.
- **Inherited aliases** (decision 305's `alias_method :extract_min, :dequeue` over a superclass's alias): a template's pending alias is copied to each of its instances, where the target is a plain instance method and copies as any; the template's own is skipped. Decision 305's error for an alias of a generic owner's method stays only for `@go_type` owners.
- **Proof:** `generic_class_test.rb` (`MinQ[E, P] < Heap #[E, P]` with `super` and an alias of an inherited alias, `Flipped[A, B] < Heap #[B, A]`, `IntHeap < Heap #[Integer, Integer]`; `superclass`, `ancestors`, `instance_of?`, `===` on an untyped value).
