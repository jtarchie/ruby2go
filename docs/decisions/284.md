# Decision 284

**Rule:** A `SimpleDelegator` subclass whose annotated `initialize` only calls `super(p)` (or `super(Set.new(p))`, 291) wraps `p`'s type; else untyped.

**A SimpleDelegator typed by its initialize; `Pathname.glob`** (#100; amends 118; 2026-10-15).
*See also decision 291*.
- A `SimpleDelegator` subclass whose own annotated `initialize` sets the wrapped object only by `super(p)` from
 a typed parameter `p` (a rest parameter wraps `Array[T]`), with no `__setobj__` call and no subclass
 `initialize`, wraps that type: `__getobj__` is one assertion to it, and forwarded calls are typed instead of
 dynamic (Homebrew's `Dependencies#initialize(*args)` with `args: Dependency`: `deps.select`, `reject`,
 `filter_map`). Anything else keeps decision 118's untyped object.
- `Pathname.glob(String | Pathname | Array[String])` (only the instance form existed, so a call on the class
 was dynamic).
- Effect on `brew info wget`'s program: untyped receivers of dynamic calls 1,779 → 1,702, dynamic call sites
 2,607 → 2,482.
- Proof: `stdlib_test.rb` (`test_simple_delegator_typed_by_initialize`, `test_pathname_class_glob`),
 testdata/boot (`DemoDlg`).
