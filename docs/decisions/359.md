# Decision 359

**Rule:** A user or gem struct class that nothing inherits from and that mixes in no user or gem module is a leaf: its values are Go `*C`, not its interface `CI`, its plain methods take `self *C`, and calls on it go to the resolved free func.

**Leaf classes as concrete pointers** (amends 210; 2026-10-24). *See also decisions 209, 210, 355.* Every struct class's values were its interface `CI`, and its methods' bodies reached their ivars through `self._C()`, an interface call per access that Go cannot inline. In a closed world a class with no subclass has exactly one Go type, as spinel types every object slot by its one class. Now:

- **Leaf** (`Class.leaf`): a struct class (not a module, not universal, no `@go_type`) with no subclass, no type parameters, not a metaclass, Hash/Array base, per-run `Class.new` or template, defined outside the prelude, and with no user or gem module among its ancestors (`mixesUserModule`): such a module's constraint can demand `m() Self` of its includers, which a leaf's `*C` methods do not declare (ponytail: check the constraint's signatures to let these in). Prelude modules (Enumerable, Comparable) are fine, so a Struct class can be a leaf.
- **Types.** `goType` of a leaf is `*C` (`objType`); a plain func (decision 210) of a leaf owner takes `self *C`, so `self._C().x` is a field load after inlining. `C?` stays `**C` (the `Ref` path); a nil `*C` for it is the next step.
- **Calls.** On a leaf receiver the method found is the method that runs, so the call is always the free func (`leafRecv` in `callMethod0`'s `free`): no forwarder or method expression, and the class's interface and forwarders are emitted only where something still needs them. A generic body's `Self` value (self, a `self` parameter) passed where a leaf's `*C` is wanted, as a plain func's receiver or argument, is asserted once (`leafSelf`); a `Self`-returning generic call instantiated with `*C` already returns `*C`, so `selfReturnAsserts` adds no assertion.
- **Nil.** A leaf value boxed into `untyped` goes through `rbPtrAny`: a nil `*C` (a gem sig promising a class where the gem returns nil, boot's `tab_for`) is Ruby's nil, not Go's typed nil pointer in an interface. Conversions to another interface type are unguarded, as a leaf-typed value is non-nil in sound code.
- **Measured** (instructions retired, GOMAXPROCS=1, before → after): spinel's `bm_setivar` 221 → 76 M (2.9x), `bm_inline` 2,394 → 1,387 M, `bm_attr_accessor` 1,825 → 1,106 M, `bm_getivar` 183 → 114 M, `bm_structaref` 206 → 127 M, `bm_structaset` 1,137 → 717 M, `bm_ao_render` 2,865 → 1,870 M, `bm_splay` 769 → 523 M, `bm_binary_trees` 98 → 80 M, `bm_gcbench` 10,511 → 8,642 M, `bm_linked_list` 1,839 → 1,464 M; `bm_object_new` 35 → 39 M (worse; not chased). Repo benchmarks: splay 1.44x, binary_trees 1.24x, collections 1.16x, objects 1.10x, the rest within ±2% (pairing_heap 0.98x: its nodes are `Node?`).
- **Cost:** TestCompileCost 1,942 / 7,624 / 29,782 → 1,942 / 7,605 / 29,228 compiled functions (leaves drop their interface and forwarders).
- **Proof:** the suite (every class test exercises leaves); `TestBootAutoload`'s expected Meter signatures are the free funcs'; spinel's benchmarks == MRI.

*See also decision 360* (a leaf's `C?` is its `*C`).
