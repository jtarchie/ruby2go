# Decision 10

**Rule:** Go type parameters are all constrained `comparable`; generic struct classes are monomorphized instead (decision 308).

Type parameters are all constrained `comparable`. Every generated Go
type satisfies it (strings, ints, pointers, interfaces, tuples of
those), and it is what `map[K]` and `tally` need; deriving the
constraint per parameter bought nothing.
*See also decision 308:* a generic struct class is not a Go generic type at all; each instantiation is its own struct.
