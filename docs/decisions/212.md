# Decision 212

**Rule:** A call to a dispatchable struct-class method compiles to the owner's free func, or an `rbSend_<Owner>_<Name>` type switch when overridden.

**A struct class's method dispatches by type switch, not by Go
interface method** (#96 phase 3b step 1, amends 8, 89, 210;
`dispatch.go`). A Ruby call on a receiver statically typed as a
struct class (or `self` in its body) whose resolved method is
`dispatchable` compiles to the owner's free function when no class
below the receiver's static class overrides the name, else to
`rbSend_<Owner>_<Name>(self OwnerI, ...)`: a type switch over the
classes whose own resolution differs, each arm a direct call to that
class's free function, the default the owner's body with the real
`self`. Such a name has no forwarder on any class and no class
interface declares it (`dispatchableAll` walks the ancestors'
resolutions, so one ancestor that keeps the Go method keeps it on
every descendant). Dispatchable: the owner is a struct class (not a
module, metaclass, universal owner or `Module` subclass), the method
is a public plain def that decision 210 emits as a plain function,
every override below has the same Go signature, and nothing reaches
the name through a Go method set: `stdMethodNames`, `genericProtocol`
(decision 211), a universal name (`inspect`, `to_s`, `==`, asserted on
`any`), an including module's self call, or a selector prelude Go
calls (`goCalled` scans `prelude/**` for `.Name(`). A `Method`
object's bound definition (`staticDef`) and a Dyn wrapper body's
self call keep their direct calls (MRI runs that definition).
- **Why:** a Go interface needs the method on every implementer; the
 pruner hid that per program (decision 89), a precompiled prelude
 cannot, and Go recompiles every method of a generic instantiation
 and every promoted method of an embedded struct in the importing
 package. The switch is compiled code with inlinable arms, no map or
 reflection, and `self` is never the embedded parent (decision 8's
 hazard), so no forwarder re-declaration is needed.
- **Speed:** 20M calls of `area`/`sides` over four `Shape`
 subclasses: 0.33 s → 0.23 s user (the arm inlines).
- **Measured** (compiled functions; peak RSS, `-dwarf=false`):
 `116_cuba_web` 31,692 → 31,075 (forwarders 2,751 → 2,541), 1,288 →
 1,254 MB; unpruned core prelude 34,431 → 33,072. The hand-built
 `rt` split of decision 210's note re-run: `05_word_count`'s own
 package 20,844 → 3,372 functions and 805 → 194 MB (one pruned
 package: 1,370 / 124 MB), `116_cuba_web`'s 82,797 → 36,370 and
 3,128 → 1,463 MB (31,075 / 1,254 MB). What remains there is
 metaclasses: a user class's `Foo_Meta` embeds `Class` and inherits
 ~100 promoted Module/Class/Kernel wrappers (`Constants` ×235,
 `Throw` ×286); the next slice.
- **Proof:** suite unchanged; `method_test`'s
 `bind_call` found the `staticDef` rule, `object_test`'s module
 constraints the ancestor walk, minitest's reporters the ordering
 against decision 86's free-func shortcut.
- *See also decision 308:* a generic struct class's instances dispatch the same way (one class each).
