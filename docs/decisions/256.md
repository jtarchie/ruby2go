# Decision 256

**Gem Hashes that gain another kind of key** (#100; 2026-10-14).
- `h.merge(g)` in gem code where g's keys are another type than h's
 (`options.merge(Sandbox::INHERITANCE_FD => fd)`, an Integer into a
 `**options` Hash of Symbols) converts both sides to Hash[untyped,
 V] (V untyped too when the values differ) and merges those
 (`mixedArrayOp`); it had converted g's keys to h's at run time and
 raised.
- A gem param given a Hash with untyped keys where its type's keys are
 typed widens to that Hash (`widenParam`): the converted copy fit by
 type but failed on another key.
- A def inheriting its parent's signature (decision 36) takes the
 parent's block whole: `Rest`, `Self` and `Untyped` were dropped,
 so concurrent-ruby's ThenPromise#initialize took one value of the
 `(*untyped)` block BlockedTaskPromise takes, and `then_on(pool, a,
 b) { |v, x, y| }` saw x and y nil.
