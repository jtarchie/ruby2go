# Decision 364

**Rule:** MRI's run-time answers where rugaroo refused to compile: a bare `raise` outside a rescue, a block to a method that never yields, main's `public`/`private`, `(a; b)`, `while`/`until` as values, `a, b = obj`, a class variable nothing assigns, `$~ = m`, `Hash.new { v }`, `def x.m` on a fresh `x = C.new`, and Proc literals' `lambda?`/`arity`/`parameters`; plus the core methods #114 listed.

**Third batch of #114** (2026-10-24). *See also decisions 4, 12, 14, 18, 58, 192, 233, 244, 302, 331, 363.*

- **A bare `raise` outside a rescue clause** (19 rejects): what gem code already did (decisions 233, 331) is now every file's. It re-raises `$!`, the exception a calling rescue clause handles, else raises an empty RuntimeError. A rescue clause records `$!` (`rbErrinfoSet`) only in a program with such a raise (`bareRaiseOutside`), so others pay nothing.
- **A block to a method that never yields** (`x.should.raise(E) { |e| }` where mspec's `raise` takes none): MRI ignores it; rugaroo warns "never yields: its block is ignored". A core method's missing block form stays an error (`unusedBlock`), as before.
- **`public` / `private` on main** with no arguments or Symbol arguments are no-ops: top-level defs are already private methods of Object, which rugaroo only calls receiverless.
- **`()` is nil and `(a; b)` is a begin's statements**, its value the last (`genParens`).
- **`while` / `until` as a value** (16 rejects): nil, or what a `break v` passes (`break 1, 2` and `break *xs` are an Array). In value position the loop is `lift`ed like an `if`; a loop frame with a value (`loopValue`) has its breaks assign the tail (or return), and an assigned value starts nil before the loop since a break skips what follows it.
- **`a, b = obj`** of an object with no `to_ary` (12 rejects, `a, b = 1`, `k, v = hash`): obj is the first target alone, nil the rest, `*r` `[]` (`destructureOne`, as a one-element Array). The `testdata/errors` cases for an Integer and a Hash now compile.
- **A class variable nothing assigns** (6 rejects): warns and raises `NameError` ("uninitialized class variable @@x in C") where it is read, as decision 363 does for a constant.
- **`$~ = m`** (7 rejects) sets the frame's last match (decision 171), typed `MatchData?`.
- **`Hash.new { 5 }`**, a default block that takes nothing (13 rejects): its value types V (`paramlessBlockEnv` probes the body), the rest (K) is untyped as an empty container's is (decision 192).
- **`def x.m` on a fresh object** (32 rejects): `lowerSingletonDefs` (parse time) turns `x = C.new(...)` followed in the same statements by `def x.m ... end` into `x = Class.new(C) { def m ... end }.new(...)`, an anonymous class only x has, which rugaroo already compiles; the def's statement becomes its Symbol. Ponytail: x's class is then the anonymous one (`x.class` is not C), and a def on any other object stays unsupported.
- **A reassigned `&block`** (`def ze(&block); block = proc { block }; yield; end`) made `yield` call the new value; such a def now has its own local for the variable (`lowerBlockParamWrites`), so `yield` keeps the block. `proc { }`/`Proc.new { }` for an untyped `^(*untyped)` Proc takes any count, as a proc (not a lambda) does (`isProcLiteral`).
- **`lambda?`, `arity`, `parameters` on a Proc literal** (21 crashes): answered from the literal's parameter list at compile time, without building the closure (`genProcInfo`), so `proc { |x: 1| }.parameters` works though such a block is otherwise unsupported. `optionalBlockParams` records the `|x = 1|` names it makes required (`File.movedOpts`). A Proc held in a variable keeps the type-based answers.
- **Go that did not compile**: `case nil` (a typed temp), `$!` outside a rescue as a T? receiver, a void call where an optional value is wanted (`yield if c` last in a `bool?` method: run, then nil), a void call statement, and a conversion as a statement (`Boolean(...)`).
- **Core methods** (decision 12's `__name_N` forms): `String#tr_s`, `#rindex(str, pos)`, `#upcase`/`#downcase`/`#capitalize`/`#swapcase` with `:ascii`, `:turkic`, `:lithuanian` (and `downcase(:fold)`, as upcase-then-downcase: right for ß, ﬁ, ς); `Regexp.linear_time?` (false with a backreference), `#fixed_encoding?` (with decision 368's flags), `#match(str, pos)` (decision 368 sets `$~`); `MatchData#deconstruct_keys`, `Time#deconstruct_keys` (`Hash[Symbol, untyped]`); `Float#arg`/`angle`/`phase`, also Integer's; `Array#pop(n)`, `#shift(n)`; `Range#last(n)`; `Time.utc`/`gm` with microseconds; `Random.srand` on the class. Not done: `Float#rationalize`; `String#append_as_bytes` and `Array#pack(buffer:)` mutate a String (decision 58); `Exception#initialize` arities.
- **Proof:** `control_output.rb` (main's public/private, parens, loop values, `a, b = 1`, `def x.m`, `case nil`), `control_test.rb` `BareRaiseTest`, `method_test.rb` `ProcInfoTest`, `object_test.rb` `ObjNoCvarTest`, `hash_test.rb` `HashParamlessDefaultTest`, `regexp_extended_test.rb` `LastMatchAssignTest` and `RegexpCoreGapsTest`, `string_test.rb` `StringCoreGapsTest`, `array_test.rb` `ArrayPopShiftNTest`, `range_test.rb` `RangeLastNTest`, `number_test.rb` `FloatArgTest`, `stdlib_test.rb` `TimeRandomCoreGapsTest`; `testdata/errors` cases moved to warnings or removed.
