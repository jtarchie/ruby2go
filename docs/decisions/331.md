# Decision 331

**Rule:** Scope: gem rules liquid needed (latent boot-recorded includes, gem param inference from dynamic calls, override block rules, gem `$!`).

**liquid compiles unmodified, from a traced run** (amends 136, 146, 172, 198, 226, 233, 244, 259, 330; 2026-10-20). Liquid 4.0.4, the version Jekyll 4 pins, renders [example 124](../../examples/124_liquid/main.rb)'s template byte-identical to MRI: `for` with `forloop` and `break`, `if`/`elsif`/`unless`/`case`, `assign`, `capture`, `cycle`, `raw`, `comment`, whitespace control, and twenty standard filters, plus `render!` with `strict_filters`. As with kramdown (330), every fix is a rule for any gem.
- **Run-time includes (boot).** Liquid's Strainer makes its filter classes at run time: `@@global_strainer = Class.new(Strainer) do ... end`, per-render `Class.new(@@global_strainer)`, and `send(:include, filter)` in a class method. The boot hook now records every module an `include` call adds during boot: its class by name, or an anonymous class by its `Class.new` call site, which the hook also records. The compiler adds each as a *latent* include of that class: its methods are compiled in, but `ancestors`, `include?` and `included_modules` (`rbActiveAncestors`) list it only once that class object's own `include` call has run (`Module#include` at run time, `rbIncludeAtRun`, kept in the hidden ivar `@__rb2go_included`). An include boot never saw raises NotImplementedError. Ponytail: a subclass object lists its parent's latent include only once it includes it itself.
- **Anonymous classes in class variables (259).** A class-body `@@x = Class.new(Super) do ... end` is scanned for the literal, and `Class.new(@@x)` names that literal's hidden class as superclass, when `@@x`'s own initializer is the literal.
- **`class << self` and `singleton_class`.** A gem's call with a receiver in a `class << self` body (`Template.default_exception_renderer = lambda ...`) runs where the body loads; `singleton_class.send(:attr_accessor, :x)` is the attr of a `class << self` body, as `alias_method` already was.
- **Parameter inference (146, 244, 330; see also 345, which narrows its gem-parameter rule).** A gem's dynamic call adds its arguments' static types as uses of every gem method of that name (`context.handle_error(e)` on an untyped context passes the StandardError a rescue caught); a parameter only such calls reach stays untyped, and a union such uses leave is untyped (the call may be meant for another class's method of the name). An untyped gem argument widens a parameter typed as a class object or a union (Go holds both as any), and one whose body tests its class (`case obj when Float`, `is_a?`, `respond_to?`) or only converts it (`to_s`, `inspect`, `==`, interpolation). For a gem method's parameter, a user's disagreeing calls also make it untyped (`render!(*args)` with two Hash types). A container use of another class counts as disagreeing even with untyped elements (`Context.new([drop, assigns])` against `environments = {}`).
- **Blocks.** A gem override that never yields, asks `block_given?`, or passes its block to `super` takes no block though its parent does (`Document#parse` calls `super do ... end` over `BlockBody#parse`'s yield); in user code a block-taking override still keeps its parent's signature. Any gem method's tail `yield` is its value (226 required a nested yield too; 247's block `return` lifted the reason). A valueless `break` in a gem block whose call's value is used (`segment.each do ... break ... end` as a `begin`'s value) unwinds to that call, which is then nil. A parameterless block on an untyped `each` (`@input.each { return false }`). A destructured block slot past a pair's end is declared, not `x := nil`.
- **Ivars.** A gem subclass storing another class in its parent's ivar (Raw's String `@body` over Block's BlockBody) makes the ivar untyped, at discovery.
- **`$!` (amends 233).** A gem rescue clause records the exception on its Thread while it runs (only when some gem file has a bare `raise`); a bare `raise` outside a lexical rescue re-raises it, as MRI's `->(e) { raise }` renderer does from inside `handle_error`.
- **Strings (136 stands).** A gem local assigned once from an Array slot (`previous_token = @nodelist.last`) writes a bang edit back to that slot (`previous_token.rstrip!`, liquid's whitespace control); another reference to the String still does not see it.
- **Matching and dispatch.** A `when` with a Regexp-valued constant (`when SINGLE_QUOTED_STRING then $1`) sets `$~` as a literal does, in user code too. `scan` on an untyped value: a String's groups when its pattern has them (`__scan_any`), and the block form `__scan_block`, which the dynamic dispatcher's block twins reach. A computed `send` takes a String name held boxed; `rbSubject` and `rbAs` unbox a `T?` held untyped. `respond_to?(:call)` (and `[]`, `yield`, `===`, `arity`, `to_proc`, `lambda?`) is true for a Proc. A nil key into a Hash whose key type is nilable is looked up (`LITERALS = { nil => nil, ... }`).
- **Nil.** A NilClass-typed value boxed as untyped is nil (a reopened NilClass's `def to_liquid = self` returned a typed nil pointer that `!input` saw as truthy).
- **Prelude.** `Module#protected_instance_methods` (protected methods leave the public table), `Enumerable#reverse_each` and its blockless form, `Set#merge` of a Set with `__merge_array` for an Array (a union parameter naming E kept it from dynamic dispatch), Regexp's `__groups?`.
- **Self calls in a module method** pick decision-12 twins from the including class (`each_slice(2).to_a` and `reverse_each.to_a` in an `include Enumerable` without type arguments emitted an unbound `E`); a blockless `_enum` twin applies only from the method's own owner (Range#reverse_each keeps its own).
- **Codegen hygiene.** A `raise` a folded `unless defined?(X)` guard always takes ends its statement list, as a `return` there did; `*new(any)` is `nil`.
- **Harness.** `Gemfile` gains `liquid ~> 4.0` and `bigdecimal` (a bundled gem since Ruby 3.4, which liquid 4 requires); `sig/liquid.rbs` is the `rbs validate` input.
- **Cost.** TestCompileCost: 64_observable +8 compiled functions, 116_cuba_web +26 (0.1%).
