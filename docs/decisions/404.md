# Decision 404

**Rule:** A program can compile roundhouse's `--target spinel` output unmodified: `$LOADED_FEATURES << File.expand_path("x.rb", __dir__)` marks a file loaded so a shim stands in for it, a `foo.rbs` beside `foo.rb` types it (its `untyped` parameters inferred from use), sig files' `type` aliases resolve, a class method's `-> instance` is the receiver's class at the call, and an override may answer `Sub?` or `Array[Sub]` where its parent's says `Parent?` or `Array[Parent]`.

**Compiling roundhouse's Spinel output** (amends 20, 146, 160, 167, 172, 296, 393; 2026-10-27; #143). *See also decisions 12, 26, 161, 306, 405.* [Roundhouse](https://rubys.github.io/roundhouse/) turns a Rails app into plain Ruby with no metaprogramming plus `.rbs` sidecars, for [Spinel](https://github.com/matz/spinel) to compile to a native binary. That subset is rugaroo's, so example 135 compiles roundhouse's Blog app (`roundhouse --target spinel`, files copied unchanged into `examples/135_roundhouse_blog/blog/`) to one Go binary whose answers to fifteen HTTP requests equal MRI's on the same files. Spinel-only pieces are replaced by shims beside it (its `README.md`); nothing in `blog/` is edited.

- **Standing in for a file.** A top-level `$LOADED_FEATURES << File.expand_path("lit.rb", __dir__)` (or `push`, or `$"`) marks that file loaded at compile time, as MRI's `require_relative` sees it (`loadedFeature`, `collect_decls.go`): the require scan does not walk it and a later `require`/`require_relative` of its real path loads nothing. Any other form is a compile error naming the one that works. The program then requires its shim, which defines what the file did (the Blog's `runtime/tep/tep.rb`, Spinel's FFI HTTP server, and `runtime/db.rb`, sqlite over FFI). The `-trace` load list skips such a feature: an `.rb` that appeared after the hook started without ever being compiled was pushed, not loaded (`trace_hook.rb`).
- **Sidecars.** Each user file the scan reaches loads its sibling `foo.rbs` (`loadSigs`), read leniently as a gem's shipped sig (decision 306), after the `sig/` beside the main file, so a program's own `sig/` overrides a sidecar member by member (decision 160's first-wins merge). A sidecar is a hint, as Spinel's `--rbs` takes it: a method sig from one is `Advisory`, and its `untyped` positional parameters get the pending inference an unannotated def's do (decision 146), typed from the callers, while its typed ones stay declared.
- **Type aliases.** A `type X = T` in a sig file resolves where a name is no class (`sigAlias`, `resolvetype.go`): by its qualified name, the lexical scope, or beside an alias being resolved. A reference to an alias inside its own definition is `untyped`: rugaroo has no recursive types, so roundhouse's `ParamValue = String | Hash[String, ParamValue] | Array[ParamValue]` is `String | Hash[String, untyped] | Array[untyped]`.
- **`instance`.** A class method's sig `-> instance` (or `instance?`) still compiles once, returning the defining class (the old ponytail); a call on a known subclass (`Post.find` of `Model.find`) types the result as that class through a Go type assertion (`instanceResult`). The method builds through `self`'s hooks, which dispatch on the receiver (decision 19), so the assertion holds; one that returned a parent instance would panic, where MRI would carry on with the wrong class.
- **Wider override results.** An override's `-> Sub?` answers its parent's `-> Parent?`, and `-> Array[Sub]` (or a Hash) answers `-> Array[Parent]`: the adapter returns the result, a converted copy for the collection (`widerResult`, as coerce's `rbAs` converts an instantiation, decision 172). A copy is a different object, so a parent call site sees later changes to the override's Array only if it re-reads; roundhouse's `_adapter_all` builds a fresh Array per call.
- **`is_a?` that cannot hold.** `if x.is_a?(C)` (or `unless`) on a local or ivar whose static class can be no `C` does not compile the branch that cannot run (`foldedIsA`, on decision 167's path): typing it fed impossible values into inference, as roundhouse's `deep_dup(v)` under `if v.is_a?(Hash)` widened its parameter to `String`. A branch that always runs keeps its `if`, so the code after it stays reachable for go vet.
- **Equality with `T?` in gem code.** `==`, `!=`, `eql?`, `equal?`, `===`, `<=>` take a `T?` argument as it is in gem code too, not unwrapped to pick a class arm (decision 393's equality rule): `"a" != nil` is true, where the unwrap raised TypeError.
- **`nil_check` along `require_relative`.** A file without its own `# nil_check:` line takes the mode of the file that `require_relative`s it (decision 393 had it from the flag only), so one line in a program's main file covers its own tree; gem files are unchanged (lenient already). In `runtime` mode a defensive `x || default` on a non-nilable `x` is a warning compiling to `x`, as in gem code (decision 172), not decision 20's error.
- **Libraries the run found.** A trace that loaded the `net-http` gem (newer than Ruby's default) maps it to the prelude's `net/http`: a gem named `a-b` is library `a/b`, as RubyGems names them.
- **Library additions the Blog reached.** `OpenSSL::HMAC.digest`/`hexdigest` and `OpenSSL::PKCS5.pbkdf2_hmac` on Go's `crypto/hmac` and `crypto/pbkdf2`, the digest named by a String (decision 281 had RSA verify only). `String#sub`/`gsub(regexp, hash)` replace a match by its value, `""` for a missing key; an overload arm can now be picked by the second argument's class too (`__gsub_regexp_hash`, decision 12).
- **`readpartial` allocates what arrived.** `BasicSocket#readpartial(n)` reads into a pooled 64 KiB scratch buffer and allocates only the bytes it got (`rbReadSome`); it allocated `n` per call, 62 KB of garbage per request in example 135's server, which held its heap high under load.
- **Lint of the generated Go.** `unless x.nil?` on an `rbOpt` is `if x.ok`, not `if !(!x.ok)` (decision 396's rule, in `genIf`'s negation), and a method whose last statement emits no Go drops its trailing `//line` directive, which the whitespace linter read as a blank line.
- **Not covered.** Spinel's FFI DSL is not compiled (`ffi_func` is a program's no-op, its functions written in Ruby by the shim). Action Cable over WebSocket is not served by the Blog's shim yet (its upgrade answers 501). A constant whose elements are of unrelated classes (`Broadcasts::TRANSPORTS`, a seed transport swapped for Cable's) is typed by the example's `sig/`, not inferred (#127).
