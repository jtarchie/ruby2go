# Decision 352

**Rule:** A String the compiler knows is binary (`.b`, `force_encoding` of a literal BINARY, `binread`) calls byte-wise `__bin_*` twins; the flavor is compile-time only and is lost at any boundary it cannot follow.

**Binary-flavored Strings at compile time** (#83; amends 136 and 324; 2026-10-23). *See also decisions 136, 324.* Decision 136 keeps no encoding tag on a String, so `"é".b`, whose bytes are valid UTF-8, read as one character where MRI reads two (`size`, `[]`, `inspect`, `=~` with a byte pattern). A run-time tag stays rejected (a String is a named Go `string`); the compiler carries the flavor instead.
- **Producers.** A prelude method marked `# @binary` returns a binary String: `String#b`, `File.binread`/`IO.binread`, and `force_encoding` whose argument is a literal `"BINARY"`/`"ASCII-8BIT"` (any case) or `Encoding::BINARY`/`Encoding::ASCII_8BIT` (`literalOverload` picks `__force_encoding_binary`). `# @binary self` returns one when its receiver is: `dup`, `+@`, `-@`, `freeze`, `byteslice`, and the String-returning twins below.
- **Flow.** The flag is on the compiled expression (`expr.bin`) and on locals: a local is binary when every write the first passes saw held a binary String (`localInfo.bin`/`text`), and each binary write read from another local stays binary only while that local is (`binDeps`, checked when pass 2 reads it), so a loop that later stores text into the source local turns both back to text. A `case` subject keeps it. It is lost at a method parameter or return, an ivar, an Array/Hash element, a block parameter, and a `String?` receiver: there the String behaves as decision 136 says, and RBS signatures are unchanged.
- **Twins.** A call on a binary String, once overload resolution (decision 12) has picked the method or its `__<name>_<suffix>` twin, takes `__bin_<name>` (`overloadBase` spelling) or `__bin_<name>_<suffix>` when the String class defines it; otherwise the ordinary method runs. Defined: `size`, `length`, `[]` (Integer, `_2`, `_range`), `chars`, `each_char` (block and `_enum`), `ord`, `reverse`, `index`, `rindex` (byte offsets), `encoding` (ASCII-8BIT), `valid_encoding?` (true), `inspect` (`rbDump`'s byte form, `"\xC3\xA9"`), `=~`, `match`, `match?`, `scan` (and `_groups`), `split` (`_regexp`), `sub`/`gsub` (`_regexp`, `_block`), `tr`, `delete`, `count`. `# @binary block` marks a twin whose block's String parameters are binary too (`bin.gsub(/./) { |m| m.ord }`; `genClosure` binds them with `binParams`). A Regexp's `=~`, `match`, `match?` and `===` with a binary argument take the Regexp twins, so `when /re/n` on a binary subject does too. Twin matching reads each byte past ASCII as the character of its value (`rbFindLocBin`, decision 324's Latin-1 view, forced even on valid UTF-8; an all-ASCII subject matches as usual), and `=~` returns a byte index.
- **Cost.** None for programs without binary Strings: the twins are prelude methods the pruner drops when nothing calls them (decision 49). Measured (TestCompileCost, compiled functions): 05_word_count 1,941 → 1,941, 64_observable 7,618 → 7,623, 116_cuba_web 29,766 → 29,781 (the String helpers now call the byte helpers the twins share: `rbStrAt`/`rbStrSub`/`rbStrRange`, `rbTr`, `rbScanLocs`, `rbSplitLocs`, `rbReplaceLocs`).
- **Differs from MRI:** a binary value through a method parameter, ivar or collection reads as text again (a String that is not valid UTF-8 still reads as bytes, decision 324); `MatchData` offsets of a twin match count characters; a mixed local (`s = x.b` then `s = "é"`) is text in all its reads.
- **Proof:** `testdata/test/string_test.rb` (`test_binary_flavor_regexp_matching`, `_characters`, `_scan_sub_split`, `_binread_round_trip`) against MRI; ruby/spec core/string 886 → 889 passing over this decision and the decision 324 amendment.
