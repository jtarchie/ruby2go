# Decision 384

**Rule:** Tuples of one length join field by field when no field needs a new union, and an Array local's refinement keeps widening by what its typed run puts in it, so stacks of tuples are `Array[[A, B]]`.

**Arrays used as stacks of tuples** (#122; amends 193, see also 22, 150, 366; 2026-10-26). `stack << [node, :open]` ... `node, state = stack.pop` ... `stack << [node, :close]` left `stack` `Array[untyped]` and every popped field a dynamic call. The element typing was already there (decision 15's open `[]`, decision 193's seeded literal); three things lost it:
- **A popped field re-pushed.** `pop` is `[Node, Symbol]?`, so its destructured `node` is `Node?`, and the re-pushed `[node, :close]` is `[Node?, Symbol]`. `join` made that and `[Node, Symbol]` a union of two tuples of one Go type, which cannot compile. Two tuples of one length now join field by field (`joinTuples`) when no field becomes a new union; otherwise (`[Integer, String]` with `[String, Integer]`) they stay decision 150's union of tuples.
- **The refined run's evidence was dropped.** In pass 1 the first run sees the stack untyped, so the re-push's fields are untyped and skipped; the refined run then sees `[Node?, Symbol]`, but `refineContainer` only refines a still-untyped container, so the typed try failed and the local fell back to untyped. `emptyRefinements` now re-widens an already refined local by its refined run's typed evidence (`rewiden`). The refinement loop also stops when a round adds only types it already has (a seeded local's same widening re-ran the function up to 8 times).
- **A seeded literal with circular evidence.** `stack = [[n, 0]]` then `stack.push([k - 1, d + 1])` with `k, d` popped: the push is untyped in the first run only because the stack is, and decision 193's `widenContainer` gave up on any untyped evidence. It now skips it, as `refineContainer` does; if the value really is untyped the typed run converts it and `try` rejects the typing, as before.
- **Limit: an unchecked pop into non-optional ivars.** `@tree, @src, @depth = @stack.pop` destructures a `T?` (pop of an empty stack is nil), so each field is possibly nil, and an ivar typed `Node` by its other writes rejects it ("possibly-nil Node? where Node is expected"): the ivar typing of `@stack` is then rejected and it stays `Array[untyped]`, as it was. A destructured Array element is just as optional (decision 7), and widening the targets to `T?` would turn that compile error into silent nil-widening of every such ivar (a representation change for value classes). `top = @stack.pop; @tree, @depth = top if top` types it.
- **kramdown is unchanged** (982 dynamic-call warnings before and after, `gen -trace benchmarks/kramdown.rb`; the generated Go is identical): `Parser::Kramdown#@stack` holds three shapes (`[@tree, @src, @block_ial]`, `[@tree, @text_type]` and, from the included `Html::Parser#parse_raw_html`, a bare `@tree`), is set from `opts[:stack]` of a `Hash[Symbol, untyped]` in `reset_env` and restored from a splatted env Array in `restore_env`, and is popped unchecked into ivars. Typing its `@tree` needs the env save/restore through the Hash typed first.
- **pairing_heap** (`benchmarks/pairing_heap.rb`, the unmodified gem): decision 307's last 5 `rbDyn` sites, `NodeVisitor#visit_node`'s `node = stack.pop` with `stack << node.subheaps` (decision 383's leftover), are typed: 5 → 0 (`TestPairingHeapGemTyped` now wants none). Instructions retired, paired, GOMAXPROCS=1, median of 3: 902M → 888M (-1.5%), output == MRI.
- **Cost:** TestCompileCost compiled functions unchanged (05_word_count 2,014, 64_observable 7,916, 116_cuba_web 30,366).
- **Proof:** `array_test.rb` `ArrayTupleStackTest` (a mixed-tuple stack with a re-push, a seeded Integer-pair stack, a seeded triple stack, an ivar stack popped with a check, against MRI); `TestTupleStackTyped` (rugaroo_test.go: the same shapes compile with no dynamic call; the first three were dynamic before); `TestPairingHeapGemTyped`.

*See also decision 392: an untyped value read back out of storage no longer declares a gem ivar; its typed writes do.*
