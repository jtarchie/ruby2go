**Rule:** The backfilled directories' remaining buckets rest on recorded rules: no run-time method definition in user code (design goal, docs/support.md), decision 179's mock scope, decision 32's untyped-block rule, decisions 21/385's typed containers, and the ruby/spec checkout itself; this file maps each to its evidence.

**Bundled-gem backfill: the evidence for each remaining bucket** (2026-10-30). *See also decisions 21, 32, 179, 385, 416, 421, 422, 423.*

A review found several limits argued from citations rather than from the rule's own text, and one citation (decision 416's "51" for mspec mocks) that names an unrelated decision (StringScanner). Each is grounded here.

- **mspec partial mocks** (net-ftp 53, prime 3): `obj.should_receive(:m)` / `obj.stub!(:m)` on a real object replaces one object's method while the program runs. That is the design goal in docs/design.md ("we don't need to support eval or `define_method` **at runtime**") and the *not supported* row of docs/support.md ("`define_method`, `define_singleton_method` in your own code: methods must be known at compile time", decision 373's tier). A `mock(...)` object is the one exception rugaroo makes, within decision 179's scope: every `should_receive`/`stub!` on it in the same statement list, answering a literal, becomes a class of its own. net-ftp's `closed?` example creates the mock in `before :each` and stubs it in the `it` block, outside that scope, so the mock stays a plain object and the call raises NoMethodError at run time (its 1 error). Decision 416 cited "51" for this; that was wrong.
- **Blocks on untyped receivers** (prime 7, matrix's spec-helper matcher 2, matrix skips): a block passed to a method on an `untyped` value in user code is a compile error. Decision 32's Rule ("blocks cannot cross them") and `testdata/errors/arrays.txtar:193`, `dynamic.txtar:228` pin it; gem code is lenient instead (decision 172).
- **`Matrix.rows(rows, false)` does not alias the caller's rows** (matrix 1): a typed `Array[Integer]` and matrix's `Array[untyped]` are different Go types (decision 21: "containers crossing instantiations are checked copies"; decision 385's Rule: "a converted copy"); aliasing across them would need one representation for every element type, which the typed representation exists to avoid.
- **Wrong argument counts, `break v`, `$_` (`$.` was an unbuilt feature, built by decision 425), Method#call with a block, Bignum, `round(digits ≤ 0)`, `ruby_exe`, IO.select over sockets, a never-assigned ivar**: decision 423's list, each with the decision text or `testdata/errors` cases that state it.
- **pstore, net-smtp, rinda have no ruby/spec directory.** The pinned checkout (`go run ./cmd/rubyspec -print-root`, commit 0816047 of 2026-09-29) has `library/drb`, `library/matrix`, `library/net-ftp` and `library/prime` among the backfilled gems, and no `pstore`, `net-smtp` or `rinda` directory, so there is nothing of theirs to measure.
- **ruby/spec's blockless placeholders** (matrix 10: `scalar` 9, `lup_decomposition` 1): checked against mspec's source (decision 421), not by running mspec under MRI; running the upstream mspec checkout was not permitted in this session.
