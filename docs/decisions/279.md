# Decision 279

**Rule:** Inference keys are typed `pendingKey`s from `paramKey`/`yieldKey`/`selfKey`/`lambdaSrcAt`; resolution order lives once in `Compiler.pendingType`.

**Inference keys are typed** (#101; amends 146, 164, 180, 183; 2026-10-14).
- `pendingKey` names a parameter typed from use (decision 146): an
 unannotated def parameter, a yielded value, a lambda parameter or an
 escaped block's self (decision 164). Its text,
 `file:line:col:[Owner#]name`, is printed by `RB2GO_INFER_DEBUG` and
 appears in warnings, so each kind has exactly one constructor:
 `paramKey`, `yieldKey`, `selfKey`, and `lambdaSrcAt(...).arg(i)` for
 lambdas. The inference, uses and pendingSeen maps and the `Param`,
 `BlockSig` and `TFunc` fields use it instead of `string`.
- The resolution order lives once, in `Compiler.pendingType`: the last
 round's type, else untyped during a round, else the `needInfer`
 abort, else untyped for a gem (decision 169), else the caller's
 outcome. `resolvePending` (decision 183 warning), `lambdaParams`
 (decision 180 warning) and `blockSelf` (decision 164 error) differ
 only in what they do when the outcome is `pendNone`.
- No behaviour change: `gen` output and `RB2GO_INFER_DEBUG` output are
 byte-identical on 731 inputs.
