# Decision 205

**Rule:** A gem method, constant or load-time statement that fails to compile is poisoned (`NotImplementedError`, `nil`, skipped) with a warning.

**Poisoning in gem code** (amends 172). *See also decision 330*. A gem method whose body
does not compile becomes `raise NotImplementedError` naming why, a
constant that does not compile stays `nil`, and a gem file's
load-time statement that does not compile is skipped, each with a
warning; the rest of the program still builds.
`RB2GO_KEEP_GOING=1` reports every such error in one run.
*See also decision 293:* a block to a prelude method that takes none is a compile error in gem code too. *See also 301* (a failed attempt leaves no declared locals behind). *See also 303* (a method Go rejects is stubbed in the Go text, without a second compile).
