# Decision 407

**Rule:** A Struct's `==`, `eql?` and `hash` stop at a pair or object already in progress on the same goroutine, as MRI's `rb_exec_recursive_paired` and `_outer` do, so a struct that holds itself answers instead of overflowing the Go stack, and a struct whose members cannot lead back to it compiles to the same code as before.

**Recursive structs** (2026-10-29). *See also decisions 382, 403.*

`x = Car.new(...); x[:make] = x` is valid Ruby, and ruby/spec's `core/struct` compares and hashes such structs. The generated `==` compared members with `==` and `eql?` went through `to_h.eql?`, so the comparison recursed until the stack overflowed (a fatal error no `rescue` sees).

- **Only where a cycle can form.** The generator (`valueclass.go`) knows each member's type. A member typed `Integer`, `Float`, `String`, `Symbol`, `bool` or `nil` (or the optional of one) cannot hold a struct, so a struct whose members are all such keeps the plain `==`, `eql?` and `hash` byte for byte: no guard, no cost. Any other member (`untyped`, a class, a container) makes the struct's `==` compare that member through `StructEq.same(a, b)`, and its `eql?` and `hash` take the guard below.
- **`StructEq.same`** (`prelude/struct.rb`, `rbRecSame` in `prelude/go/recursion.go`) compares same-typed integers and symbols directly and sends the rest through `rbEq`; anything that is not a scalar is bracketed by `rbRecEnter(0, a, b)` / `rbRecLeave`. A pair already in progress answers `true` ("equal so far"), so a difference anywhere in the cycle still makes the whole comparison false and two structurally equal cycles are equal.
- **The guard costs a counter until a cycle is likely.** Each goroutine keeps a depth (in its `rbGoTag`, or a plain variable for main); a comparison nested no deeper than `rbRecShallow` (8) only bumps it, and only past that does it list the pairs in progress (one slice while no goroutine but main runs Ruby, a `sync.Map` keyed by goroutine id otherwise, as `rbFindActive`, decision 66). A cycle always reaches the list.
- **`hash`** is `Struct.__hash_rec(self) { to_h.hash }`: reaching `self` again unwinds with a sentinel panic to the outermost `hash` on the goroutine, which returns one constant, so `car.hash == similar_car.hash` when `car.eql?(similar_car)`, as MRI's.
- **Only Struct.** Data is immutable and cannot hold itself; its generated methods are unchanged.
- **Measured** (20M `==` calls on a two-member struct, against the commit before): typed members, 0.01 s and 0.01 s (unchanged); untyped members holding integers, 0.22 s against 0.46 s (faster, from the direct integer compare); 600k struct-keyed Hash operations on untyped members, 0.33 s against 0.32 s. `TestCompileCost`: 05_word_count and 64_observable unchanged, 116_cuba_web +45 functions.
- **Zero-argument `String#concat`** (decision 382): it appends nothing and returns the receiver, so it compiles to the local itself and the append proof treats it as a read.
- **Proof:** `ObjectRecursiveStructTest` in `testdata/test/object_test.rb`; `StringAppendTest#test_concat_without_arguments_returns_self`; ruby/spec `core/struct` 69 to 72 passing with the three crashes gone.
