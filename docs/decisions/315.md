# Decision 315

**Rule:** RBS parses `A & B` (the first class operand types it), single-quoted strings, backquoted names and named proc parameters.

**Intersection types, single-quoted strings, backquoted and proc parameter names in RBS** (amends 306, 12, 150; 2026-10-18). Decision 306 left 12 of the 220 installed gems' `sig/` files unparsable, so each was skipped whole: prism 1.7-1.9's `node.rbs` and `parse_result.rbs` (`type node = Node & _Node`), rbs 4.2's `rdoc_annotater.rbs` (`Array[Object & _WithRDocComment]`), `collection/config.rbs`, `config/lockfile.rbs`, `sources.rbs` (`{ 'type' => 'git', ..., }`), `type_alias_dependency.rbs` (``(Types::t `type`, ...)``) and webrick 1.9.2's `httprequest.rbs` (`^(String body_chunk) -> void`).
- **Grammar** (ruby/rbs `docs/syntax.md`, `src/util/rbs_unescape.c`): `A & B` is `rbs.Intersection`, binding tighter than `|` and looser than `?` (`A | B & C?` is `A | (B & (C?))`); it prints with parentheses where nested in a union, intersection or optional, as a union does. `'...'` is a string literal whose only escapes are `\'` and `\\`; the tokenizer rewrites it as the double-quoted token of the same text, so literal types (decision 12) and record keys take it unchanged. A backquoted name (`` `type` ``, any text but a backquote) is a parameter name and prints backquoted unless it is a plain identifier. A proc type's parameter may carry a name, which is documentation and dropped (`rbs.Proc` holds types only). A record's trailing comma already parsed.
- **Compiler mapping of `A & B`** (`resolveIntersection`). A value of the intersection is a value of every operand, so any one operand types it soundly; Go has no type that is a struct and an interface at once, and an RBS interface (`_Node`, a name whose last segment starts with `_`) names no class in rb2go (one alone resolves as an unknown name: untyped in gem code, an error in user code). So: the first operand that resolves to a class wins (`Node & _Node` is `Node`, `Object & _WithRDocComment` is `Object`); else the first typed one (a module: `Comparable & _Each` is `Comparable`); interfaces are skipped while any other operand remains; when every operand is an interface the first resolves as one alone does. Rejected: untyped for every intersection (against minimize-untyped: prism's `node` is a real class), and a Go interface built from the interface's methods (the closed world never declares RBS interfaces as types; one would be the first such machinery for a gem-only form). The interface's extra methods are not checked on the class: a call the class lacks is what decision 205 already handles in gem code.
- **Census** (`rbs.ParseFile` over `/opt/homebrew/lib/ruby/gems/4.0.0/gems/*/sig/**/*.rbs`): 220 files, 12 unparsable before, 0 after.
- **Measured:** TestCompileCost unchanged (05_word_count 1,339, 64_observable 27,087, 116_cuba_web 28,239 compiled funcs).
- **Proof:** `internal/rbs` `TestParseTypeShapes` (intersections, precedence, single quotes and their escapes, a record's trailing comma, a named proc parameter), `TestParseMethodTypeParams` (backquoted names), `TestParseTypeErrors`, fuzz seeds; `internal/compiler` `TestResolveIntersection`; `testdata/boot/sigdemo/sig/sigdemo.rbs` (`Meter & _Reading`, a `'single-quoted'` record with a `'meter'` literal, ``Meter & _Reading `other` ``, a named proc parameter, in type aliases and method sigs), whose types `TestBootAutoload` checks in main.go and whose output equals MRI.
