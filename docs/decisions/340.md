# Decision 340

**Rule:** A generic `<=>` calls the free `cmpNil`; `Set#<=>` and multi-arg `Set#merge` exist; a `deconstruct` Struct member is what patterns call.

**`<=>` on a generic class, Set#<=>/merge, and a Struct member named like the pattern protocol** (#109 follow-ups; amends 12, 336; 2026-10-23). *See also decisions 12, 336.*
- **`<=>` on a generic class compiles.** `emitCmpAdapter` (the `Op_cmp(Self) Integer` Comparable slot) called `self.cmpNil(x)`, a Go method the pruner drops for a generic receiver: a generic forwarder survives only when some interface declares its name (`isGenericForwarder`), and none declares `cmpNil`. A generic receiver now calls the free func (`Set_cmpNil[E](self, x)`). A non-generic receiver is unchanged. This unblocked `Set#<=>` (nil for a non-Set, 0, -1 proper subset, 1 proper superset, nil otherwise); `Set#<=>` is a Go body (`Set_Size`/`Set_SubsetQ` on the `_ToAny` views): in Ruby, its `size`/`superset?` selectors keep those names on every class (the pruner matches selectors unscoped) and grew every program with a dynamic `<=>` by ~1,000 lines. It still adds Set to each dynamic `<=>` dispatcher (+33 lines). `Set#merge` takes MRI's `merge(*enums)` through twins: `merge(Set)`, `__merge_array`, `__merge_range` stay typed, `__merge_0` and `__merge_2` to `__merge_4` take untyped arguments through `__merge_any` (`rbEnumElems`; it pulls `Range#to_a`, so only a program that merges several enumerables pays); five or more arguments are a compile error.
- **A Struct/Data member named `deconstruct` or `deconstruct_keys` is the accessor MRI calls.** The pattern shortcut that reads members directly (decision 143) is skipped for such a class: an array pattern calls the member, so `Struct.new(:deconstruct).new([7, 8])` matches `in [x, y]`. A hash pattern over a `deconstruct_keys` member is a compile error (the accessor takes no argument; MRI raises ArgumentError at run time).
- **Not done: a name past the end of a typed block rest is nil.** `two { |a, b| }` over `{ (*Integer) -> void }` that yields once binds `b` to 0, MRI nil (decision 263's note). Fixing it makes every such name `T?`, which forces nil checks on every user of a variadic block. Left as is.
