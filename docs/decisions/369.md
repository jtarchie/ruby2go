# Decision 369

**Rule:** A destructuring block parameter that nests or splats is a fresh name destructured by a multiple assignment; keyword parameters of a call's block take their defaults when the method yields no keywords (else a compile error); a `|a = nil|` default is no statement; an untyped lone value splats across a lowered parameter list.

**Seventh batch of #114** (2026-10-24; "keep going" on the open list). *See also decisions 222, 241, 364, 367.*

- **Nested destructuring parameters** (`|a, (b, (c, d))|`, `|a, ((b, c), d)|`, `|(a, *b, c), d|`, `|a, (*), b|`): blockParamList takes one level of plain names. `lowerNestedParams` (parse time) names such a parameter `__rugaroo_dN` and starts the body with `(b, (c, d)) = __rugaroo_dN`, the multiple assignment that already destructures nested, splatted and nil values as MRI's; a bare `(*)` target marks its temp used.
- **Keyword parameters in a block list** (`|a, **k|`, `|a, b: :b|`, `|a, b = 5, *c, d, e: 2, **k|`, `|a = nil, **b|`). MRI fills them only from keywords a yield passes explicitly, never from a yielded Hash (and a lone Array still does not splat over one positional name), so where the method yields none they are their defaults. `lowerBlockKeywords` makes them prologue assignments (an optional one its default, `**k` `{}`, a required one MRI's ArgumentError "missing keyword") for a block given to a call; the call is a compile error when its method's body yields keywords (`yieldsKeywords`). Not covered: Proc literals (`proc`/`lambda`/`Proc.new`, whose calls may pass keywords), `|&b|`.
- **`|a = nil|`** (`optionalBlockParams`): a nil default assigned what is already nil was a type error on a typed parameter (`nil where Array[...] is expected`); it is no statement now.
- **A lowered list over an untyped lone value** (decision 367's `__rugaroo_args`): it splats when the value is an Array (`rbAutoSplat`), as the typed path does.
- **An `Array?` destructured** (`a, b = xs` or a nested `(b, c)` target, as `block_spec`'s `|a, (b, (c, d))|` over a missing value): nil destructures as an empty Array, every target nil, rest `[]` (`optArrayOrEmpty`); decision 222's `T?` of a tuple is unchanged, and `control.txtar`'s `multi_optional_array` (which pinned the error) is removed.
- **Proof:** `method_test.rb` `NestedBlockParamsTest`, `control_test.rb` `OptArrayDestructureTest`.
