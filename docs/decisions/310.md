# Decision 310

**An open generic `X.new` is typed by later calls** (#104 phase 3; amends 308, 182; 2026-10-18). `q = MinQ.new` binds nothing (initialize takes no `E` or `P`), which decision 308 rejected. Like decision 182's empty `Hash.new`, it is now an open literal when assigned to an unannotated local (`openTemplate`: an `X.new` of a template whose arguments' parameters do not mention every type parameter).
- **Evidence.** Pass 1 types the local as the template at `untyped` arguments (no instance is made: genNew returns a placeholder of that type), and each later call on it (`noteTemplateArgs`) unifies its positional arguments with the method's parameters: `q.push("a", 1)` against `push(E, P)` records `E = String`, `P = Integer`. Pass 2 builds the instance of the joined evidence (`refineTemplate`), so `X.new` takes it as its expected type. Typed evidence joins as a parameter's uses do (decision 146): `h.push(:x, 1.5); h.push(7, 0.5)` is `Heap[Integer | Symbol, Float]`; untyped evidence counts for nothing.
- **No evidence** keeps decision 308's "cannot infer type parameter E of Heap.new" in user code. In gem code the parameter is `untyped` (the erased instance) with a gem warning, as a gem's empty container is (decision 192).
- **Not yet:** an open `X.new` assigned to an ivar (decision 182's `refineIvars` path) or passed straight to a call; keyword and block arguments as evidence.
- **Proof:** `generic_class_test.rb` `test_open_new_typed_by_later_calls`; `generics.txtar` `new_unbound` (no evidence).
