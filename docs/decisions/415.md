# Decision 415

**Rule:** English.rb's names for the punctuation globals are always known (`$ERROR_INFO`, `$MATCH`, `$FS`, ...); `` $` ``, `$'`, `$+`, `$@`, `$>`, `$<` and `$*` read as MRI's, and `$;`, `$,` and `$\` are variables that `String#split`, `Array#join` and `print` default to; `$.` and `$_` stay unsupported.

**Bundled-gem backfill, fifth batch: English** (2026-10-30). *See also decisions 61, 171, 180, 361, 414.*

`library/English` went from 6 to 22 of 27 passing. English is MRI's `alias $ERROR_INFO $!` list; rugaroo had a fixed subset of it (Homebrew's `$CHILD_STATUS`, decision 361's era).

- **The names.** `englishGlobals` maps each English name to the global it aliases; `$MATCH`, `$PREMATCH`, `$POSTMATCH`, `$LAST_PAREN_MATCH` are the back-references (`englishMatchRefs`) and count as reading the frame's last match (decision 171). Like the subset before, they need no `require "English"`: no program that runs on MRI names `$ERROR_INFO` without it.
- **Targets that were missing.** `` $` `` and `$'` are the last match's pre/post text and `$+` its highest-numbered group that matched (`rbLMPre`, `rbLMPost`, `rbLMLast`); `$@` is the handled exception's backtrace, nil outside a rescue as `$!` is; `$>` is `$stdout`, `$<` ARGF, `$*` ARGV.
- **A rescue that reads `$!` or `$@`** captures its frames as `rescue => e` does (decision 106), and `x rescue $!` sees the exception (the modifier counts as a rescue, so a bare `raise` there re-raises it and a new exception takes it as cause).
- **Separators.** `$;`, `$,` and `$\` are `rbFS`, `rbOFS`, `rbORS` (nil unless the program sets them), as `$/` is `rbRS` (decision 180): `split` without a pattern uses `$;`, `join` defaults to `$, || ""`, and Kernel's, IO's and StringIO's `print` write `$,` between arguments and `$\` after them. Storing them without these would have turned a compile error into a silent difference.
- **Limits:** `$.` and `$_` (`$NR`, `$INPUT_LINE_NUMBER`, `$LAST_READ_LINE`): rugaroo's `gets` keeps no last line or count. `alias_spec`'s `(1 / 0 rescue $ERROR_INFO).backtrace` calls a method on an `Exception | Integer` union, which user code must narrow first (decision 150).
- **Proof:** `testdata/test/globals_test.rb`'s `EnglishTest`; `library/English`.
