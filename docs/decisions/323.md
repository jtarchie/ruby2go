# Decision 323

**Rule:** Scope: gem shapes and prelude additions (spawn options, `File.fnmatch`, FileUtils, Pathname) that made macOS `brew install wget` match MRI.

*See also decision 414 (matrix's backfill), which amends this for gem code.*

**Compiled `brew install wget` on macOS equals MRI's** (#100; amends 172, 193, 205, 301; 2026-10-19). `overrides/brew/macgen build` then `macrun`: through a symlink `/opt/homebrew/bin/brew-rugaroo` (bin/brew takes the prefix from the link's directory and the repository from its target, so the patched copy pours into the real Cellar, whose bottles are pinned to `/opt/homebrew`), stdout, stderr and the exit status each equal MRI's for the same state; only the interleaving of the two streams differs (MRI's download threads). Gem-code shapes on the way: *See also decision 325* (this run never parsed a Mach-O file).
- an `attr_writer`-only ivar is `T?` (it holds nil until the writer runs: `@sandbox_inheritance = T.let(nil, ...)`);
- a gem's non-empty Hash literal local widens with later `h[k] = v` writes, as decision 193 does for Arrays (`widenHashSeed`);
- an empty literal branch joins the other branch's container type in gem code (`untypedContainerJoin`);
- a super bridge into a parent of another shape passes the parent's missing optional parameters as zero values and drops a value the override's type cannot hold (`reshapedBridge`, ObserverPathnameExtension#mkpath over Pathname#mkpath(mode:));
- `|_, (token, _)|` binds nothing for the blanks (Go's `_ := x` did not compile);
- a block call on a value held as Go `any` (a Sorbet `T::Enumerable[X]`) goes through the view, and a concrete value converts at run time where a method type parameter is wanted.
- Prelude: `Process.spawn` reads a trailing options Hash, Integer keys as descriptors (`ExtraFiles`), and redirects a `File`; `Pathname#find` runs its block inside `catch(:prune)` so `Find.prune` leaves the block (it is a closure, not a loop body); `File.fnmatch` (MRI's `fnmatch_helper`: PATHNAME, DOTMATCH, CASEFOLD, NOESCAPE, EXTGLOB) and `File::FNM_*`; `File.absolute_path`, `File.ctime`, `File.world_writable?`; `FileUtils` `rm_r`, `mkdir`, `rmdir`, `mkpath`, symbolic `chmod`/`chmod_R`, `chown`/`chown_R`, `ln`, `install`, `compare_file`/`identical?`/`cmp`, `uptodate?`, `remove_entry`, `pwd`; `Pathname#chown`, `fnmatch?`, `ctime`, `each_child`, `descend`, `world_writable?`, glob with a block; `Tempfile.new(name, dir)`/`Tempfile.open`, `binmode`; `Etc.getgrnam`/`getgrgid`; `Thread#report_on_exception`; `Array#sort!` with a block; `JSON.pretty_generate(obj, nil)`; `Errno::ELOOP`.
- Brew patches 0025-0028: exec3's options as spawn's trailing Hash, `RUBY_PATH` from `HOMEBREW_RUBY_PATH` (the compiled program is not a Ruby), and Pathname subclasses for `ObserverPathnameExtension`, `InstallRenamed` and `MachOShim` instead of per-object `extend`.
- Third-party tap formulae installed from source (`.brew/<name>.rb`) cannot be read by a compiled brew (decision 301's string eval): `Upgrade.dependants` skips them as unreadable. The Linux container still stops at ELF relocation (bindata, decision 301).
- Proof: `stdlib_test.rb` (`test_fnmatch`, `test_pathname_find_prune`, `test_pathname_walk_helpers`, `test_tempfile_open_in_dir`, `test_report_on_exception_false`), `fileutils_test.rb` (`test_install_path_methods`), `process_test.rb` (`test_spawn_trailing_options_with_fd`), `control_test.rb` (`test_blank_params_in_nested_tuple`), `array_test.rb` (`test_sort_bang_with_block`), `json_test.rb`, `testdata/boot` (`spawn_opts`, `observed_mkpath`).

*See also decision 374:* a run-time `instance_eval(string)` the trace saw (a tap's cask) compiles at its call site.
