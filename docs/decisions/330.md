# Decision 330

**Rule:** Scope: gem rules kramdown needed (boot-recorded computed aliases, gem param inference, String edit write-backs, ivars by name); `# trace:` examples.

**kramdown compiles unmodified, from a traced run** (amends 146, 172, 198, 205, 244; 2026-10-20). *See also decision 331*. The first non-Homebrew gem through `-trace` (decision 296): kramdown 2.5.2 with its rexml dependency, Markdown to HTML and back to kramdown, byte-identical to MRI on a document with nested lists, a blockquote, fenced and indented code, a table, a definition list, footnotes, inline HTML, entities, smart quotes and typographic symbols. None of the fixes names kramdown; each is a rule for any gem.
- **Boot hook.** `const_classes`, `safe_name`, `literal` and `sorbet_structs` call `Module#name` unbound (`MOD_NAME.bind_call`): `REXML::Functions` defines its own `name`, which crashed the dump.
- **Harness.** An example with a `# trace: why` line is compiled by `testExample` with `CompileTrace` (one run, no arguments; ponytail: pass `# args:` when a traced example needs them). `sig/kramdown.rbs` is the `rbs validate` input. The generated-code lint runs misspell on comments only (`mode: restricted`): a string literal is the program's data (kramdown's entity names `andd`, `infintie`).
- **REXML constants.** rb2go's REXML is its own (decision 114), so the real gem's files are not compiled. `rexml/xmltokens` and `rexml/parsers/baseparser` map to `prelude/rexml_tokens.rb`: rexml 3.4.4's name and reference patterns as literals (a constant built from a class-body local reads empty).
- **Boot-recorded definitions.** `alias_method` with a computed name in a load-time loop (`%w[b strong i].each { |i| alias_method("convert_#{i}".to_sym, :convert_em) }`) is recorded by the boot hook (owner, new name, the alias's `original_name`, call site) and declared at collect; the run-time call is a no-op, as decision 198's `define_method` is. `send(:define_method, ...)`/`__send__`/`public_send` is a boot `define_method` site too (`singleton_class.send(:define_method, name) do |data| ... end`). Ponytail: a computed alias on a singleton class stays a NoMethodError.
- **Parameter inference (146, 244).** A gem's `Array`/`Hash` of untyped passed to a parameter types it only when no other call passes another class or a gem's untyped value; otherwise the parameter is untyped (`Options.define(name, type, default, desc)` gets `{}`, `""`, `2`, `true`). A gem parameter its body only interpolates (`"<#{name}>"`) is untyped once a gem passes it an untyped value (`el.type`, a Symbol, where literals passed Strings). A gem's non-empty Hash literal default (`opts = {indent: 0}`) is recorded as `Hash[K, untyped]`.
- **Literals into untyped slots.** In gem code a non-empty Array or Hash literal where untyped is expected holds untyped elements (values for a Hash), so a later `map!` to Symbols or an Element stored in an options bag fits; `rbConv` still hands a typed reader its instantiation.
- **Ivars across a hierarchy.** A gem class reading an ivar no ancestor declares, which a subclass has (itself or from a module it includes), reads it by name (`rbIvarGet`), nil on an object without it: `Parser::Base#add_text(text, tree = @tree)` with `@tree` held by `Html::Parser`, which `Parser::Kramdown` includes. An untyped value assigned to a gem ivar of a value type (Symbol, String, Integer) makes it nilable (`@tree, @text_type = @stack.pop`, which pops nil).
- **String edits (amends 172, 233; decision 136 stands).** A gem's bang method or `<<` on an untyped local, ivar or attribute checks for a String at run time and rebinds it, else calls as before; when the String arm cannot compile (`@tree.children << el`) it raises NoMethodError if taken. New targets: an attribute `r.name` with a `name=` writer (`item.value.sub!(...)`, including an untyped receiver when some class has the pair), an Array slot `r.last`/`r.first`/`r[i]` (`item.value.last << result` writes `item.value[-1]`), with r a local, ivar, self, or an attribute or `first`/`last` chain of one. `x&.sub!(...)` on a local skips a nil x. Appends onto a String nothing else holds (an operator's or interpolation's result: `' ' * indent << "<" << tag`) are the concatenation. Another reference to the edited String does not see the edit (decision 136).
- **Dispatch.** A gem's call whose first argument is untyped, of a method with by-class twins (`sub`/`__sub_regexp`), goes through the dispatcher, which picks the twin at run time; the dispatcher's wide twins (`__split_regexp(re, limit = 0)` for `split(sep = nil)`) now apply to a base with optional parameters. A dynamic call that brings a block reaches the class's `__<name>_block` twin (`value.gsub(re) { ... }` on an untyped String). A Proc held untyped answers `[]`, `yield` and `===` as `call`. `x !~ re` on a nil (typed `T?` or untyped) is true, as Kernel#!~.
- **Smaller gaps.** `self.class::CONST` in a gem is `self.class.const_get(:CONST)`, and a literal `const_get(:X)` keeps every constant named X from the pruner. `Hash#default_proc=` (an untyped Proc or another Hash's). `StringScanner#[]` by group name (IndexError for an unknown one) and `StringScanner#initialize`, which a subclass's `super(string)` reaches. `Array#slice!(range)` (ponytail: the index and start-length forms). Onigmo's POSIX-named properties `\p{Word}`, `\p{Alpha}`, `\P{Upper}`, `\p{^Word}`, in and out of classes. A gem's `h[k]`/`h.key?(k)` with a `K?` key into a nil-free `K` is a miss on nil. A gem's `x = lambda { ... x.call ... }` declares x first, untyped. A probe now restores the Ruby block nesting a caught compile error left open (it made a later method-level `return` look non-local and a block-local shadow its method-level namesake).
- **User code too.** `yieldValueUsed` (decision 183) passes value position down: `found = (block_given? ? yield : true)` uses the block's value, where it compiled the block as void and the program did not build. A `while`'s break test cancels a negation instead of emitting `!(!(c))`, and a Proc call on a just-boxed func is the func (`(*(&f))`), which staticcheck rejected.
