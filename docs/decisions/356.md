# Decision 356

**Rule:** When ivar discovery cannot compile an if/unless/while/until/case/begin statement, it still dry-runs each branch body in its own scope, so the ivar writes inside them type the ivar.

**Discovery reads into the branches of a statement it cannot compile** (amends 191; 2026-10-23). *See also decisions 148, 183, 191.* spinel's `bm_splay.rb` (copied unmodified to `benchmarks/splay.rb`) compiled with every tree operation untyped: 5 `rbDyn` dispatchers and 35 dynamic-call warnings, all rooted in "instance variable @root is only ever nil, so it is untyped" (decision 183). `SplayTree#initialize` sets `@root = nil`; the only other writes sit in `insert`'s `if empty_p ... @root = SplayNode.new(key, value) else ... @root = node end`. Discovery (decision 191) skips a statement it cannot compile, and this one fails at its condition: `empty_p`'s return inference reads `@root`, which nothing has typed yet. The whole `if` was skipped, writes and all.
- **How** (`discoverNested`, `gen.go`). In discovery, a failing statement of those kinds has each branch body (then/else and elsif chains, `when` arms and `else`, loop bodies, `begin`'s body, rescue clauses, `else` and `ensure`) dry-run on its own, each in a fresh block scope, skipping what does not compile inside as before. The last statement of a body, which decision 191 left to fail with its body, is tried the same way and its error re-raised. Each statement is expanded once per discovery body (`nestedDone`): an enclosing failure re-runs its descendants, which would otherwise double per nesting level.
- **Branch facts are lost.** The branch runs without the condition's narrowing, so a write there sees the unnarrowed type (`if @x.nil? ... else @y = @x end` would type `@y` `T?`). Discovery's types only declare ivars; the emitting pass still checks every write against them.
- **nil-initialized attributes** need nothing new: an unannotated `attr_accessor` is a def whose parameter is inferred (decisions 172, 307), so SplayNode's `@left = nil` with `node.left = @root` writes is `SplayNode?` once a round types the writer.
- **splay** with decision 357: 0 `rbDyn`, 0 dynamic-call warnings, output equal to MRI. `RUNS=5 scripts/benchmark splay`: MRI 0.211 s, rb2go 0.059 s (3.6x).
- **Proof:** `testdata/test/infer_test.rb` `RecTest#test_nil_initialized_tree_links` (`RecTree#add`'s `if empty_p` first write; `RecLeaf`'s `@nxt = nil` written only through its writer), `TestSpinelBenchmarksTyped`.
