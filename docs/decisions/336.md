# Decision 336

**Rule:** Scope: correctness refactor: pinned eval order, lazy `when`, variadic block binding, Struct members beat helpers, ruby/spec runner fixes.

**Phase 1 of the second deep refactor: correctness** (#109; amends 3, 98, 137, 242, 272; 2026-10-21). *See also decisions 3, 98, 137, 242, 272, 340, 341.* Every fix began as a test that failed on the old code and was compared with MRI.
- **Evaluation order (amends 98, 242).** Hash literal keys, values and `**` splats are pinned like array elements (`pinExprs`), so a later pair that hoists statements no longer runs before an earlier one; a Proc `f << g` evaluates the receiver first; `ENV.fetch(k, d)` evaluates a non-literal `d` into a temporary after the key, as MRI does whether or not the key exists (literal defaults are used in place; the block form is still a compile error).
- **Lazy `when`.** A `when` condition that needs statements (a ternary, a modifier `if`, `||`) ran even when an earlier arm matched. An arm with pre-statements now sits in the previous switch's `default:`; a local first assigned in a later `when` is still declared before the `case`.
- **Block parameters over a variadic signature.** `|a, b|` over `(Integer, *String)` binds `b` to the first rest element, as MRI; only `*name` gets the Array. Fewer names than leading parameters bind what exist (it was an index panic, decision 263). A `(x, y)` destructuring over the rest is a located compile error. A name past the end of a typed rest binds the zero value, as `bindFromRest` does (a `T?` would force nil checks on every user; revisit if wanted).
- **Names (amends 3).** `goMethodName` reads the first rune, so `ça` and `éa` no longer both become `Cap__FFFD__FFFD_a`. The widened fuzz alphabet found two more collisions, left as known: `a_1` and `a1` both become `A1` (the prelude's `__fill_2`-style names depend on the mapping), and `ı`, `ſ` upper-case to ASCII `I`, `S`. (Fixed in decision 339.) Emitted code no longer names the `math` or `os` packages or the `min` builtin (`rbNegZero`, `rbPid`, `rbMinInt` in prelude/go/shadow.go; the 64-bit clamps are literals), so a Ruby local called `math`, `os` or `min` builds. `goKeywords` is unchanged: prelude `%x{}` bodies bind parameter names through it.
- **Struct and Data.** A member named like a generated helper wins, as in MRI (`Struct.new(:size).new(5).size` is 5). Generated code calls `__` twins that are always emitted (`__members`, `__to_h`, `__inspect`, `__to_a`, `__pp_members`), so members called `to_a`, `to_h`, `inspect` and the like keep every other method working. Helpers skipped when a member has the name: `members`, `to_h`, `hash`, `inspect`, `to_s`, `deconstruct`, `deconstruct_keys` (both), and for Struct `to_a`, `values`, `size`, `length`, `each`, `each_pair`, `values_at`, `dig`, `select`, `filter`. A Struct with a member `each` or `to_a` loses `include Enumerable` (its Self interface calls both; MRI keeps it but calls the accessor). Anonymous classes and Structs (and `class X < Struct.new(:a)`) are declared hidden (`declareHidden`), so `constants` no longer lists `RbAnon...`. `coerceArg`'s discarded check runs in a `probe`; before, a `T | untyped` parameter given a tuple evaluated the argument twice.
- **Compile errors instead of internal errors.** `include Foo #[A] | nil`, `class X < Base #[A] | nil`, and `URI.open`/`#open`/`#read` without `require "open-uri"` are located errors. `requireScan.walk` restores `top`, so a `require` resolved inside a method no longer turns a later computed `require` into an error; `emitRequireTable` uses `within`; `requireRelative` checks its argument count first.
- **Gem code (lenient).** A closure that writes a parameter with `+=`, `||=`, `&&=`, a multiple assignment or `for` counts as capturing it. A module reading `@v` shares the field a superclass writes with `@v ||= ...`, `&&=` or `@v, @w = ...` (`ivarNodeName`). Two files with `END {}` at one byte offset get distinct guards (`rbEnd<file>_<offset>`).
- **RBS (amends 264, 315).** `private def` / `public def` / `private attr_*` members are kept (visibility is not recorded). Comment stripping and bracket depth are quote-aware, so `-> "#"` parses; an unclosed bracket costs O(lines), not O(lines squared); the `?` wraps of one type are bounded in total by `maxDepth`, so a type with more than 200 `?` is rejected.
- **Boot (amends 262).** The manifest is dumped only by the process that installed the hook (a forked child no longer overwrites it). The hook module is `Rb2goBoot` (a program's own `Boot` no longer clashes), requires `json` at dump time with the stdlib directories first on `$LOAD_PATH`, and scrubs Strings to UTF-8. A run that wrote no manifest (`exit!`) reports that and its stderr. The trace reader checks the scanner error and caps `loaded.txt`; a timeout is reported only when the run failed. The process-group kill stays deferred.
- **Runtime.** `Marshal` nesting is capped at 100000 for dump and load alike (measured about 2.6 KB per level; MRI itself raises `SystemStackError` near 25k for objects), so what dumps loads. NUM2INT is one `rbNum2Int` ("too small" for negatives, as MRI); `comparison of X with Y failed` is one `rbCmpErr`. `sleep` of more than about 9.2e9 seconds clamps instead of overflowing. `rbEncDefault*`, `rbMtTraceDepth` and the Open3 waiter's status are atomic or `sync.Once` (no mutex). Fiddle unlocks its OS thread with `defer`. `Array#reverse_each` stops when the block shrinks the array. The key index drops an emptied bucket.
- **Prelude.** `Tempfile` is a `DelegateClass(File)` (so `write; rewind; read` works) with `close(unlink_now)`, `close!`, `open`, `size`. `Dir.mkdir(path, mode)`, `Pathname#mkdir`/`mkpath` and `FileUtils.mkdir`/`mkdir_p`/`mkpath` honour `mode:` (umask applies); `FileUtils` methods that MRI gives `noop:`, `verbose:` or `preserve:` take them, and verbose output goes to `$stdout` as in fileutils 1.8. `String#rindex`/`rpartition` with a Regexp match with the whole string as context (`rbRindexLoc`), so `"ab".rindex(/\bb/)` is nil and a long string is no longer quadratic. `Set#&` follows the argument's order as MRI.
- **ruby/spec runner (amends 127, 272).** `expand` walks nested directories: one target per directory that directly holds specs (`core/array` and `core/array/pack`), so the published totals grow (core 1,855 to about 2,151 spec files, library 715 to about 1,517); re-measured 2026-10-23: `core` 21,731 examples with 8,561 passing (82.1% of those that ran) and `library` 5,307 with 1,102 passing (81.7%). `core/array/pack` and `core/string/unpack` (3,177 examples) first read as 347 passing because the runner left mspec's `@method` unset for the specs' `pack_format`/`unpack_format` helpers; it now also sets `@method`/`@object` in a hook when the shared spec's argument is a String or Symbol literal (any other expression, such as a lambda calling a private method, would fail to compile for every example of its group; found as a 7-example `library/stringio` regression), and they pass 2,543 (#110); `library/etc` and `library/erb/defmethod` still stop on a syntax error in the program the runner builds. A program that keeps crashing is FATAL; a panic or Ctrl-C removes its temp module (exit 130); an edit that overlaps a rewrite is an error, not a silent drop; `-timeout` under 1 ms is rejected; `scripts/rubyspec-coverage` reads the pinned checkout through `rubyspec -print-root`. A cache at another commit still only warns (272).
- **Checkers.** `TestDesignIndex` (index rows, highest decision and `CLAUDE.md`'s "last: N" agree, and a numbering gap is an error), `TestVendoredMirror` (both directions, walk errors fatal) and `TestVendoredEmbedded` (disk against the embed) fail when they check nothing. `scripts/vendor-gems` exits 1 on an uninitialised submodule, where it used to delete `vendored/*`.
- **Left.** `a_1`/`a1` and `ı`/`ſ` collisions; `Set#<=>` (the generated forwarder calls a missing `cmpNil`; a compiler fix) and a multi-argument `Set#merge`; `File.delete` of a directory (MRI raises `EPERM`); FileUtils return values (MRI returns the list); `Runnable#assertions` is not thread-safe; the binary-String audit; Net::HTTP per-read timeouts.
