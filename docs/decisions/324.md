# Decision 324

**Rule:** Gem run-time Ruby (computed singleton methods, per-object `extend`, class-defining string evals) compiles ahead of time from boot records.

**Run-time Ruby that bindata, elftools and patchelf need, compiled ahead of time** (#100; amends 35, 136, 172, 198, 204, 230, 301; 2026-10-19). *See also decision 326* (Fiddle calls work; the in-method LoadError is gone). Linux `brew install` relocates bottles with patchelf, which reads and writes ELF through bindata's DSL. The gems run unmodified except one gem patch (below); every construct is compiled at build time, with no run-time method table or eval (decisions 198, 204). *See also decision 325*.
- **Per-object singleton methods.** A gem's receiverless `define_singleton_method(name_expr) { |params| body }` with a computed name (bindata's `Struct#define_field_accessors_for(name, index)`) compiles the block once as `__rb2go_sm_N(captures..., params)`; the call records `[N, name.to_s, captures...]` on the object (`@__rb2go_sm`, a new Array per record so a `clone` shares nothing it later changes), and the class gets `method_missing`/`respond_to_missing?` that find the latest record by name. A literal name on any receiver (`parser.define_singleton_method(:parse_and_append_field)`, bindata's `:big_and_little`) adds the same record and a check at the top of each class's own def of that name. Class objects keep decision 198's boot defs.
- **Per-object `extend M`.** A gem instance method's `extend M` sets `@__rb2go_ext_K`; each def of M is copied into the class whose def an object would otherwise run, its `super` calling a renamed copy of that original, and the original def starts with the flag check (bindata's `Choice` `CopyOnChangePlugin`, `BasePrimitive`'s value plugins).
- **instance_eval of a dynamic block.** A class-body DSL block passed to `method_missing`, to a dynamic call, or to a gem method's untyped `&block` when it does not compile on its lexical self, takes its self at call time: `instance_eval(&blk)`/`instance_exec` of an untyped block pass `rbSelfArg{obj}` first (bindata's `struct :e_ident do ... end`).
- **String evals that define classes** (`BinData::Int.define_class`): the call site switches on the built source over what boot recorded (`genEvalSwitch`); a site whose sources only define methods stays a no-op. Their classes exist only once the eval ran (`rbEvalConst`, `const_missing` hook).
- **64 bits.** In gem code a run-time `Integer#<<` past 64 bits wraps (Go's shift, mod 2**64), `unpack` of an unsigned value past 2**63 keeps its 64 bits, and a boot eval's source has each decimal literal past int64 rewritten mod 2**64 (`wrapBigLiterals`), so `"val &= #{(1 << nbits) - 1}"` equals what boot recorded and means Go's 64-bit arithmetic. Literal-only arithmetic (`(1 << 64) - 1`) folds exactly and saturates to the Integer range (`clamp(0, max)` stays valid). **Differs from MRI:** these values print as their int64 bits, not Bignums (decision 35).
- **Binary Strings.** A String that is not valid UTF-8 is ASCII-8BIT (decision 136), so its `length`, `[]`, `[i, n]`, `[range]`, `ljust`/`rjust` count bytes; they counted runes, turning invalid bytes into U+FFFD (patchelf's section data); so do `chars`, `each_char`, `reverse` and `tr`/`delete` (2026-10-23, #83).
- **Strings stay values** (decision 136). A gem's `s[range] = v` / `s[i, n] = v` on a local rebinds it, as `<<` does; an untyped local is checked at run time and a non-String takes `[]=` as before. An edit through an alias (patchelf's `new_dynstr = replace_section(...)`, also held in `@replaced_sections`) is lost, so `overrides/brew/gem-patches/patchelf-1.7.0.patch` writes the edited String back (two lines; no change under MRI); `in-container.sh` applies `gem-patches/<gem>-<version>.patch` to the vendored gem.
- **Typing.** An untyped argument to an overridden gem method or a gem `initialize` makes the parameter untyped (`paramUse.widen`; `obj.assign(value)` on a `Base`, `RawIO.new(io)` of a File); a gem `super`'s arguments type none of the target's parameters. A gem module's ivar its includer's class assigns is read and written by name (elftools' `Dynamic` reading `Segment`'s `@offset_from_vma`). `instance_variable_set("@tl_#{sym}")` declares one untyped ivar per literal its self-callers pass. A gem's `@x ||= v` on a non-nil-typed object ivar checks for nil. `klass.new(*args, **kw)` over subclasses whose `new` take other keywords dispatches at run time. Gem sigs `sig/gems/bindata`, `sig/gems/patchelf`.
- **Smaller shapes.** Untyped `each` with 3+ block parameters splats; a blockless untyped `each` is an Enumerator; untyped `zip`; `send(*args, &blk)`; `refine X do ... end` reopens X and `using` is a no-op (patchelf's StringIO#fill); a gem module's own `loop do ... end`; `to_enum(__method__, ...)` in a private method; Integer arithmetic with an object answering `coerce`, and implicit `to_int`/`to_str` of an object through its `method_missing` (`rbImplicitConv`); a dynamic Hash lookup with a key of another class misses; a `method_missing` that `class_eval`s a String def to memoize is left to answer each time; `Range` converts between instantiations. Prelude: `StringIO#binmode`, `File#pos=`, `Object#clone` (frozen kept), `Module#autoload?` (nil), `ObjectSpace.define_finalizer` (records nothing; ponytail: run at exit), `Integer#step` without a limit (`__step_0`, which an iterator call with no arguments now picks, decision 12), `Array.new(n)`, `Errno::ESPIPE`.
- Go-rejection stubs (decision 205) are written after the prune, so a gem compile keeps `NewNotImplementedError`.
- **Proof:** `testdata/boot` `DemoObjDyn` (computed and literal singleton methods, `extend` with `super`, a class-body DSL block instance_eval'd, computed ivar names, `||=`, 64-bit masks, String edits and binary slicing, `coerce`/`to_int` through `method_missing`, `refine`).
- **Linux `brew install wget` equals MRI's** in the container (`TARGETS=/w/install-targets.txt ./gen && ./build && TARGETS=/w/install-targets.txt ./check`): the same 79 lines and exit 0, apart from two differences. MRI's "Landlock ABI 10 or later is required…" warning is "Sandbox unavailable: processing downloaded files without sandboxing!" here, and the ✔︎ lines of the parallel downloads come in another order. `check` now keeps both outputs (`work/mri-*.txt`, `work/rb-*.txt`) for an order-free comparison.
- **No Landlock sandbox.** brew probes Landlock through Fiddle's `syscall(2)` and runs extraction and relocation in a forked child that applies it; without cgo nothing can be called through Fiddle, and a Go program cannot fork and keep running Go code. A `require "fiddle"` inside a method raises LoadError, which brew takes as `:missing_fiddle` and runs unsandboxed (Fiddle's constants still load for top-level users). Fiddle over purego (#32) plus a fork-free sandbox child is the follow-up.
- **What the sandbox child had run now runs in the brew process**, so a traced compile also takes each loaded gem file's literal `require` of the same gem's file inside a `def` (patchelf's `require 'patchelf/alt_saver'` in Patcher#save), and everything such an added file requires (`addGemOwnRequires`). Engine-specific load-time requires (concurrent-ruby's TruffleRuby backend) stay out.
- **Gem patches:** `bindata-3.0.0.patch` counts read bytes with `bytesize` (MRI's `read(n)` is ASCII-8BIT; a short binary read that happens to be valid UTF-8 counted characters here and raised "data truncated"). Brew patch 0029: the download queue printed a download that finished between its two passes twice when not on a TTY; MRI's GVL hid the race, goroutines in parallel did not.
- **More shapes:** a block's `return false` in a gem method carries the method's Boolean, not Go's untyped `false` (`Utils::Output.claim_warning`); a binary Regexp (`/n`, now kept in its options and `inspect`) matches a String that is not valid UTF-8 byte by byte, Latin-1 decoded so `/\xFD7zXZ\x00/n` matches the byte 0xFD (`UnpackStrategy::Xz.can_extract?`), offsets mapped back, for `scan`, `sub`/`gsub`, `split` and `start_with?` too (`rbFindAll`; 2026-10-23, #83); any other Regexp still raises MRI's ArgumentError on it; `"#{self}"` whose `to_s` dispatches at run time is a String; `::Regexp.last_match(n)`; `Regexp.escape(Symbol)`; `FileUtils.mv`/`rm` options; `File.readlines(path, chomp:)`; `n.times do ... end` as a value is an Integer; Integer folding applies only to the arithmetic call itself (case's `when 0` handed its `===` the literal and lost the subject); an `if` whose branches are a typed and an untyped Array literal takes the typed one only when it is more specific (`cond ? [x.soname, x.needed] : [nil, []]`); a gem's `[]=` on an untyped local is a String edit only for an Integer or Range index and a String value; `Array#include?` of a value of another class compares `elem == obj` (`[SHT_SYMTAB, SHT_DYNSYM].include?(shdr.sh_type)` of a bindata Uint32, which answers through its own `==`), and `rbEq` honours a gem's `==` returning untyped; a gem module's ivar is read by name only when every including class assigns it.
- **Differs from MRI:** patchelf sorts sections and program headers with `sort!` on offsets that tie (`.bss`/`.comment`, `PT_TLS`); MRI's unstable quicksort and Go's sort order ties differently, so a relocated file is a valid ELF (the same program headers, dynamic section and symbols, each symbol's section index consistent with its own table) but not always byte-identical to MRI's: 20 of the 151 ELF files in wget's 12 bottles are.
- `RB2GO_GO_STACK=1` (via `HOMEBREW_RB2GO_GO_STACK` under brew) adds the Go stack to a Go runtime panic turned into a Ruby exception.
