# Decision 194

**Rule:** `Enumerable#to_h` reads `[k, v]` pairs into `Hash[untyped, untyped]`; unannotated `**opts` is `Hash[Symbol, untyped]`.

`Enumerable#to_h` and unannotated `**opts` (#49). `to_h` reads each
element as a `[key, value]` pair (a tuple or Array, through `rbAs`;
MRI's "wrong array length" ArgumentError otherwise) into a
`Hash[untyped, untyped]`; it did not exist. An unannotated `**opts`
is `Hash[Symbol, untyped]`, as decision 183 makes an unannotated
parameter `untyped`; it was an error. mspec: `mock_to_path(path)` for
a computed path (an object whose `to_path` answers it, which decision
191's `to_path` conversion takes) and `should.binmode?`.
**Proof:** `infer_test.rb` `test_enumerable_to_h_and_unannotated_kwrest`.
