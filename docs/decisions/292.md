# Decision 292

**Rule:** A large upstream program lives in `overrides/<name>/`: pinned Dockerfile, upstream-shaped `patches/`, MRI `expected/`; patches beat directives.

**`overrides/<program>/`: compiling a pinned upstream program from the repo** (#100; 2026-10-16). Each large
upstream Ruby program rb2go compiles lives under `overrides/<name>/`, with the brew harness as the first:
a Dockerfile pinning the upstream commit, a `git apply` series (`patches/`) of upstream-shaped changes that
replace dynamic features with ordinary typed Ruby and leave MRI's output unchanged (`./mricheck` proves it),
traced entries (`entries/<cmd>.rb`, decision 197), the launcher's environment, and the MRI output each command
must match (`expected/`). Patches, not compiler directives, are the default fix for a construct only that
program uses; the remaining `rb2go_replace` overlays are to be replaced by patches. Not run by `go test`: one
round needs Docker and ~10 GB.
