# Decision 203

**Rule:** `B = A`, or a constant boot saw holding a class, names the same class object; `Thread::` names are the top-level prelude classes.

**Class aliases.** `B = A` names the same class object; so does a
constant whose value boot saw be a class named otherwise (`Impl =
case ... end`, private constants included). `Thread::Mutex` and the
other `Thread::` names are the top-level prelude classes.
