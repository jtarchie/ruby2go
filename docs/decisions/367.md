# Decision 367

**Rule:** A block whose parameters mix optionals, a rest and trailing names binds them MRI's way from one rest (`lowerProcArgs`); `(a, b) = x` of a non-Array `T?` binds x to the first; `defined?` of an assignment is "assignment" and of an Array literal nil when an element is undefined; `Float#rationalize` is MRI's simplest rational.

**Fifth batch of #114** (2026-10-24). *See also decisions 12, 302, 364.*

- **Proc argument split** (the "unsupported block parameter form" rejects of `block_spec`/`proc_spec`: `|a, b = 5, c = 6, d, e|`, `|a, *b, c|`, `|*a, b|`). At parse time such a block's list becomes the single rest `__rb2go_args` with a prologue that assigns each name MRI's way: the leading names first, then the optionals while values remain beyond the trailing names (`Array#__bopts`), the rest (`__brest`), the trailing names (`__bpost`), nil past the end. A lone yielded Array splats across the names, as MRI's proc does (`bindRestParams`). Proc#parameters reads the original list (`File.procArgsOrig`). Synthesized integer literals have no source text, so `genInteger` takes a zero-length literal's `Value`. Not covered: keyword parameters, `&b` and destructuring in such a list, and lambdas (strict arity).
- **Nested destructuring of a `T?`** (`(a, b), c = x, 3` with an Integer?): x is the first target alone, nil or not, as decision 364's `destructureOne` for a non-optional value.
- **`defined?`**: of a global, class-variable, constant, index or attribute assignment or op-assignment, "assignment" (not run, as MRI); of an Array literal, nil when an element is undefined, else "expression".
- **`Float#rationalize`**, with no argument the simplest rational within half an ulp (MRI's `rb_flt_rationalize`, exact on `big.Rat`), with eps the simplest in `[f-|eps|, f+|eps|]`, walked on Floats as `rb_flt_rationalize_with_prec` does; infinity and NaN raise FloatDomainError.
- **Proof:** `method_test.rb` `ProcArgSplitTest`, `control_test.rb` `NestedOptDestructureTest`, `number_test.rb` `FloatRationalizeTest`.
