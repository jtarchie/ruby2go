# Decision 253

**Rule:** A private method a subclass overrides dispatches on self (`staticPrivate`); inference keys include the owner; `alias_method :[], :new` works.

**concurrent-ruby's executors and Promises: private dispatch, template keys, alias of new, shadowed Kernel methods** (#100; 2026-10-14). *See also decision 297* (a module's includers count as overriders), *298* (initialize through an interface).
Driven by compiling Homebrew's vendored concurrent-ruby directly (a
FixedThreadPool, `future_on`, `then_on`, an Event): a one-minute loop
instead of a brew round.
- A private method a subclass overrides dispatches on self, as MRI's
 (`staticPrivate`). It had been called directly, the base's method
 always: a silent miscompile in user code too (`private def hook`
 overridden by a subclass). An override of such a method (private or
 not) answers its slot.
- Parameter inference keys add the method's owner: the defs one
 `class_eval` template makes in several classes share a source
 position (attr_atomic's accessors), and one class's argument types
 had typed every class's.
- `singleton_class.send(:alias_method, :[], :new)` /
 `singleton_class.alias_method` in a class body is a class-method
 alias. An alias of the synthesized `new` is a class method passing
 initialize's required parameters to new, untyped, so nil and any
 value pass as in MRI.
- Gem code:
 - A class method's `new(...)` on self, where a subclass defines its
   own initialize, builds the class self is at run time
   (`inheritedSelfNew`).
 - A call that resolves to a prelude Kernel/Object method on a struct
   class some subclass defines the name on (concurrent-ruby's Event
   `alias then chain` over Kernel#then) dispatches at run time.
 - An untyped argument into a rest parameter makes its elements
   untyped (`paramUse.anyRest`).
 - `x.nil?` on a struct-class value checks it at run time
   (`lenientObject`), as such a value may hold an untyped nil.
 - The vendored signature `sig/gems/concurrent-ruby` types
   `MutexAtomicReference`'s value, compare-and-set and update as
   untyped (one class holds every attr_atomic field's values), and
   `Concurrent.monotonic_time` as Float.
- Runtime: `rbAsSlow` converts nil to an object (interface) type as
 nil, where it raised TypeError. MRI never type-checks an object
 argument; a call on the nil raises there.
- Prelude: `Process.clock_gettime(id, unit)` (MRI's units, untyped
 result), and `ConditionVariable#wait(mutex, timeout)` with a nil or
 Integer timeout.
- A value-type class answering `to_path` (Pathname) where a path
 String is taken converts through to_path (implicitConv), as MRI's
 path parameters do.
- Brew harness: the entry requires `concurrent/options`, an autoload
 boot never triggers.
- Not yet: the Promises chain past a worker's run_task (a nil into a
 Float in Logging#log), so `brew info`'s download queue does not
 finish yet.
