# Decision 272

**Rule:** MRI oracle caches only runs MRI finished, keyed by source and env; the CLI cancels cleanly on SIGINT/SIGTERM; playground children get a scrubbed env.

**Harness and process-boundary hardening** (#101; amends 88, 102, 127; 2026-10-14). *See also decision 336.*
- MRI oracle cache: key = Ruby description, TZ, checkout,
 sha256(Gemfile.lock), args, sources (prefix v5). It stores only runs
 MRI itself finished (exit >= 0, no `LoadError` / "cannot load such
 file" in stderr: those reflect the machine and would replay
 forever). Writes go to a temp file in the cache dir, then
 `os.Rename`. Suites fail on an empty glob (`mustGlob`). `TestMulti`
 requires MRI exit 0.
- Signals: `rugaroo build|run|test` installs one SIGINT/SIGTERM
 cancelled context before compiling; the compile is abandoned on
 cancel, `go build` gets SIGINT, the temp module is always removed,
 and the exit status is 128+signal on every path. `run` and `test`
 share `runProg` (forwarding signals to the child).
- Playground `/run` (decision 102 stays single-user, no semaphore):
 the child's environment is only PATH, HOME=<its temp dir>,
 TMPDIR=<its temp dir>, so submitted code cannot read the developer's
 tokens. A handler panic becomes a 200 JSON error (web.html turns a
 non-OK response into raw text).
- `cmd/rubyspec`: one panicking program is that program's FATAL
 result; any FATAL program makes the exit status 1; the ruby/spec
 cache is fetched at the pinned `specCommit` (0816047, 2026-10-14)
 into `<dir>.tmp`, then renamed; a cache at another commit warns.
 `scripts/rubyspec-coverage` still clones unpinned HEAD.
- The generated module pins regexp2 once (`regexp2Version`);
 `TestGoModMatchesRepo` ties it to go.mod and checks GoSum is
 non-empty.
