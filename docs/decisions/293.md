# Decision 293

**Rule:** Scope: brew batch 19: `defined?` guards that return end a method, run-time optional switches, gem blocks to blockless prelude methods error.

**Brew batch 19: more `info` targets; absent-constant guards end a method; run-time optional switches;
blocks a core method lacks** (#100; amends 167, 205, 245; 2026-10-16). `overrides/brew/check` now compares
`brew info` for wget, jq, git, python@3.13 and `--json=v2 wget` with MRI in one container; the first four match.
- `return unless defined?(C)` (or an if/else whose taken branch returns) for a constant no file defines always
 returns, so the statements after it, which name C, are not compiled (decision 167 dropped only the guarded
 branch). Brew patch 0008 guards `Utils::Backtrace` with it: compiled brew has no RubyGems.
- A switch whose kind is read at run time (an untyped block, decision 245) with `OPTIONAL_ARGUMENT` and no
 placeholder yields true when the argument is left out, as MRI does; only a placed `" [V]"` argument takes
 the next word (`"=[V]"`, `"[=V]"` and the bare constant do not); and the untyped block gets the String, not
 the `String?` box the typed `_opt` overloads take (`brew info --json=v2` failed "no implicit conversion of
 String into Boolean | String").
- In gem code a block passed to a prelude method that takes none is a compile error, as in user code: MRI's
 method uses it, so dropping it (decision 205's rule for gem methods that never yield) gave a different answer
 (`related.uniq(&:full_name)` deduplicated by identity). `Array#uniq { }` added.
- `[a, b, *xs]` where xs's element type is not the literal's (`Formula` into `Formula?`) appends element by
 element through the element conversion instead of converting the Array as a whole.
- `T.cast(x, [A, B])` converts: from untyped or an Array (`xs.partition { }`) through rbAs (decision 22), from a
 wider tuple element by element,
 a narrowing element checked at run time as from untyped (it was passed through unconverted, so a multiple
 assignment of it read tuple fields off `any`: Homebrew's `named_formulae, named_casks = T.cast(...)`).
- `x&.m` on a union holding nil (`@url&.to_s` of `String | URL | nil`) is nil for nil; it called `m` on nil,
 so a formula without a head spec had `url == ""` and printed `HEAD`.
- An if/case in value position types its branches with the expected type as a hint (`tail.hint`), so a branch
 literal takes it as it would alone: `T.let(if a then [c ? [] : xs, ys] else ... end, [A, B])` was
 `[Array[untyped], B] | [A, B]`. The hint only steers literals; the value's type is still the branches' join.
- A hoisted gem local (other than `_`) is marked used (`_ = x`): a when arm that does not compile (decision 244) may have been its
 only reader, and Go then rejected the whole method.
- `Pathname#read` takes `File.read`'s options; `Array#fetch(i, default)`.
- Brew patches 0007 (`pour_bottle?` presets call PourBottleCheck directly, no `instance_exec` of a lambda that
 `T.bind`s self) and 0009 (`info --json=v2` builds its pair without reusing the targets as scratch locals).
- Proof: `control_test.rb` (`test_defined_guard_return`), `stdlib_test.rb` (`test_runtime_optional_argument`,
 Pathname#read), `array_test.rb` (uniq block, splat into `T?`, fetch default), `sorbet_test.rb`
 (`test_cast_tuple`), `union_test.rb` (`test_safe_navigation_on_nil_union`).
