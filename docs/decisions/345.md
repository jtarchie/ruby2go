# Decision 345

**pairing_heap's links are static again** (amends 307, 331, 308; 2026-10-23). *See also decisions 307, 331.* `benchmarks/pairing_heap.rb` had 45 `rbDyn` calls where decision 307 left 5 (`git bisect` on example 120: first bad 23d7151, decision 331), and ran at 15x a hand-written Go port's instructions. Two causes, both general:
- **A bare untyped use is no kind.** Decision 331 made a gem method's own parameter count uses that hold untyped in `gemUsesDisagree` (liquid's `render!(*args)` with two Hash types). That also counted a bare untyped argument, which in an inference round is a value not yet typed (`meld(left, right)` from `merge_pairs`, whose locals are untyped until `meld` is): its join with `Node` is untyped, so the parameter was untyped every round and the fixpoint 307 relies on never started. Only a container with untyped elements counts now; a bare `untyped` (or `untyped?`) use counts for nothing, as in `joinUses`.
- **A generic subclass's instance is discovered after its parent's.** `cloneTemplate` appended an instance to `classList` before `linkSuperInst` created its superclass's, so `MinPriorityQueue[Integer, Integer]` came before `PairingHeap[Integer, Integer]`. Ivar discovery then ran the subclass's copy of `change_priority` (the `decrease_key` alias, owned by the subclass, decision 309) first: its `@root = meld(node, @root)` declared `@root` on the subclass while `meld`'s return was still unknown (untyped), and the parent's `@root = nil` moved that untyped ivar up (decision 182). An instance is now appended after its superclass's, the order MRI defines them in, so the parent's `push` declares `@root` first.
- **Guard:** `TestPairingHeapGemTyped` compiles the benchmark against the installed gem and allows at most 5 `rbDyn` call sites; each fix alone fails it. `TestNilLinksTyped` had kept passing: it has neither a gem file nor a generic subclass.
- Measured: pairing_heap 4,340M to 2,135M instructions (hand Go: 295M). What is left is 307's "Left" list: a `Node?` link is `*NodeI`, so each link write boxes an interface (`Ref`).
