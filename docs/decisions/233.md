# Decision 233

**Homebrew's subprocess layer and more gem leniency** (amends 4, 6,
97, 107, 146, 172, 183). `SystemCommand#exec3`/`each_line_from` run
every child (curl for the API data) through `Process.spawn(env,
[exe, exe], *args, in:, out:, err:)`, `Process.detach`, `IO.select`
and `ReadlineNonblock`'s `read_nonblock(n, @buffer)`.
- **`Process.spawn`'s general form**: an env Hash (nil unsets),
 `[program, argv0]`, and `in:`/`out:`/`err:` (an IO, a path, :close),
 `chdir:`, `pgroup:`, `unsetenv_others:` (`rbSpawnFull`, reached as
 `__spawn_hash`/`__spawn_array` by the first argument's class;
 decision 12's class overloads now allow a rest parameter).
 `Process.detach` is a Thread whose value is the Process::Status.
 `Kernel#fork` raises NotImplementedError where reached (Homebrew
 forks only when spawn fails); `Thread.handle_interrupt` yields.
- **`IO.select`, `read_nonblock`, `readpartial`** on Go's poller: a
 pipe's read deadline (a millisecond's grace, since a deadline already
 past hides an EOF) and `bufio.Reader.Peek`, which tests readability
 without consuming. `IO::WaitReadable`/`EAGAINWaitReadable` move from
 socket.rb to core. `IO#winsize` (TIOCGWINSZ; Errno::ENOTTY,
 ENODEV), `Time#to_r`, `Etc.uname` (from uname(1)).
- **String mutation in gem code** (decision 172's rebinding) reaches
 ivars too, `concat` (several arguments), `slice!(range)`, and an
 out-buffer argument: `io.read_nonblock(n, buf)` rebinds buf to what
 was read. MRI's aliasing (an Array holding the buffer sees later
 fills) is not reproduced: Strings stay immutable.
- **Signatures**: an unannotated `initialize` returns void; a gem
 def that does not yield takes the block an override below it yields
 (`AbstractLockableObject#synchronize`), with that override's answer
 to whether the block's value is used; a gem def whose body ends in
 `raise` (abstract) returns untyped, so overrides inheriting its
 signature keep their values.
- **Gem leniency**: a local assigned two unjoinable types is untyped;
 nil where a Boolean is kept is false (MRI's value is nil, which
 `p` would show); a T? or another union into a union converts at run
 time; a tuple destructured into another count of targets, or
 yielded to another count of block params, gives the first fields,
 then nil; `raise x` and `raise klass, msg` with x or klass untyped
 (or a union) decide at run time (`rbRaiseValue`), and a bare `raise`
 outside a rescue is an empty RuntimeError; an iterator call's value
 is the receiver for `each_line`/`each_char`/`each_byte`/`times` too,
 and nil for others (`loop`).
- **Proof:** `stdlib_test.rb` `StdlibSpawnTest`, `testdata/boot`
 (`Demo::Counter`, `Demo::Lenient`).
- **Amended (2026-10-13, ruby/spec `core/enumerable`):** the
 inherited block applies only to an override of the parent's
 parameter shape (`sameParamShape`), and `iterAdapterBody` passes
 nothing for a rest parameter the slot lacks (`EachCounter#each(*arg)`
 answering `Numerous#each`) instead of indexing it; any other extra
 parameter is a compile error, not a crash. The adapter yields the
 slot's element type (`iter.Seq[Integer]` for a parent whose `each`
 yields Integers, converting the override's elements with `rbAs`),
 not always `any` (ruby/spec `core/range`).
- **Also found (2026-10-13):** decision 202's inherited call on a
 subclass of a non-generic `@go_type` class (`Thread`, `Time`)
 emitted the free function (`Thread_Name(&self.super_Thread_)`), which
 only generic bases have; it is the base's Go method now
 (`containerCallCode`, `isDirectMethod`; ruby/spec `core/thread` and
 `core/marshal`, broken since eaf6397). A `Thread` subclass's `join`
 waited forever: decision 239.
