# Decision 321

**Rule:** A gem return `T.any(U, String)` with `U` bound only by a block is `String` at a blockless call; a `type_member`'s `upper:` types reads like `fixed:`.

**A gem method's `U | String` return is `String` at a call without the block that binds `U`; a `type_member`'s upper bound types its reads** (amends 150, 172, 196; 2026-10-19). Sorbet's block-or-value idiom, `.returns(T.any(T.type_parameter(:U), String))` with `U` bound only by an optional block (Homebrew's `Utils.popen_read`, 78 of brew's dynamic-call roots), resolved to untyped as a whole: decision 150 admits no type variable in a union, and decision 172 makes that untyped in gem code. The declaration stays untyped (its body and Go shape are unchanged; a first attempt that kept the variable in the union leaked `U` into the union conversion helper, a free function), but the method remembers the members (`Method.retUnion`, `varUnion`), and a call that passes no block drops the members only the block could bind (`dropVars` over the block signature's free variables) and converts the untyped result where it lands, as decision 225 does: `popen_read(cmd).chomp` is a `String` call. A call with a block keeps the declared untyped result. `type_member { { upper: T } }` resolves to `T` as `fixed:` does (Homebrew's `Cacheable`: `cache.key?` is a typed Hash call; the elements stay untyped by its bound).
- **Measured:** brew `info wget`: dynamic-call warnings 2,002 → 1,795 (`popen_read` 78 → 0, `Cacheable#cache` 86 → 0), stubs 140 → 139, functions 59,850; output equals MRI.
- **Proof:** `testdata/boot` `DemoRead` (with and without the block) and `DemoCacheable`/`DemoCached`.
