# Decision 288

**Rule:** Traced mode is the CLI's `-main` flag (built by `-trace`, 296); no magic comments: `rugaroo_main`, `rugaroo_fold`, `rugaroo_replace` and kin are gone.

**Traced mode is the CLI's `-main`; `rugaroo_main`, `rugaroo_method_requires` and `rugaroo_fold` are gone** (#100;
amends 197, 246; 2026-10-15). *See also decision 296* (`-trace`: no entry file).
- Magic comments in the compiled program made rugaroo a dialect: the source said how to compile it. Decision
 197's entry (the requires MRI loaded) is now a plain Ruby file that MRI can run too, and `rugaroo gen|build|run
 -main brew.rb entry.rb` names the program it boots into. `-main` is traced mode, which always resolves a
 require inside a method at run time (decision 246): the two comments only ever appeared together.
 `compiler.CompileTraced` / `rugaroo.CompileTraced` are the API.
- `rugaroo_fold` (build-time facts, `OS.mac? => false`) is removed. Measured on `brew info wget`: dropping its
 four OS/engine facts added 114 functions (0.16%) and no method that fails to compile, since brew's macOS
 code is in files a Linux trace never loads; `ENV["HOMEBREW_SPAWN_SYSTEM"] == "1"` is now an environment
 variable brew reads at run time (its own spawn mode), and the fork branch compiles.
- `rugaroo_replace` remains until the brew patch series replaces its two shims (`standalone/init.rb`,
 `standalone/sorbet.rb`). *Removed by decision 297: brew's boot files compile as they are.*
- Proof: `TestTracedEntry` (testdata/traced, no magic comments).
