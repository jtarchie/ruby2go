# Decision 283

**An assignment narrows a union local** (#100; amends 150, 241; 2026-10-15). Gem code is to stay typed where
*See also decision 318*.
the program is (the 2026-10-15 review of Homebrew's untyped values: `RB2GO_UNTYPED_WHY` names each dynamic
receiver's root).
- `x = v` into a local or parameter typed as a union, with `v` of one class that fits it, leaves `x` that class
 until its next write or the end of the scope: one Go assertion (`t := x.(Pathname)`) at the assignment, and
 reads of `x` use `t`. Before, `src = Pathname(src)` with `src: String | Pathname` kept the union, so
 `src.dirname` failed on the String member: an error in user code, a dynamic call (and the parameter widened
 to untyped, decision 241) in gem code.
- A later write of the same class updates the view's variable as well as the local (`x = x.dirname / ...`
 inside an `if` keeps `x` a Pathname after it); another class drops the view, as any other narrowing.
- Not when a block or lambda in the method writes the local: its write would not reach the view.
- `FileUtils.touch` takes `String | Pathname | Array[String]` instead of decision 12 class twins: a dynamic
 call's wrapper cannot pass a twin its keywords (decision 281 added `mtime:`/`nocreate:`).
- Effect on `brew info wget`'s program: untyped receivers of dynamic calls 1,829 → 1,779, dynamic call sites
 2,693 → 2,607, `rbAs` conversions 8,295 → 8,246.
- Proof: `union_test.rb` (`test_assignment_narrows`).
