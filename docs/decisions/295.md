# Decision 295

**Brew batch 21: casks** (#100; amends 294, 243, 150; 2026-10-16). `brew info --cask` firefox, visual-studio-code
and font-fira-code join targets.txt; the info entry gains the 23 files their MRI traces load.
- Every Delegator, not only SimpleDelegator, stands for its object in untyped code: each delegator class gets a
 `_DelegateObj` method calling its own `__getobj__` (a LazyObject's evaluates its block), and `rbDelegateObj`
 backs the dispatcher fallback (replacing decision 294's SimpleDelegator case), untyped iteration and
 `rbSplatAny`; `[*x]` of a statically typed delegator spreads it the same way (Homebrew's
 `*default.fetch(:languages)` of a LazyObject).
- A computed send's `&block` may be any Proc value, typed (`T.nilable(T.proc...)` from a tuple) or untyped
 (`rbBlockArgAny`), not only the method's own block; with one anywhere, a block-less method's wrapper drops a
 trailing block as MRI ignores it; `**kwargs` of an empty Hash passes nothing (Homebrew's cask loader
 `public_send(key, *args, **kwargs, &block)`).
- `rbConv` boxes into a scalar's `T?` (String, Integer, Float, Symbol, Boolean, through `rbOptFrom`), so a JSON
 Hash converts into `Hash[Symbol, String?]` (CaskStruct `ruby_source_checksum`).
- A call binding a method type parameter to a class's `T?` records it; `rbOptClassFrom` boxes an untyped value
 (nil, or the object) into that pointer type where the generic body converts with `rbAs[U]` (Homebrew's
 `set_unique_stanza[U]` returning an ivar as `DSL::Version?`). Generic Go cannot tell the pointer's element type
 without reflection, so the cases are the instantiations the program makes.
- In gem code any value where a Boolean is expected is its truthiness (a predicate block's
 `select { |var| ENV.fetch(var) }`); user code still requires a Boolean or `T?`.
- A local assigned on the right of `||` in a condition is hoisted, as `&&`'s already was (`next if k.nil? ||
 (blk = h[k]).nil?` then `blk`: Cask::DSL#language_eval).
- `T.bind(self, X)` narrows self to X for the rest of its block or method when X is a subclass of self's static
 type (asserted once); otherwise it is dropped as before (amends 196). Homebrew's MacOSRequirement and
 XcodeRequirement satisfy blocks, bound to Requirement by patch 0013, call their own class's methods.
- StringScanner `scan`/`skip`/`match?`/`check` take a String pattern, matched literally.
- Brew patch 0011: CaskStruct `sha256` and `version` are nilable; brew's silenced sorbet-runtime builds a struct
 with a missing required prop as nil, which rb2go's typed initialize rejected. Patch 0012: `print_info` types
 `resolved` as the `T::Array[[T.untyped, T.nilable(Tap)]]` its callee takes: a tuple branch beside an Array
 literal one otherwise joins to a union rb2go cannot convert. Patch 0013: Requirement's satisfy blocks are typed
 `T.proc.bind(Requirement)`, as `satisfied?` instance_evals them on the requirement (decision 164's escaped
 block), and ArchRequirement's block binds to its class as its siblings' do.

 `stdlib_test.rb` (`test_scanner_string_patterns`),
 `sorbet_test.rb` (`test_bind_narrows_self`). All eight targets.txt commands equal MRI's output.
