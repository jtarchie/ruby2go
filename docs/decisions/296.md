# Decision 296

**Rule:** `-trace main.rb args` runs the program under MRI once (executing it fully) and compiles the files it loaded, as `-main` with a built entry.

**`-trace`: compile what a run of the program loaded** (#100; amends 197, 288, 199, 262; 2026-10-16).
- `rugaroo build|run|gen -trace main.rb args...` runs `ruby [-rubyopt ...] -I <-I dirs> main.rb args` once under a
 load tracer (`internal/boot/trace_hook.rb`: TracePoint `:script_compiled` plus `$LOADED_FEATURES` and `$LOAD_PATH`
 at exit), then compiles as `-main main.rb` with the entry built from that run (`compiler.TracedEntry`). A program
 that picks its files at run time (Homebrew's `require "cmd/#{name}"`, `extend/os/#{OS}`) no longer needs a
 hand-traced entry file, an `-I` list or a container: the trace is on the machine it runs on, so a Mac trace
 compiles brew's `extend/os/mac` files and a Linux one its `extend/os/linux` files.
- The trace EXECUTES the whole program, not only its load phase (decision 262's trust model, widened): a
 command with side effects (`brew install`) performs them at compile time too. Its stdout is dropped and its
 exit status ignored; only a run that wrote no load list fails the compile.
- Each loaded file becomes a `require`: a gem the prelude is (`json`, `sorbet-runtime`) by its name; a file of
 MRI's own library by its name when rugaroo knows the library (`mriLibs`, `preludeLibs`), else dropped (encodings,
 portable Ruby's helpers); any other file by its path under the longest `$LOAD_PATH` dir, which becomes a gem dir
 (`-I`). A file under no load-path dir was reached by `require_relative` from a compiled file and is compiled
 from there. A gem that loaded a C extension (`fiddle`) is left out, as rugaroo cannot compile its Ruby half
 against a missing native one; a method using it is stubbed (decision 205).
- In traced mode the `setup.rb` that `bundle install --standalone` writes compiles to nothing: its `$LOAD_PATH`
 edits are what the trace already resolved, and the rest shims RubyGems' `Kernel#gem`.
- `class << self; prepend M; end` is `singleton_class.prepend(M)` (amends 199).
- A top-level constant whose initializer reads a top-level local (brew's `dir = __dir__ || raise(...)`, then
 `HOMEBREW_LIBRARY_PATH = Pathname(dir).parent.realpath.freeze`) is assigned where it stands in its file's top
 level, with the locals (`Const.inMain`; closes decision 170's "not yet"). Its type is inferred by first typing
 the file's top-level local assignments before it in the constant's own probe; a `#: T` still wins.
- RbConfig's `rubylibdir` is `/rugaroo/lib/ruby/4.0.0` (and `archdir` under it), not `""`: MRI's library is compiled
 in, so a computed require of a path under it is already loaded (false), whatever the file (brew's
 `FastBootRequire.from_rubylibdir("pathname")`, and `from_archdir("portable_ruby_gems")` in the arm boot ran
 under portable Ruby).
- The prelude gains what brew's MRI boot plumbing (`standalone/init.rb`, `standalone/sorbet.rb`, which the two
 `rugaroo_replace` overlays used to replace) reads: `require "rubygems"` loads `prelude/rubygems.rb` (`Gem::VERSION`,
 `Gem::Version` comparison, `Gem.paths=`, `ruby_api_version`, `discover_gems_on_require`; no gem loading, as
 MRI under `--disable=gems`), and sorbet-runtime's `T::Configuration` setters are no-ops (signatures are checked
 at compile time). Statements editing `$LOAD_PATH` stay skipped (decision 205).
- `T.bind(self, X)` also makes X the owner of the block's ivars (decision 295's narrowing; ArchRequirement's
 `@arch` in its satisfy block).
- A run sees only the paths that ran: the main file's own literal requires outside its methods, of files on the
 traced load path, are compiled too (brew.rb's `rescue` requiring utils/backtrace).
- `fiddle` (a C extension) is a prelude library: MRI's LP64 constants, so code that builds C signatures at load
 (Homebrew's os/mac/ffi) loads; `Fiddle.dlopen` raises `Fiddle::DLError`, as without cgo nothing can be called
 (*see also decision 326*: Fiddle now calls C through purego).
 `fcntl` is one too (`IO#fcntl` with an integer argument); `File#stat`, `File::Stat#ino`/`#dev`,
 `File.identical?` and `FileUtils.ln_s(force:)`/`ln_sf` over Pathnames join the prelude (brew's LockFile and
 cached downloads).
- Ancestors: a module the superclass already has, included again (directly or through another module), keeps its
 place after the superclass, as MRI's include skips it: CurlDownloadStrategy's `ohai` is
 AbstractDownloadStrategy's override, not Utils::Output::Mixin's again through Utils::Curl. Method lookup used to
 put it before the superclass.
- Typed fixes the Mac path needed: `return x unless x.nil?` narrows a `T?` local (only unions narrowed);
 Comparable's ops on `self` in a generic body go through a `<=>` that takes untyped (decision 287 for
 self: MacOSVersion#prerelease?'s `self >= "27"`); a `-> self` call on self asserts back to Self
 (MacOSVersion#strip_patch calling Version#major_minor); `&p` of a nil `T?` Proc passes no block, as MRI's,
 instead of raising.
- A gem method's first pass that a compile error unwound from inside nested blocks left its closure depth behind,
 so the retried pass (decision 251) compiled a plain `return` as a non-local one that raises
 (Resource::BottleManifest#manifest_annotations). Each pass now starts at the body's own nesting. No small
 reproduction was found; the Mac `brew info` run is the proof.
- Brew patch 0014: `Formula.service` stores its block as `T.proc.bind(Homebrew::Service)`, as its parameter
 already says and Service#initialize instance_evals it.
- `RUGAROO_RUBY` names the MRI for boot, gem lookup and the trace (default `ruby` on PATH). The boot hook calls
 Module's own methods through `instance_method(...).bind_call`, as a module may make them private for itself
 (brew's `Cask::Quarantine`), and tests a constant with `Module === v` (a BasicObject has no `is_a?`).
- overrides/brew's `host` clones the user's Homebrew at the pinned commit into `work/homebrew`, applies the
 patches, and replaces its portable Ruby with `tools/ruby-wrapper`: `bin/brew` sets up its environment as always
 and then runs `rugaroo run -trace brew.rb <args>`; any other Ruby call (and a nested `bin/brew`) goes to the real
 Ruby. No brew patch: brew.sh runs `$HOMEBREW_RUBY_PATH` explicitly, so a `#!` line is never consulted.
- Proof: `TestTraceRun` (testdata/traced from a run: a standalone Bundler setup, a constant reading a local, a
 require under rubylibdir), `TestTracedEntry` in internal/compiler, `object_test.rb` (`test_prepend`),
 `control_output.rb`, `control_test.rb` (`guarded_unless_nil`), `stdlib_test.rb` (`test_gem_version`,
 `test_fiddle_constants_and_dlerror`, `test_file_stat_ino`), `fileutils_test.rb` (`test_ln_s_force`),
 `sorbet_test.rb` (`test_bind_narrows_self`), testdata/boot `DemoCmp`; `brew info wget` on macOS equals MRI's.
