# Decision 297

**Rule:** `-trace-also` merges more traced runs into one binary; `rb2go_replace` is gone; a private method dispatches when a module includer overrides it.

**`-trace-also`; `rb2go_replace` is gone; the brew harness traces** (#100; amends 197, 288, 296; 2026-10-17).
- `rb2go build|run|gen -trace main.rb args -trace-also "other args"` (repeatable) traces more runs of the same
 program; their loaded files join the first run's (load order kept, each file once), so one binary serves
 several commands: overrides/brew's targets.txt (formulae, `--json=v2`, casks) builds into one work/brew-bin.
- `# rb2go_replace: path => file` is removed (`readMagic`, `Compiler.replaced`): with decision 296 brew's
 `standalone/init.rb` and `standalone/sorbet.rb` compile as they are, so no directive remains in rb2go.
- overrides/brew drops entries/, overlay/, env.txt, dirs.txt and ./trace. Every script runs brew through its own
 `bin/brew` with tools/ruby-wrapper in place of its Ruby (tools/install-wrapper, tools/in-container.sh):
 `./gen` traces every targets.txt line (`HOMEBREW_RB2GO_ALSO`), `./build` cross-builds work/brew-bin, `./check`
 compares each line against unpatched fork-mode MRI in the same container. The wrapper takes a prebuilt rb2go
 (`HOMEBREW_RB2GO_EXE`) where there is no checkout to build it from.
- A private method is called directly only when nothing overrides it; a module's includers (and their
 subclasses) now count, not only subclasses (`Class.includers`). Utils::Curl is `module_function`, so its
 `curl` is private, and CurlDownloadStrategy overrides it to add its headers and `--silent`: `curl_download`
 called the module's own `curl`, so the compiled brew's bottle manifest download went out without its
 Authorization header and failed (amends 253).
 An includer's own private override of a module's dispatched private method (UnpackStrategy::GenericUnar's
 `extract_to_dir`) is dispatched too, so it gets the forwarder the module's constraint needs.
- Several `**` splats into named keywords (`super(*a, **x, **y, **z)`) are one `**{**x, k: v, **y}` from the
 first splat on: later keys win and **rest keeps MRI's order. It was a compile error.
- Brew patch 0015: `PourBottleCheck#satisfy` stores its block on the formula class (`pour_bottle_satisfy`) and
 `Formula#pour_bottle?` instance_execs it, instead of `define_method` at run time (macOS `:clt_installed`).
- Brew patch 0016: `Context#with_context`'s block is `T.proc.returns(T.untyped)`, not `void`: the method returns
 the block's value, which CurlDownloadStrategy#expand_deferred_environment_args uses.
- Proof: `TestTraceRun` (a second run given `argv` loads traced_argv), `object_test.rb` (`ObjFetcher`,
 `ObjUnar`), `method_test.rb` (`test_several_double_splats`); all eight targets.txt lines equal MRI's through
 the traced build, and on macOS `brew info` wget, jq, git (downloading its manifest itself), python@3.13 and
 `--json=v2 wget`.
