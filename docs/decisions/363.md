# Decision 363

**Rule:** A constant assigned again keeps one variable typed by the join of its writes and prints MRI's warning when the write runs; a constant nothing defines warns and raises `NameError` where it is read; a top-level def hides Kernel's method of its name; a yield with a splat gives the def a `{ (*T) -> R }` block; `a[*xs]` and `a[*xs] = v` switch on xs's length.

**Second batch of #114** (2026-10-24). *See also decisions 18, 146, 183, 302, 362.*

- **A constant assigned twice** (68 rejects, "constant X is already defined"). MRI warns "already initialized constant X" and the second value wins. Now a later `X = v` in the same file is a `Const` with `first` set: it declares no variable, assigns the first one's in source order (decision 18), and writes MRI's two warning lines to `$stderr` first. The constant's type joins every write (`joinAgains`), so `X = 1; X = "a"` is `Integer | String` (decision 150) and a use that does not fit both is the union's compile error. A reassignment from another file is still "already defined" (ponytail: rare, and file order then decides the type).
- **A constant nothing defines** (52 rejects, `ScratchPad` inside never-called fixture methods, and every unresolved name). MRI raises `NameError` only when the read runs. Now the read warns at compile time ("raises NameError if this line runs") and compiles to that raise; a call on it (`ScratchPad.record :x`) is the raise, with no dynamic call. The `testdata/errors` cases that expected the compile error now expect the warning. Ponytail: `x = Missing` types x untyped.
- **A top-level def named like a Kernel method** (`def test(i)` in spinel's `bm_object_new_init`/`bm_object_new_no_escape`; "Kernel#test: wrong number of arguments"). The def is Object's, which precedes Kernel in every ancestry: `topOverKernel` lets it win in `resolve`, `classCall` and `selfCall`.
- **`yield(*xs)`** (103 of the 112 "SplatNode" rejects: mspec's `BlockSpecs::Yielder#m(*a)`). An unannotated user def (a gem's spreads at run time, decision 250) with a yield that passes a splat takes a `{ (*untyped) -> R }` block (`splatYields`), its element typed from what the yields pass (`restArgs` notes `xs`'s element type), and the block binds `|a, b|` from it as decision 302's `bindFromRest` does (a missing argument is still T's zero value, that decision's ponytail). Such a block is never a Go iterator, so a tail yield is the method's value. A splat of an untyped value spreads as MRI's (`rbSplatAny`); `k: v` passed to such a block is one Hash, as a proc takes it.
- **`a[*xs]` and `a[*xs] = v`** (`genIndexSplat`): `[]`'s overloads are picked by arity, unknown for a splat, so the call is a switch on `len(xs)` over the one- and two-index forms that compile (each the static call), joined; another length raises ArgumentError. Only a typed Array splat; a tuple is not covered.
- **Proof:** `control_output.rb` (constant again, missing constant, `def test`), `objects.txtar` `constant_reassigned_other_type`, the warning cases in `objects`/`encoding`/`socket.txtar`, `method_test.rb` `SplatYieldTest`, `array_test.rb` `ArrayIndexSplatTest`.
