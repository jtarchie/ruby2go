# Decision 377

**Rule:** After pruning, a module free func generic over Self that is called with a single-parameter container (`Enumerable_Sum[*Array[T], T]`) is copied with Self fixed to that container (`Enumerable_Sum_onArray[T]`), and the call goes to the copy (`RUGAROO_NO_SPECIALIZE=1` turns it off); `format`/`sprintf`/`String#%` on a literal format string compile to typed appends, and a chain of three or more String `+` to one `rbConcat`.

**Module funcs specialized per container** (2026-10-26). *See also decisions 86, 210, 342, 348.* Research against the hand-written Go ports showed that `1 + 1` already compiles to nothing (Go inlines `Integer#+` with its overflow check and folds it) and that the per-element cost in `benchmarks/` is the generic Enumerable protocol: in `func Enumerable_X[Self Enumerable_Self[Self, E], E ...](self Self)`, `self.Each()` is a call through the instantiation's dictionary (Go stencils by GC shape, so every pointer Self shares one body), its iterator closure escapes, and the loop body becomes a second escaping closure: three allocations per call and a closure call per element. A copy with the same body and `self *Array[E]` makes `Each()` a direct, inlinable call: `sum` of 3 Integers 83 ns to 11 ns, 0 allocations; of 300,000, 767 to 433 µs. Earlier guesses were measured and dropped: `any(x).(Integer)` does not allocate (an unsafe cast was no faster), and yield inlining stays declined (348).
- **Where.** `specializeSelf` (`internal/compiler/specialize.go`) runs on the Go AST in `formatGo`, after the pruner's sweep: every `IndexListExpr` naming a func whose first type parameter is `Self M_Self[Self, E, ...]` with `E` next, and whose first two type arguments are `*G[T]` and `T` for a one-parameter generic type `G` whose parameter has the same constraint as `E`, becomes `M_X_onG[T, rest...]`. The copy is the generic reprinted with its comments (so its `//line`s and frame label carry over: backtraces read `Enumerable#inject` as before), its `Self` parameter dropped and each `Self` replaced by `*G[E]`; copies are rewritten in turn, so module funcs calling each other specialize together. Forwarders (`(*Array[E]).Sum`) are rewritten too, so dynamic and interface calls reach the copy.
- **Not specialized.** A two-parameter container (`*Hash[K, V]` with `E = Tuple2[K, V]`) would need E substituted as well; a user class's Self is its interface, already one shape. A name that is already declared keeps the call generic.
- **Cost.** Go compiles a generic only where it is instantiated, so the generic left without callers is free; the copy takes the generic's place as one instantiation per element shape. `TestCompileCost` compiled functions: 05_word_count 2,011 to 2,013, 64_observable 7,723 to 7,729, 116_cuba_web 30,277 to 30,295.
- **Measured** (instructions retired, GOMAXPROCS=1, median of 3): blocks 981M to 586M, array 184M to 154M, collections 1,555M to 1,452M, objects 518M to 494M, format 3,311M to 3,182M, liquid 2,093M to 2,011M, kramdown 4,464M to 4,391M; the rest within 1%.
- **Literal format strings.** `rbFormat` cost 1,300 ns and 24 allocations a call against `fmt.Sprintf`'s 446 ns and 5: every argument boxed into `[]any`, the string parsed, a spec string rebuilt per directive, the Builder grown. `genLiteralFormat` (`expr_format.go`) lowers `format("lit", ...)`, `sprintf` and `"lit" % x` / `"lit" % [...]` (Kernel's or String's prelude method, not a user override) when the string has only `%[flags][width][.prec]verb` directives, as many as there are arguments, and no splat or keywords: each argument is evaluated first, left to right, into a temp of its static type, then one `[]byte` gets the literal text and a helper per directive. `rbFmtInt` (`%d %i %u`, and `%x %X` of a non-negative value), `rbFmtFloat` (finite `%f`) and `rbFmtStr` (`%s` of a String, width in characters) take `-` and `0` flags; any other directive, flag or value goes through `rbFormatOne` with the spec `rbFormat` would have built, so the text is the run-time path's. Anything else (`*`, `N$`, `%<name>`, a count mismatch and its ArgumentError, an untyped `x` in `"lit" % x` that may be an Array) stays on `rbFormat`. `byte` and `rune` joined the predeclared names a Ruby local is renamed away from (`{ |byte| ... }` shadowed the buffer's type).
- **String `+` chains.** `String#+` (cost 186) did not inline and each `+` of `a + b + c` made its own String. Its two-non-empty-short-operands case (Go's concatenation, always a new String) now inlines, the rest in `rbStrPlus`. `genStrChain` (`expr_format.go`) compiles a chain of three or more statically String operands of the prelude's `+` to `rbConcat(a, b, c)`: one allocation, operands evaluated left to right; a first operand of 64 bytes or more goes through `rbStrCat` (`rbStrPlus(a, rbConcat(rest))`), so `s = s + x + y` in a loop still extends `s` in place.
- **Smaller fixes, measured on the way.** `each_cons` slides its window in place (`win = win[1:]` dropped capacity and reallocated every few elements): that line of blocks 230M to 190M. ASCII `upcase`/`downcase` build in one `strings.Builder` (was `[]byte(s)` then `string(b)`), ASCII `capitalize` and `reverse` in one pass and one allocation (was two case maps and a concat; a `[]rune`): `capitalize` 211M to 142M, `reverse` 231M to 137M for 200,000 calls. `"A".capitalize` returned its receiver (the concat of `"A"` and `""`); it is a new String now, as in MRI.
- **Found on the way:** `%+f`/`% f` of NaN dropped the sign flag (MRI prints `+NaN`, ` NaN`, as for Inf); fixed in `rbFormatOne`. Not fixed here (pre-existing; fixed in decision 379): `"ßtraße".swapcase` keeps `ß` (MRI `SSTRASSE`), case mapping of a binary String prints `\uFFFD` for `\xFF`, and `"%.2f" % 2.675` is `2.67` in rugaroo (correctly rounded, as C's printf) and `2.68` in MRI.
- **Measured:** format 3,048M to 1,876M instructions (its `format` loop 1,380M to 394M, `"%.2f" % x` 427M to 151M).
- **Proof:** `TestSpecializeSelf` (the rewrite, what it leaves alone, copies calling copies, the frame label); `StringConcatChainTest` (order, identity, a long left side in a loop, case-mapping identity); `StringCompiledFormatTest` (each lowered format against the run-time path on the same values, and both against MRI by the trace oracle); the existing minitest and run suites, whose output must still equal MRI's.
