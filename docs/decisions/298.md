# Decision 298

**Rule:** A `@me = self` ivar in a generic body is the class interface; receiver'd `X.prepend` in a body is collected; interface `initialize` is the free func.

**ruby/spec regressions from the brew rounds** (#100; amends 199, 253; 2026-10-17).
The brew work left three ruby/spec core directories unbuildable (core 5,004 → 4,669 passing). All three are
ordinary-Ruby gaps, not brew constructs:
- An ivar first typed by `@me = self` inside a generic body (a struct class with subclasses, or an anonymous
 class's metaclass) was declared `*Self`, a type parameter outside any generic. It is the owner's class type
 (its interface), as `Self` is everywhere else outside the body. Latent before #100 (the class-body form was a
 compile error, so specs skipped it).
- `::Module.prepend M` (any receiver'd `X.prepend` / `X.singleton_class.prepend`) inside a class or module body
 is collected like the top-level form (decision 199), not left as a run-time call.
- Decision 253 made an overridden private method dispatch; `initialize` is overridden almost everywhere but is
 never an interface slot, so a call through an interface-typed receiver (`SystemCallError.instance_method(
 :initialize)`) named `SystemCallErrorI.Initialize`. Such a call is the free func, as before 253.
- Process: ruby/spec core (`go run ./cmd/rubyspec core`) joins the per-batch checks of #100, so a FATAL
 directory shows up in the round that causes it.
- Proof: `object_test.rb` `SelfIvarTest`; core/class, core/exception, core/kernel run again.
