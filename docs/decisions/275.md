# Decision 275

**Rule:** Core method twins are prelude `alias` lines (each keeps its own frame label); the prelude defines no non-MRI public Enumerable methods.

**Prelude method twins are aliases; non-MRI Enumerable helpers removed** (#101; amends 12; 2026-10-14).
- Removed the non-MRI public Enumerable methods `count_if`,
 `with_index_pairs`, `uniq_by` and `each_with_index_from` (no
 callers anywhere): `respond_to?` was true where MRI's is false, and
 calls compiled instead of raising `NoMethodError`. `with_object` is
 Enumerator's only, as in MRI. `Hash#first_pair` became
 `__first_pair`.
- Core method twins (`map`/`collect`, `select`/`filter`/`find_all`,
 `find`/`detect`, `reduce`/`inject`, Hash `each`/`each_pair`,
 `select`/`filter`, Array `select!`/`filter!`) are `alias` lines.
 `copyAlias` renames the method, so each name keeps its own
 backtrace frame label; a forwarding `def` would add a frame.
- `Range#__span(n)` is the shared `[]=`/`fill` range arithmetic
 (returns `[start, count]` or nil; the callers raise `RangeError`,
 since raising inside would add a backtrace frame). It returns a
 tuple, so a program whose only tuple use is `fill(range)` emits the
 Tuple2 boilerplate (+3 functions); programs that also slice with a
 range shrink. `Range#__slice` keeps its own clamping copy.
- Measured (generated bytes): 64_observable 2,861,546 → 2,854,504;
 116_cuba_web 3,012,365 → 3,007,862; word_count and hello unchanged.
