# Decision 301

**`brew install` path: gem-code shapes `info` never reached** (#100; amends 205, 296; 2026-10-17).
- A failed `try` attempt, and a discarded `probe`, undo what they noted about locals (declaration pass, block,
 hoist flag). A lenient retry had found the local "already declared" and assigned (`sym = ...`) without
 declaring it (`forbidden = forbidden.split.each_with_object({}) { ... sym = ... }`).
- `alias base_respond_to? respond_to?` in gem code forwards to the intrinsic (`respond_to?` has no `Method`);
 `singleton_class.send(:undef_method, :x)` / `.undef_method` / `.remove_method` in gem code is a no-op (boot
 recorded the one definition that survives), and a receiverless `define_singleton_method` site boot saw is a
 no-op as `define_method` is (decision 198): bindata's self-replacing `inherited` hook compiles.
- `(a, = expr)` as a condition is `expr`'s value; the Go it produced (`_ = `) did not parse.
- An `each(&block)` whose block is `|*args|` (a gem forwarding to an untyped collection) gets an iterator adapter
 too: several yielded values reach the iterator as one Array (`rbPackYield`).
- A gem's `x = super(*mods)` of a void method (`Module#include`) runs it and binds nil. A block parameter rebound
 to a non-Proc value (`task = ScheduledTask.execute(&task)`) becomes a new Go variable. A `NamedArgs < Array`
 (embedded `Array[any]`) passed where `Array[String]` is declared converts at run time (`rbAs`).
- `$LOAD_PATH`, `$:` and `$-I` read what boot left in it (`Manifest.load_path`); without a boot they stay
 unsupported (decision 61).
- Prelude: `File::Stat#ctime/#writable?/#readable?/#executable?/#uid/#gid/#grpowned?`, `File.grpowned?`,
 `Pathname#grpowned?`, `Process.groups`, `IO#getch` (line-buffered, no raw mode), `Errno::EBUSY`.
- Brew patch 0017 gives the compiler plain shapes where Ruby is dynamic (`self.class.new`, `send(*args, **kw)`,
 `flat_map` returning an element, an untyped lambda passed as a typed proc, `T.self_type` through the
 `freeze` chain).
- Linux `brew install` also needs bindata/elftools/patchelf (relocation reads ELF files): bindata's
 `define_singleton_method(:new)` closing over locals boot cannot record (`endian_classes`) is still poisoned.
- Later in the same push (macOS `brew install wget`, `overrides/brew/macgen`/`macrun`): a private class hook
 (`private def inherited`) is called by the runtime, not refused; an `inherited` hook's
 `subclass.class_eval { @x = local }` runs where the hook stands (`seedsFromLocals`), not as the class's body;
 `module_eval(String)` in gem code raises NotImplementedError (a ScriptError the loader rescues: third-party
 tap formulae are unreadable in a compiled brew, API formulae are fine); an undefined method on a gem class not
 all loaded is a run-time NoMethodError inside methods; `T::Class[Mod]` of a module is any class object; a
 Delegator member of a union forwards an iterator call; Kernel#then/yield_self/tap fall back on any value;
 `def_delegators` through an untyped accessor forwards untyped; run-time `rbAs` unwraps a Delegator.
 Prelude: `FileUtils.copy_file`, `File.chown`/`Pathname#chown`, `Errno::EROFS`.
 Brew patches 0018-0023 (option lists, seatbelt template, merge_repeats kwargs, runtime dependency record
 type, `from_extension`, sandbox inheritance File).
- Proof: `testdata/boot` (`rebind`, `rebind_block`, `Registry`, `safe_responds?`, `$LOAD_PATH`), `control_test.rb`
 (`test_destructure_as_condition`), `enumerator_test.rb` (`ForwardedTest`), `stdlib_test.rb`
 (`test_stat_access_and_groups`).
