# Decision 366

**Rule:** A mixed Array literal assigned to a local that is later used as an Array (a mutator, a `!` method or an iterator) is an Array of its elements' union, widened by later writes as decision 193's; a tuple iterates as an Array of its fields' union; a user Hash literal local written later with `[]=`/`store` widens the same way.

**Mixed-type Arrays and Hashes** (#114's typing gap; 2026-10-24). *Amends 193 and 241; see also decisions 22, 150, 227, 323.* Decision 22 makes a 2-3 element mixed literal a tuple and decision 193 widens a homogeneous literal local by later writes, so `a = [1, "two"]; a << 3.0`, `[1.0, 42].each { }` and mspec's `ArraySpecs.recursive_array` (`a = [1, 'two', 3.0]; 5.times { a << a }`) were "undefined method << for tuple" or "undefined method each for tuple".

- **A tuple local used as an Array** (`usedAsArray`: a call on the local, in its scope, of an Array mutator from `tupleMutators`, a `!` method, or an Array iterator) is seeded as decision 193's open local with its elements' union (`joinAllUnion`, decision 150's `joinUnion` folded), so its type is `Array[A | B | ...]` joined with what later writes add; a write that does not join (an Array holding itself) leaves it `Array[untyped]`, and pass 2 then builds the literal as that Array (`widenSeed`). A tuple used only as a tuple (fields, destructuring, read-only Array methods per decision 241) is unchanged.
- **Iterating a tuple** (amends 241): an Array iterator on a tuple receiver as a statement (`[1.0, 42].each { |n| }`) runs over a copy of its fields as `Array[union]` (not decision 22's numeric join, which would make 42 a Float), which is what MRI's iteration sees.
- **Hash literals in user code**: decision 323's gem-only `widenHashSeed` now also applies to a user local that the scope writes with `[]=` or `store`, so `g = {1 => :a}; g["s"] = 2` is `Hash[Integer | String, Symbol | Integer]`; other Hash literal locals keep their literal type (an open-uri options Hash is still recognised).
- **Cost:** none for programs that compiled before: the widening only applies where a write or call of another type was a compile error, and a tuple iterated was one.
- **Proof:** `array_test.rb` `ArrayMixedLiteralTest`, `hash_test.rb` `HashMixedLiteralTest`; `arrays.txtar` `tuple_each` removed.
