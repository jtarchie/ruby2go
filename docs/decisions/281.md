# Decision 281

**Rule:** Scope: brew batch 14: `openssl` RSA verify, bound blocks through dynamic calls, run-time `instance_method`, per-run classes get `New<X>In`.

**Homebrew batch 14: RSA verify, bound blocks through dynamic calls, run-time `instance_method`, per-run classes without `initialize`** (#100, #101; amends 141, 243, 259; 2026-10-15).
- `require "openssl"` loads `prelude/openssl.rb` (net/http loads only
 `openssl_ssl.rb`, its `OpenSSL::SSL::VERIFY_*`, so a web program
 does not compile RSA). Only what Homebrew's JWS check
 needs: `OpenSSL::PKey::RSA.new(pem)` (PKIX/PKCS #1 public, PKCS #1/#8
 private; anything else is `PKeyError`, which `RSAError` names, as in
 MRI), `#verify` (PKCS #1 v1.5), `#verify_pss` (`salt_length:
 :digest/:auto/:max/Integer`), `public?`/`private?`, on Go's
 `crypto/rsa`. Go's MGF1 always uses the message digest, so another
 `mgf1_hash:` returns false where MRI could verify. No signing, key
 generation, TLS or X509 objects.
- A method's own typed `&block` passed on to a call on an untyped
 receiver (`def bottle(&block) = stable.bottle(&block)`, `stable`
 returning `T.untyped`) becomes an `rbBlockArg` whose values are
 asserted into the block's types. A `T.proc.bind(X)` block is marked
 `bound` and takes self first. The receiving adapter of a bound-block
 method passes self first only to a bound `rbBlockArg`, so a literal
 block (which cannot rebind self, decision 164) still sees just the
 yielded values. Bound-block methods now get dynamic-call adapters.
- An optional block's adapter passes nil when the call gave none
 (decision 243 said so but always passed a raising stand-in).
- `recv.instance_method(:m)` on a non-constant class object
 (`self.class.instance_method(:brew).owner`, Formula#initialize):
 built on the receiver's static class, but `bind`/`bind_call`
 dispatch through the object, and `owner`/`inspect` come from a type
 switch on the class object's metaclass type over the subclasses
 that override `m`. A constant receiver keeps decision 141's static
 binding. A union of class objects is still an error.
- Under decision 197 (a traced entry), a literal `require` of a
 prelude library inside a method loads that library at compile time:
 MRI's trace never lists one a method requires late (Homebrew's
 `require "openssl"` in `verify_jws_signature`). Other in-method
 requires still resolve at run time.
- A Method of a method whose block is required (gem code only:
 `self.class.instance_method(:brew).owner`) is built for its
 reflection; calling it raises LocalJumpError without running the
 method (MRI would run it up to its first yield).
- `FileUtils.touch(list, mtime:, nocreate:)` as MRI's (a missing
 path under `nocreate: true` is ENOENT from `apply2files`), and
 `MatchData#values_at` takes group names as well as indexes
 (Homebrew's `Tap.with_formula_name`).
- A dynamic call on an untyped nil goes to a reopened `NilClass`'s
 method before Object's or Kernel's, as decision 241's typed nil
 does (Homebrew's `compact_blank`: `case v when Object then
 v.blank?` must see `NilClass#blank?`).
- An untyped Array converted to a tuple (`rbAs`, decision 22)
 converts each element as an Array's are (`rbConv`), so
 `["u", {tag: "v"}]` from JSON fills a `[String, Hash[Symbol,
 untyped]]` prop (Homebrew's `FormulaStruct#stable_url_args`).
- `Digest::SHA2.digest/hexdigest/base64digest/file` are SHA-256's, as
 MRI's class methods are (Homebrew's `Formulary.namespace_key`).
- Decision 241's param widening judges a `T?` value by its `T`:
 `fits` lets any non-class type through, so `rebuild = (".#{rebuild}"
 if x)` into an Integer param never widened it (Homebrew's
 `GitHubPackages.version_rebuild`).
- A gem's String bang method rewritten to its plain form (decision
 136) keeps its block: `gsub!(re) { ... }` lost it and called
 `gsub(re)` (Homebrew's `Formulary.class_s`).
- A per-run `Class.new` class (decision 259) whose ancestry defines no
 `initialize` also gets `New<X>In`, so its instances' `self.class` is
 their own class object, not the shared one.
- Proof: `testdata/test/openssl_test.rb`, `method_test.rb`
 (`test_instance_method_on_run_time_class`), testdata/boot
 (`DemoBoundFormula`, `DemoBareLoader`, `DemoNeedsBlockSub`, `DemoUrlStruct`,
 `DemoRebind`, `DemoClassS`),
 testdata/traced (`TracedReq.late_lib`), `fileutils_test.rb`
 (`test_touch_mtime_and_nocreate`), `string_test.rb` (`test_matchdata`),
 `object_test.rb` (`test_reopened_markers`).
