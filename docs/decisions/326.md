# Decision 326

**Rule:** Fiddle calls C through purego, without cgo or reflect, on one 8-int/8-float superset signature; `extern` and `struct` literals are compiled.

*See also decision 426* (`--cgo`: the same Fiddle API over cgo instead of purego).

**Fiddle over purego** (#32; amends 59, 242, 296, 324, 325; 2026-10-20). *See also decision 327* (sqlite3 on top of it). *See also decision 329* (calls and callbacks without reflect). *See also decision 375* (the ffi gem's API on top of it). Fiddle, Ruby's way to call C shared libraries without a C extension, works without cgo. `github.com/ebitengine/purego` (v0.11.2, Apache-2.0, no dependencies) does libffi's job in Go and assembly. It is the second runtime module after regexp2, wired the same way (242): every generated `go.mod` requires it (`rugaroo.GoMod`/`GoSum`, `TestGoModMatchesRepo`) and Go loads it only when `main.go` imports it, which happens only when the pruner keeps a Fiddle helper (`prelude/go/fiddle.go`). The generated module's `go` directive is now `1.25.0`, purego's minimum. *See also decision 82*: no `reflect` is involved.
- **Calls without reflect.** Fiddle's types are run-time values, and Homebrew passes them through parameters (`NativeLibrary#function(name, argument_types, return_type)`), so `Function.new` cannot be typed from literals. Instead every C function is bound to one Go signature, `func(8 × uintptr, 8 × float64) uintptr` (or `float64` for a float/double return). On the System V (amd64) and AAPCS64 (arm64, Apple's too) ABIs, integer and floating arguments fill their own register files independently, so this superset passes any register-passed signature: the callee reads the registers it declares and ignores the rest. A float sits in the low half of its register. Narrow results (char, short, int, bool) are truncated and sign- or zero-extended in Go, since the ABI leaves the upper bits unspecified. More than 8 integer or 8 floating arguments (stack-passed, laid out differently per platform) and `TYPE_VARIADIC` (C varargs, which purego cannot make) raise `NotImplementedError`. `Fiddle.last_error` is errno, read on the calling OS thread (`runtime.LockOSThread`) right after the call.
- **Ruby on top.** `prelude/fiddle.rb` is the C half: `Handle` (dlopen; `nil` is `RTLD_DEFAULT`), `Function`, `Pointer` (libc `malloc`/`free`, byte and range `[]`/`[]=`, `to_s`/`to_str`, `ptr`/`ref`, arithmetic, `free=`/`call_free`), `Closure`/`Closure::BlockCaller` (purego callbacks, the same superset signature; at most 2000 per process, never freed, no float return), `CStructEntity`, `CStruct`, `CUnion`, the `TYPE_*`/`SIZEOF_*`/`ALIGN_*` constants, `Fiddle.malloc`/`realloc`/`free`/`dlopen` (with MRI's Linux linker-script fallback). `prelude/fiddle_import.rb` (`fiddle/import`, `fiddle/cparser`) ports MRI's `CParser` and `Importer` (`dlload`, `typealias`, `sizeof`, `extern`, `bind`, `[]`, `import_symbol`, `import_function`, `bind_function`) and `CompositeHandler`.
- **extern/bind are compiled.** MRI's `extern "int abs(int)"` `module_eval`s a method. A literal signature in a module that extends `Fiddle::Importer` is read at compile time (`internal/compiler/fiddle.go`, cparser's patterns, typealiases seen so far) and a `def self.abs(a0)` is synthesized that calls the registered `Function`, typed by the C return type (`Integer`, `Float`, `bool`, `Fiddle::Pointer`, `nil`); the `extern` call still runs at load to look the symbol up. A non-literal signature, a variadic one, and an unknown type are compile errors. Only the module method is made (MRI's `module_function` also makes a private instance method).
- **struct/union are compiled.** `Name = struct ["int id", "char tag[4]", ...]` in an Importer module declares `class Name < Fiddle::CStruct` (`CUnion` for `union`) with the LP64 layout CStructBuilder computes (offsets, `size`, `alignment`, `members`, `types`, `offsetof`, `malloc`) and typed accessors per member: integers `Integer` (a `bool` member too, as MRI reads it through pack), floats `Float`, pointers `Fiddle::Pointer`, fixed arrays `Array[...]` (a fresh Array, as MRI's for signed element types). `[]`/`[]=` by name, `to_h`, `each`, `each_pair`, `to_ptr` (a `CStructEntity`), `to_i`. Nested structs and non-literal member lists are compile errors. **Differs from MRI:** `CUnion` is a subclass of `CStruct` here (MRI's is not).
- **Strings passed as pointers** are copied into C memory, since rugaroo Strings are immutable values (decision 136): C's writes to the copy do not reach the String, and `Pointer[str]` is a copy. The copies are freed after the call unless the function returns `void*`, which may point into one (`strchr`); those leak (ponytail).
- **Overrides need a signature.** A `Fiddle::Closure` subclass's `call` overrides `(*untyped) -> untyped`; written without a `#:` its result is not known when the override is checked, so it is a compile error until annotated.
- **No more LoadError.** Decision 324's in-method `require "fiddle"` raised LoadError so Homebrew took Landlock as `:missing_fiddle`; that special case is gone, and `Fiddle.dlopen` no longer raises (296).
- **Linux `dlopen(nil)` also loads libm** (`RTLD_GLOBAL`): MRI's process links it, a binary without cgo links only libc, so `pow` was missing.
- **`respond_to?(:fork)` is false** (`notImplemented` in `expr_untyped.go`), as MRI answers for a method it defines with `rb_f_notimplement` on a platform without it; `fork` itself still raises NotImplementedError. **Differs from MRI** on Linux and macOS, where MRI forks. `Errno::<NAME>::Errno` constants exist now, with `Errno::ENOSYS` and `Errno::EOPNOTSUPP`.
- **Homebrew backfill.** macOS `brew install wget` without brew patch 0030 (the shared-cache fallback, deleted): `LinkageChecker#dylib_found_in_shared_cache?` calls `_dyld_shared_cache_contains_path` through `NativeLibrary#function`, and stdout, stderr and exit status each equal MRI's. On Linux, Fiddle made Landlock's probe work, so compiled brew took the sandboxed path and failed in `Utils.safe_fork` (fork is not implemented). New brew patch 0030 reports `:missing_fork` when `Process.respond_to?(:fork)` is false (a no-op under MRI), so the output is as in decision 324: the same lines as MRI's except "Sandbox unavailable" for MRI's Landlock ABI warning, and the parallel-download order differences are gone in this run. A fork-free Landlock child stays the follow-up: the restricted work is Ruby, and a Go program cannot fork and keep running it. Example 121 and `fiddle_test.rb`, cross-built for linux/arm64 with `CGO_ENABLED=0`, equal MRI and pass in the container.
- **Proof:** example 121 (`examples/121_fiddle`: Importer externs, a struct, `Function.new`, a `qsort` callback, a Pointer C string, DLError), `testdata/test/fiddle_test.rb` (mixed int/double/float arguments, narrow returns, errno, Pointer bytes and arithmetic, struct and union layout and members through `memcpy`, a Closure subclass and a BlockCaller called from C and from `Function`), `testdata/errors/fiddle.txtar`; sig `sig/fiddle.rbs`.
