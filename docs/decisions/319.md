# Decision 319

**A computed `respond_to?` on an untyped value emits every `rbResponds*` marker check, not every dispatcher** (amends 32, 235; 2026-10-19). `rbRespondsByName` (a computed name on an untyped receiver) was tied to `rbSendByName` by one flag, `dynEvery`: reaching either emitted every noted dispatcher, every Dyn wrapper on every class and every forwarder up front. Answering `respond_to?` needs none of that: `rbResponds<Name>` is a class-ID switch (`rbHas_Responds<Name>`) plus the `respond_to_missing?` fallback. The prelude's `SimpleDelegator#respond_to_missing?` (`__getobj__.respond_to?(name)`, untyped by decision 118) is reached from every `rbResponds*` fallback, so any program with a delegator and one `respond_to?` dispatcher paid for every dispatcher. Now `respondEvery` (set when `rbRespondsByName` is reached, or by the eager retry together with `dynEvery`) emits every `rbResponds*`, and dispatchers stay lazy (`dynNeeded`). `tableInputs` carries the flag so a late flip recompiles eagerly, as `dynEvery`'s does.
- **Why:** the brew measurement under decision 316: after patch 0024 typed the last two computed sends on untyped receivers, the delegator's `respond_to?` alone kept 3,867 dispatchers and 12,105 wrappers. Of brew's five SimpleDelegator subclasses only two have a typed object (decision 284), so a per-subclass `respond_to_missing?` would not have cleared it.
- **Measured:** brew `info wget` (macOS gen, with patch 0024): 63,572 → 59,859 functions, dispatchers 3,867 → 2,565, Dyn wrappers 12,105 → 10,342, `rbAs` 7,842 → 6,366; `rbSendByName` call sites 117 → 0, `rbRespondsByName` 6 → 2 (the delegator's and `install_steps`' `respond_to?` guard on the typed union, which the scoped form answers). What remains is dynamic calls on genuinely untyped receivers, each noting its own name.
- **Proof:** `dynamic_test.rb` `test_computed_respond_to_on_untyped` (public, inherited, missing, `respond_to_missing?`, private with and without `true`); TestCompileCost 05_word_count 1,339 and 64_observable 7,209 unchanged, 116_cuba_web 28,245 → 28,286 compiled functions (its computed `respond_to?` now answers over every `rbResponds*`).
