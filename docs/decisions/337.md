# Decision 337

**File layout of the compiler, and checkers that stop drift** (#109 phase 2; 2026-10-22). *See also decisions 280, 336, 338.*
- **Split by responsibility, with the generated Go as the oracle.** `gen.go` (4,469 lines) is `gen.go` plus nine `gen_*.go` files; `decls.go` (about 2,700) is `decls.go` plus `emit_*.go`; `dynamic.go` (about 1,750) is `dynamic.go` plus `dynamic_*.go`; `expr.go`, `expr_string.go`, `expr_call.go`, `model.go`, `sigs.go` (now `sigfiles.go` and `overloads.go`) and `internal/rbs/rbs.go` (`types.go`, `lex.go`, `parse.go`) are split the same way. Each move is a verbatim cut of whole declarations by a go/ast script with their doc comments; nothing inside a function or a string literal changed. The proof for a pure move is that `rb2go gen` produces the same bytes for every example and `testdata/run` file before and after (171 inputs; stdout, stderr and exit status). Known limits of that oracle: it cannot see whitespace that go/format normalizes, the `//line` paths embed the checkout directory so it must run from the same path, and `examples/120_pairing_heap` is skipped because `gen` on it is not deterministic (two valid outputs, about 75/25; likely map order in generic-instance emission, decision 308). The one intended output change is a doc comment that moved inside `rxtranslate.go`, whose source is embedded in generated programs that use regexps (19 outputs).
- **`TestGofmt`** fails on any tracked Go file gofmt would change. `golangci-lint run` does not check formatters in v2 (they run under `golangci-lint fmt`; `.golangci.yml` enables gofmt for that), so drift from a split or a move would otherwise pass every gate.
- **Fewer seconds per `go test`.** `FuzzCompile` seeds itself from every example and `testdata/run` file only under `-fuzz` (it cost 57.6 s serially in a plain run, and TestExamples/TestRun compile the same files). Five more root tests run in parallel; `TestBootAutoload` and `TestTraceRun` stay sequential because they use `t.Setenv`. `requireToolchain` (was `requireRuby4`) checks `ruby` and `bundle` once per run. The MRI output cache key now hashes every file of an example directory, not only `.rb` (a changed `scores.csv` no longer matches a stale entry), and its version is v6 (decision 272). The root package took 1,086 s with a cold MRI cache, against 1,389 s before this wave.
- **Removed.** `prelude/runtime.rb` and `prelude/dynamic.rb` (comment-only files still required), the duplicate `Pathname#/` (the class reopening is merged; the later `(Pathname | String)` definition stays, since its signature drives a union-conversion helper), `rbChild.err`, `rbOpen3Status`, `internal/boot/cuba_probe_test.go`. `rbAt` stays: `expr_proc.go` emits it by name.
- **Wave 2: duplicated code.** One `synthDef`/`synthFile` (internal/compiler/synth.go) for the 11 sites that parse a synthesized Ruby `def`; line padding is `File.shiftLines(n)` (n leading newlines without parsing them), since `addDef`, `sigComment` and the boot keys read `f.line`. One `walkNode`/`opensScope` (ast.go) for eleven stateless AST walkers; walkers that thread state down the tree, or prune differently (`unset.go`'s state machine, `reach.go`), keep their own recursion. `receiverEnv`, `adapterFunc`, `resolveMixinArgs`, `emitDynReturn`, `isTopConst`, `regexFlagsOf`, `localVarRef` replace the copies. A gem-code Struct, Delegate or Fiddle member is synthesized without a path, so it compiles as user code (`synthOpt.NoPath` keeps that; it may be accidental).
- **Wave 2: measured speed.** Profiling `rb2go gen` showed the review's candidate list (isSubclassOf, sortedClasses, sortedLocals, readsLastMatch, argFits, delegateType, stubRejected ...) under 1 percentage point each on 05/64/116/120, and rejected them; the time was in regexps: `goCalled` (14-28% of CPU on every program), `dynShareable`, `plainCut`, `nameGo`, `reach.scanGo`. Hand-written scanners, each tested against the regexp it replaces on the corpus and random strings, cut `gen` wall time 05_word_count 0.305 to 0.215 s, 64_observable 1.129 to 0.50 s, 116_cuba_web 4.285 to 2.75 s, 120_pairing_heap 1.412 to 0.65 s. Generated Go is byte-identical. `isSubclassOf` (28 of 274 CPU-s on brew, decision 240) was not visible at this scale and brew cannot run here: unmeasured, not disproved. An empty-set memo for `methodSet` was rejected (about 3% CPU, within noise, and nothing would catch a stale empty set).
- **`formatGo` is not a formatting step.** It parses the generated Go, prunes the AST (decision 49), emits the lazy tables batch by batch (`emitNext`, the largest slice: 471 of about 2,900 ms on 116_cuba_web), splices the std imports, and prints. Printing is how the pruned program becomes text, so it cannot be skipped; `printer.RawFormat` (skip gofmt's alignment) saves 0.4-1.2% of `gen` and was not adopted as an option. The `madvise`/page-fault share in profiles is a darwin sampling artifact (sys time 0.18 s, `GOGC` changes left wall unchanged). `parser.SkipObjectResolution` would cut parse by a third (about 2% of `gen`) but `prune.go` reads `Ident.Obj`.
- **Runtime speed (generated programs).** String/Symbol/Hash inspect about 2.9x faster (no regexps or ReplaceAll passes), `gets(sep)` and `gets(nil)` 20-30x, `FileUtils.compare_file` 3-5x, `BigDecimal` trailing zeros about 50x, anchored matches on a large subject about 70x (`rbValidUTF8` keeps the last large valid subject in an `atomic.Pointer`, no mutex), flag-free `format` 25-45%, backtrace capture allocates on the stack. Each kept only when measured at 10% or more; the strscan lazy-groups attempt measured within noise and was reverted. `format("%05s")`, `%05p` and `%05c` ignore the `0` flag, as MRI.
- **Not done.** Splitting `io.rb` and `file.rb` (load order would change emit order, which the oracle could not prove identical); pinning the Go tarball checksum in `overrides/brew/Dockerfile` (cannot be checked here).
