# Decision 208

**A forwarder instantiates `Self` with one type per owner, not per
class** (#96 phase 2, amends 8). Go compiles a generic body once per
GC shape and, for each distinct type argument, a small dictionary
wrapper. An inherited class body was already instantiated with its
owner's interface (`Module_Constants[ModuleI]`: one instantiation for
every metaclass), so #96's premise that each class compiles its own
copy held only for two cases, now fixed:
- **Universal owners** (`Kernel`, `Object`, `BasicObject`) were
 instantiated with the receiver, `Kernel_FrozenQ[*Foo]`: a wrapper
 per class. A struct class's forwarder now passes `[any]`, as
 decision 121 does for Dyn wrappers. Primitives keep their own type,
 which `any` would box.
- **Module bodies** were instantiated with each includer's interface
 (`Minitest_Assertions_AssertEqual[FooTestI]`), each a GC shape of
 its own. When the module's constraint names no `Self` in a method,
 the forwarder passes the constraint itself, `Mod_Self[any, E]`,
 which every includer satisfies. Decision 8's `[VersionI]` rule
 stays where it is needed: the constraint names `Self`
 (`Comparable_Self`'s `Op_cmp(other Self)`; `constraintNamesSelf`
 reads the rendered constraint), the signature names `Self` or the
 class (`sigMentions`), or the class is generic.
- **Rejected:** `*C` for class owners. It shares the shaped body
 (pointers of a method-set constraint share `*uint8`) but adds a
 dictionary wrapper per class: `64_observable` went from 51,939 to
 55,075 compiled functions.
- **Measured:** `64_observable` 51,939 → 50,855 compiled functions.
