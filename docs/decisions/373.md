# Decision 373

**Rule:** Every supported feature is in one tier, listed in `docs/support.md`: stable (MRI-oracle tested; a difference from MRI is a bug unless a decision names it), experimental (works on what is tested, may change), or not supported (a compile error, by design); `TestSupportDoc` fails when a require name the compiler answers is missing from that page.

2026-10-25. Before this, the README's "What works" was the only list, it had drifted from
`internal/compiler/libs.go` (ten require names missing), and it read the same for core
`Array` as for compiling an arbitrary installed gem. Someone deciding whether their program
will compile needs to know how much to trust each line.

**The tiers.** A tier is set by what backs it, not by how finished it feels.
- **Stable.** Covered by the MRI oracle under `go test`: an example, a `testdata/test`
  file, a `testdata/run` file, or ruby/spec. Output that differs from MRI is a bug, unless a
  numbered decision documents the difference (decision 20's TypeError wording, decision
  58's immutable Strings, ...). Stable is a promise about behaviour, not about the shape of
  the generated Go, which stays internal and changes freely.
- **Experimental.** Works on the programs it is tested with and may change or break between
  commits: a design still moving, a dependency outside the binary, or a test set much
  narrower than the feature. At 2026-10-25: compiling installed gems (the boot snapshot,
  decision 161), `-trace`/`-trace-also`/`-main` (decisions 296, 297, 197, 288), patched
  gems (`overrides/brew/gem-patches`), `fiddle` and `sqlite3` (a system library at run
  time, purego; decisions 326-329), `--int-overflow=promote` (decision 372), the Sorbet
  bridge (decision 196), `Ractor`, and the wasm playground (decision 102).
- **Not supported.** A compile error that names the reason, each with its decision:
  `eval` and code loading, `define_method`, `instance_variable_get`, runtime reopening,
  in-place String mutation, encodings beyond the listed ones, overloaded RBS signatures,
  non-local `return`/`break` out of a closure block.

**Promotion.** An experimental item becomes stable when it has an oracle test and has gone
one tagged release without a design change. Demotion needs a decision, as any change to a
stable behaviour does.

**Keeping the page true.** `TestSupportDoc` (`internal/compiler`) reads `docs/support.md` and
fails when a key of `preludeLibs` or `vendoredLibs` (bar the internal `__` ones) has no row,
so a new library cannot ship unlisted; `TestCLIDoc` (`cmd/rugaroo`) does the same for every flag `main.go` and `web.go` define against `docs/cli.md`. The ruby/spec rates on the page are pasted from a
dated `cmd/rubyspec` run, like the README's and the landing page's numbers.
