# Decision 416

**Rule:** cmd/rubyspec loads a library's own spec_helper, keeps a shared spec's `__dir__`, keeps `guard_not` of CRuby's make-test-spec check, and expands a gem class body's literal `[:a, :b].each { |m| define_method(m) { } }` without a boot; gem code's mismatched writes widen Hash/Array constants and ivars of unrelated classes to untyped, a lambda's optional params are optional to a dynamic call, `send` on an untyped receiver is a class's own send when it defines one, and a gem's `loop` in value position is nil; a Proc of another shape, a tuple whose elements do not fit, and `allocate` of a class with a non-nilable ivar are compile errors.

**Bundled-gem backfill, sixth batch: net-ftp and drb** (2026-10-30). *See also decisions 183, 198, 233, 236, 247, 330, 331, 409, 414, 415.*

`library/net-ftp` went from 0 of 460 (every program failed `go build`) to 331, and `library/drb` from no examples (its block was guarded out) to compiling, its 2 examples erroring on one gap. The general fixes also took `library/matrix` from 319 to 327 of 361 (its spec_helper now loads), getoptlong from 24 to 26 of 27, and prime from 37 to 40 of 68. pstore, net-smtp and rinda have no `library/` directory in ruby/spec, so there is nothing to measure for them.

**The harness** (cmd/rubyspec):
- **A library's spec_helper loads.** Every `require_relative` of a file named spec_helper was skipped, meant for ruby/spec's own (mspec.rb stands in for it); net-ftp's requires net/ftp and sets `default_passive`, matrix's defines `be_close_to_matrix`. Only `spec_helper.rb` at the root is skipped now.
- **A shared spec's `__dir__`.** Inlining a shared spec into the spec that includes it made its `__dir__ + "/../fixtures/putbinaryfile"` the spec's directory; it is rewritten to `(__dir__ + "/shared")`.
- **`guard_not -> { MSpecScript.instance_variable_defined?(:@testing_ruby) }`** (CRuby's own make test-spec) keeps its block, as this is not that run: drb's whole spec was inside it.
- **`x.should.unitary?`** (from batch 5's matrix run): any predicate on SpecExpectation asks the actual value, as mspec's.
- **`Net::FTPError.should < Exception`**: SpecExpectation's `<`, `<=`, `>`, `>=` on a Module compare ancestors. Not a dynamic Module#< in the compiler: its arm in every `<` dispatcher kept every class's ancestor table (cuba +397 functions).
- **Literal define_method loops without a boot.** A gem class body's `[:local_address, :send, :shutdown].each { |method| define_method(method) { |*args| ... } }` (net-ftp's BufferedSocket) becomes the records boot would make (`staticDefineMethods`), one per Symbol with the block param captured as it (decision 198), when no boot ran.

**Compiler, gem code:**
- **`result&.concat(data)`** as a statement emitted the edited String as a bare Go expression; a done edit's value now goes to the result.
- **A constant's lambda** (`TIME_PARSER = ->(value, local = false) { ... usec = x if fractions ... }`): constant initializers with a block get a pass-1 probe, so a block's locals are hoisted, and `maybeUnset` covers them; the unset walk now enters lambdas as blocks (a lambda's `y = x if c; y` read 0, not nil, in user code too).
- **Container constants widen** (`widenConstElems`): `FACT_PARSERS = Hash.new(CASE_DEPENDENT_PARSER)` then `FACT_PARSERS["modify"] = TIME_PARSER` stored a two-param lambda into a one-param V and failed `go build`; a write its element type cannot hold makes the element untyped. A converted Hash copy keeps `Hash.new`'s default (a default proc does not: ponytail).
- **A lambda's optional params** stay optional to a dynamic `call` (`procMinArity`, with `rbArg` nil past the end), and a rest-param Proc (`-> s, *args { }`) is callable dynamically.
- **ivars of unrelated classes**: `@sock = NullSocket.new` then `@sock = Socket.tcp(...)` widens the ivar to untyped in discovery, as a subclass's write into its parent's does (decision 331).
- **`Socket.tcp(host, port)` held untyped**: a block-taking generic method with a `__name_enum` sibling dispatches block-less dynamic calls to it, and `__name_enum` is not a by-class twin (`untypedTwinArg`).
- **`rv.clear` / `replace`** on an untyped local holding a String rebind it (`untypedStringEdit`).
- **`@io.send(line, Socket::MSG_OOB)`** on an untyped receiver is the receiver's own `send` when its class defines one (BasicSocket's, a BufferedSocket's forward), Kernel#send's call by name otherwise, decided at run time (`ownSendOrName`); a `Socket?` receiver's typed `send` is its own too.
- **An inherited signature with `**`** no longer fits a def without one (`sameParamShape`): drb's `DRbProtocol#open(uri, config, first = true)` is not Kernel#open.
- **`require(x) rescue nil`** (void or nil) is untyped, its void expression run as a statement.
- **A class body's bare `respond_to?(:to_a)`** folds to what the class object answers, read off the method tables (drb's `undef :to_a if respond_to?(:to_a)`); calling lookup at collect time cached Kernel's table before link and lost `==`.
- **`ruby2_keywords def method_missing(...)`** collects the def.
- **A gem's `loop do ... break ... end`** as a block's last value runs, then is nil.

**Compiler and prelude, all code:**
- **`String#slice`** mirrors `[]`'s forms (`slice(re, n)`, `slice(re)`, `slice(str)`, `slice(i)`), so an untyped receiver's call picks the same one.
- **`Time.utc`, `gm`, `local`, `mktime`** take numeric Strings (by-class twins `__utc_string`, ...) and `local` takes usec; a dynamic wrapper with optional params tries a by-class twin per argument count, so its defaults run.
- **Sockets**: `Addrinfo#listen`, `Socket#accept` (`[conn, addrinfo]`), `read_nonblock(n, buf, exception:)`/`write_nonblock`/`wait_readable`/`wait_writable`/`to_io` on BasicSocket, `Socket::SO_OOBINLINE`.
- **`Object#private_methods` / `protected_methods`**: its class's (drb's check_insecure_method); ponytail: not Kernel's private methods, which MRI lists too.
- **No `Range#to_ary`**, as MRI's Range has none: `a, b = (1..2)` binds the Range, and matrix's `Matrix[1..2]` raises TypeError (the prelude's to_ary, from example 36, answered an Array).
- **A class object's `private_methods`** lists its private class methods (`private_class_method :new`, from a `_PrivateSingletonMethods` table).
- **`ObjectSpace::WeakMap`**: ponytail: strong values, keys by eql?.
- **`Class#allocate`** of a struct class is the zero object; a class with a non-nilable ivar other than Boolean is a compile error, since it would read 0 where MRI reads nil.
- **A tuple where an Array is expected** converts when each element fits, else is a compile error (Go rejected it); gem code then calls `+` at run time, whose mixed result is an `Array[untyped]` (`rbViewFromWide`). A Proc of another shape where a Proc is expected is a compile error instead of a `go build` failure.
- **`Kernel#private_methods`/`protected_methods`** load only when a file calls one (`__reflection`, as `__errno_process`): as Kernel methods in every program, a computed send compiled every class's method tables for them (64_observable +1,048 functions).
- **Found by the coverage recheck** (`language` lost two files to `go build` failures that more reachable code exposed): a super bridge whose parent answers another Go type than the override converts the value (`[:b, super]` over a Symbol `foo`: raising where they differ, as rugaroo types super by the override's result), and `def initialize_copy` with no parameter makes dup raise MRI's ArgumentError instead of passing it the source.
- **Cost:** TestCompileCost compiled functions 2060→2065, 7925→7949, 30245→30379 over decisions 414-415 (the dynamic wrappers block-less `File.open`/`IO.open` now have, Hash#_DefAny, rbViewFromWide); 64_observable's compile time is HEAD's within noise (median 1.77 s against 1.76 s).
- **Design limits left in `library/net-ftp`:** spec code's ivars nothing assigns (`@binary_mode`, and the `@ftp`, `@remote_tmp_file` writes its setup takes down: user code's compile error, 73; *decision 422 corrects the attribution to 183 and maps every net-ftp bucket*), mspec's partial mocks (`stub!`, `should_receive` on real objects: run-time method replacement: the design goal and docs/support.md's not-supported row, *corrected by decision 424, which this cited as 51*), `ruby_exe`, and a fixture method whose param is typed by its Symbol default but called through `send` with a String.
- **Design limit left in `library/drb`:** `IO.select([server_socket, pipe])` in DRbTCPSocket#accept_or_shutdown: BasicSocket is no IO subclass, since IO is a `@go_type` (decision 62), so IO.select takes IOs only.
- **Recheck (decision 417):** `Matrix[1..2]`'s TypeError and `Matrix.new`'s privacy hold when their spec file runs alone, and fail in the whole `library/matrix` program, whose joined parameter types differ; drb's 2 examples were miscounted as 0 by the harness, not guarded out.
- **Proof:** `testdata/test/{object,string,array,hash,date,socket}_test.rb`'s new classes; `testdata/run/gem_lenient/ftpish.rb`; `testdata/errors/objects.txtar`'s `proc_of_another_shape` and `allocate_integer_ivar`; `TestGemDefineMethodWithoutBoot`; cmd/rubyspec's `TestRewriteLibraryHelpers`; `library/net-ftp`, `library/drb`.
