# Decision 405

**Rule:** A class method or top-level def that appends to a String parameter, and never rebinds it, takes it as `*String`: the caller passes a local String it owns, the method copies it in and writes it back however it returns, and nothing in the method may keep, return or pass on the String except to another such parameter.

**String out-parameters** (amends 382; 2026-10-27; #128, #143). *See also decisions 58, 136, 395, 404.* Decision 382 let a proven-unaliased String local take `<<`; a parameter could not, since the caller's String would have to see the append. Roundhouse's views are all that shape, `def self.form_into(io, article, ...)` appending to the caller's `io` and nesting partials with `Views::Comments.comment_into(io, ...)`, as Rails templates append to one output buffer. #128's option 1 (out-parameter rewrite): compile-time only, no mutable String type.

- **Which parameters.** `markOutParams` (`outparam.go`, after signatures resolve): a positional, required parameter typed `String` of a class method or top-level def in user code, whose body has `p << x` or `p.concat(...)` and never assigns `p`. Instance methods are left out: an override or a dynamic call (`send`, a dyn wrapper) would pass a `String` where a `*String` is taken.
- **The callee.** The Go parameter is `p_out *String`; the prologue binds `p := *p_out` and defers `*p_out = p`, so the appends are on a local, decision 382's `rbStrAppend` buffer, and reach the caller on return or raise (MRI shows a raising partial's appends too). Decision 382's proof runs on it with no seal: any read that may keep the String (stored, returned, passed to anything but another out parameter, the method's own value) is a compile error, since the caller keeps appending after the call.
- **The caller.** The argument must be a local String variable; it is passed as `&local`, and counts as an append on that local in the caller's own proof (`outCallArg`), so a local that something else holds is still refused. Inside a block that may run after its call, it is refused as an append there is.
- **Cost.** The callee's buffer starts empty, so its first append copies what the caller built: one copy of the page so far per partial. ponytail: pass the caller's buffer beside the pointer when a page's partial count makes that matter.
- **Not covered.** An attribute (`page.out << ...`, #128's option 2), an instance method, a parameter the method returns (`def grow(s) = s << "x"` stays an error: `t = grow(s); s << "1"` would leave `t` behind), and a String argument that is not a local.
