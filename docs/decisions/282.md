# Decision 282

**Rule:** A class variable a module assigns stays the module's after `prepend`; the prepended copies do not redeclare the class's own `@@x`.

**Homebrew batch 15: a prepended module's class variables** (#100; amends 241; 2026-10-15).
- A class variable assigned in a module body and used by that
 module's methods after `Klass.prepend(Mod)` is the module's: the
 copies prepending makes no longer declare the class's own
 method-first `@@x` (#52), which shadowed it and read as unset.
- A reached method's `@@x` read or write keeps a gem body's
 assignment through constant pruning (decision 169).
- Homebrew's `OS::Linux::DependencyCollector` (`@@global_dep_tree`,
 `@@building_global_dep_tree`).
- Proof: `object_test.rb` (`test_prepended_module_class_var`),
 testdata/boot (`DemoCvCollector`).
