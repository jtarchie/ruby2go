# Decision 294

**Brew batch 20: `brew info --json=v2` deeper; delegators through untyped code; forwarded optional blocks**
(#100; amends 118, 99, 209; 2026-10-16). Each was one layer of `info --json=v2`'s `Formula#to_hash`; the remaining
static stubs on that path (`overrides/brew/hits`) are four, in cask loading, and the rest show only at run time.
- A Forwardable/`delegate` forwarder of a method whose block is optional declares `?{ ... }` and passes the
 caller's block on (`&blk`), or none: it always passed a block, so Homebrew's `livecheck` (read without one,
 configured with one) took the configuring path. A target block binding self keeps `[self: T]`.
- `s.scan(C)` with C a constant holding a Regexp literal with groups (`.freeze` allowed) picks `__scan_groups`, as
 the literal would (Homebrew's `Patch.extract_cves`).
- `x.instance_eval(&blk)` on an `X?` receiver passes the object (nil raises before the block runs; ponytail:
 MRI runs it with self nil).
- A dispatcher (`rbDynName`) given a SimpleDelegator that does not define the name retries on its `__getobj__`
 before method_missing, as MRI's delegator method_missing does; a static call keeps decision 118's typed
 rewrite. (A prelude `SimpleDelegator#method_missing` in Ruby did the same but changed which overloads
 unrelated classes' operators compiled to.) Untyped iteration (`rbEachAny`, `rbElemsAny`) looks through a SimpleDelegator, so
 `deps&.reject(&:implicit?)` of Homebrew's Dependencies iterates its Array.
- A generic class's method returning `Array[E]` of its own bare parameter gets a Dyn wrapper (Set#to_a through
 untyped); `growsTypeParams` (decision 209) still leaves out other classes of bare parameters (Hash[K, V]'s pairs
 close a Go instantiation cycle) and any union naming a parameter (its rbUnion helper is package-level).
- `Array#union(*others)`, `Hash#transform_values!`.
- Brew patch 0010: `to_formulae_and_casks` wraps `load_formula_or_cask` in `Array()` for `flat_map`.
- Proof: `object_test.rb` (`test_optional_block_delegator`), `regexp_findall_test.rb`
 (`test_scan_groups_through_constant`), `stdlib_test.rb` (`test_untyped_simple_delegator`), `hash_test.rb`,
 `array_test.rb`, testdata/boot (`DemoDelegBlock`, `DemoHoistUnderscore`).
*See also decision 295:* every Delegator (rbDelegateObj), not only SimpleDelegator.
