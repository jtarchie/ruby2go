# Decision 305

**Rule:** Pending inherited aliases are pruned with their targets; `super(&:sym)` works; `:sym.to_proc` compiles at the call site, not at run time.

**Symbol procs into gem blocks, and pruned aliases** (amends 169, 223, 244; 2026-10-18). The unmodified `pairing_heap` gem (example 120) needed three things.
- **An unreached inherited alias is pruned with its target.** `alias_method :extract_min, :dequeue` in a subclass, where `dequeue` is the superclass's own alias, waits in `inheritedAliases` until `linkAliases` (decision 169's pruner never saw it). Unreached, the pruner dropped `dequeue` but kept the pending alias, which then could not find it. `prune` now drops a pending alias by the rule it applies to methods.
- **`super(&:sym)` / `super(&proc)`** pass the block as the same `&expr` on a call would (`genClosure`). Decision 223 allowed only a literal block or the method's own `&block`.
- **`:sym.to_proc` is compiled at the call site** where a Proc is expected: the lambda `&:sym` would build, typed by the expected Proc. Into a gem's untyped Proc or block (`^(*untyped) -> untyped`, decision 244: `@order = block || :<=.to_proc`, `super(&:<=)`), it is a variadic Go func that sends the name to its first argument through the dynamic dispatcher, with the rest as arguments; no arguments raise ArgumentError "no receiver given", as MRI does. No `Symbol#to_proc` method exists at run time; a non-literal symbol's `to_proc` is still unsupported.
- **Not done** (*see also decision 306*, which now reads it): the gem ships `sig/pairing_heap.rbs`, which rugaroo does not read (only `sig/gems/<gem>/` and a `sig/` beside the program). Its `class PairingHeap[Elem, Priority]` would also need generic struct classes (decision 44 says they may not exist), so the gem's internals stay untyped, and a Dijkstra + heapsort workload runs slower than MRI (0.98 s vs 0.71 s). *(See also decisions 308-309: generic struct classes and generic superclasses now exist.)*
- **Proof:** example 120 (`examples/120_pairing_heap`), `object_test.rb` `ObjectSuperSymbolBlockTest`.
*See also decision 307:* the pairing_heap internals now type (rbDyn 56 → 5; benchmark 0.49 → 0.17 s).
