# Decision 374

**Rule:** A traced compile records each run-time string eval (call site and source); an `instance_eval(string, ...)` on self at a recorded site switches on the string and runs that source compiled, as a block on self, and any other string raises NotImplementedError.

**Run-time evals the trace saw, compiled where they run** (#100; amends 204, 296, 301, 323; 2026-10-25). The goal: a
compiled brew runs `brew tap jtarchie/rugaroo https://github.com/jtarchie/rugaroo`, `brew trust jtarchie/rugaroo` and
`brew install rugaroo`, the cask in this repository's own tap. Homebrew reads a tap's cask with
`instance_eval(content, path)` inside `CaskLoader::FromPathLoader#load`, a string eval at run time, which decision 301
compiled to a NotImplementedError (brew reports it as an unreadable cask).

- **Recording.** The trace hook (`internal/boot/trace_hook.rb`) keeps each `:script_compiled` event that has an
 `eval_script`: the caller's `path:line` and the source (base64 on an `E` line). `boot.Loaded.Evals` carries them as
 kind `run`, deduplicated across `-trace-also` runs, into the manifest's evals.
- **Compiling.** `collectRunEval` parses each source as a file named after the eval's file argument, with its own line
 numbers (`__FILE__`, `__LINE__` and backtraces name `Casks/rugaroo.rb:39`, as Homebrew's deprecation notice reads them
 from `caller`), and gem or user code as its call site is. At a site that is
 `instance_eval(string, ...)` with no receiver or `self`, `genRunEval` emits `switch string(src)` with one case per
 recorded source; each case is that source's statements compiled as a block on the current self (a cask's
 `cask "x" do ... end` calls the loader's `cask`, whose block is `T.proc.bind(DSL)`), and the call's value is the
 block's last value (`.tap do |cask|` on it is typed). The file and line arguments only name the source for MRI's
 messages and are not evaluated. Decision 169's reach walk also walks every recorded source, so the methods it calls
 (`cask`, `version`, `postflight`) are compiled.
- **The closed world.** The default arm raises NotImplementedError naming the string: the binary runs the cask text it
 traced, not casks in general. A tap that publishes a new version needs a new compile, as any other input outside the
 traced run does (decision 296). Other kinds of site (`eval` with a binding, `class_eval` on another object) still
 ignore what the trace recorded.
- **DSL blocks run later on another object.** A literal block passed to a gem method's untyped `&block` that, compiled
 on its lexical self, reaches self's `method_missing` (a cask's `postflight do system_command ... end` on `Cask::DSL`,
 which brew later instance_evals on a `DSL::Postflight`) takes its self at call time, as decision 324's class-body DSL
 blocks do (`rebindableBlock`, `fctx.missingCalls`).
- **On the way** (the tap rebuilds the completion list, which loads every brew command file, so all of `cmd/` and
 `dev-cmd/` compile now):
  - a block parameter typed by a same-file `T.type_alias` (`block: SearchBlockType`) is written out as the alias's
   type; a qualified alias path (`Search::SearchBlockType`) is not looked up;
  - `T::Enum`: an `enums do X = new end` block is the class body and each value is named (`X = new.__enum_bind("X")`),
   so `serialize` defaults to the downcased name and `inspect` is sorbet-runtime's. ponytail: no `values`,
   `deserialize` or `each_value`;
  - `T::Class[T.type_parameter(:U)]` is untyped (RBS has no `singleton()` of a type variable);
  - an `attr_writer`-only ivar's `T?` (decision 323) does not conflict with the class body's `@x = T.let({}, X)`: the
   ivar stays `T` and the writer takes `T`;
  - a Struct's generated `==`/`eql?` may name its class when it is a `private_constant` (generated source is exempt);
  - a generic block result `U?` with `U` a leaf class (decision 360) is boxed to the `**C` the generic code holds
   (`filter_map { Locale.parse(it) }`);
  - in gem code a leaf's `C?` where `C` is wanted passes the pointer on, nil as MRI's nil (decision 257's rule for
   objects; `ChecksumMismatchError.new(filename, checksum, actual)` after `checksum.blank?`);
  - `IO#to_io`/`File#to_io` (Readall's `stdout_file.to_io`);
  - a Sorbet block parameter typed `T.untyped` is an optional block (`?{ (*untyped) -> untyped }`): untyped includes nil
   (LazyObject's `__getobj__(&_blk)`);
  - `{...}.freeze` and `[...].freeze` where a type is expected build the literal as that type (a `T.let` of a frozen
   Hash of lambdas types each lambda's parameter);
  - a Struct/Enumerable forwarder whose generic result is a leaf's `E?` opens the box (`rbFlat`, `rbFlatArray` for
   `Array[E?]`), and the call site no longer opens it again;
  - in gem code an `Array[untyped]` into an `Array[X]?` ivar converts where it lands;
  - `instance_eval(&T.cast(block, T.proc...))` of an untyped block rebinds self as the block itself would; an optional
   `&block`'s `Proc?` box held untyped converts back to the Proc (`rbAsSlow`);
  - run-time conversion to a type parameter bound to a `C?` box fills the box (`rbAsSlow` through `rbMBox`); a union
   converter takes a value-class subclass (`Cask::DSL::Version < String`) as its String;
  - a dynamic `Hash#fetch(k, default)` whose default is not the Hash's V answers the value or the default, as MRI's
   (concurrent-ruby's `opts.fetch(:auto_terminate, true)`);
  - a dynamic call of a one-value prelude iterator without a block answers an Enumerator, as `iterEnum` does for a typed
   one (TSort's `each_strongly_connected_component.to_a`), except over a type variable (its Enumerator would
   instantiate itself);
  - prelude: `Dir.glob`/`Pathname.glob` take `File::FNM_DOTMATCH` (wildcards and `**` take dot entries; `**/*` lists
   `.` at zero depth only, as MRI); blockless `Pathname#descend`/`#ascend` are Enumerators; a relative path's `ascend`
   stops at its first segment;
  - brew patch 0031: `tap.rb` builds the "Tapped 1 cask" sentence with interpolation instead of `presence&.prepend(" ")`;
   patch 0032: `Bundle::Brew::Topo` defines `tsort_each_node` as `Utils::TopologicalHash` does, instead of aliasing a
   wider `each_key`.
