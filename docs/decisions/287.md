# Decision 287

**Brew batch 16: Comparable ops through a `<=>` that takes untyped; `String#start_with?(Regexp)`; Set's
union family takes an Array** (#100; amends 9; 2026-10-15).
- Comparable's `<`, `<=`, `>`, `>=` on a class whose own `<=>` takes `untyped` pass the argument to that
 `<=>` as it is, as MRI's Comparable does, instead of converting it to Comparable's `(self)` parameter:
 `version < "2.39"` (Homebrew's `Glibc.below_ci_version?`; `Version#<=>` is Sorbet `other: T.untyped`, the
 authors' type, not one rb2go widened). A nil result is MRI's ArgumentError ("comparison of Version with 3
 failed": special constants show their inspect, others their class). Any other `<=>` signature keeps
 decision 9's static `(self)` check.
- `String#start_with?(Regexp)` is a typed overload (`__start_with_q_regexp`: a leftmost match at 0); it was
 a dynamic call that failed (Homebrew's `Ld.library_paths`). `$~` is not set (ponytail).
- `Set#merge`, `|`, `union`, `+`, `&`, `intersection`, `-`, `difference` take `Set[E] | Array[E]`, as MRI's
 take any enumerable: `paths = Set.new; paths += array` widened the local to untyped and then failed.
- Proof: testdata/boot (`DemoCmp`), `string_test.rb`, `stdlib_test.rb` (`test_set_ops_take_an_array`).
