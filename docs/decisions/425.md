# Decision 425

**Rule:** `$.` (English's `$NR`, `$INPUT_LINE_NUMBER`) is the line number of the last line an IO's or ARGF's `gets` read, 0 before any, and can be assigned (an Integer, a Float truncated, else to_int); the store happens only in programs that read or assign `$.`. `$_` is still not kept.

**Bundled-gem backfill, fourteenth batch: `$.`** (2026-10-30). *See also decisions 61, 95, 361, 415, 424.*

Decision 415 listed `$.` with `$_` as a limit. `$.` is not one: each IO already counts its lines (`IO#lineno`), so the global only had to follow the last read. It was an unbuilt feature, filed as a limit.

- **Runtime:** `rbLineNo`, an `atomic.Int64` (threads may read lines while another reads `$.`), stored by File's and IO's `gets` and by `rbGetsFrom` (gets with a separator or limit), through `rbNoteLineNo`. ARGF (bare `gets`, `readlines`, `each_line`) now counts its lines across ARGV's files, as MRI's ARGF.lineno, and stores them too. StringIO's `gets` does not touch `$.`.
- **Assignment.** `$. = 123.5` sets 123, as MRI's lineno setter (NUM2INT): an Integer as it is, a Float truncated, a struct class through `to_int` (decision 179's implicit conversion). Before this decision `$.` was the program's own global when assigned (decision 361), which `language/predefined_spec.rb`'s Integer and `to_int` examples passed through; making `$.` a builtin first refused the assignment (decision 109's rule for builtins) and lost those two, which a measure of the directories that use `$.` caught. With the setter they pass again, and the Float one now too (`language` 983 → 984).
- **Cost:** the store is behind `rbTrackLineNo`, which an `init` the compiler emits sets only when the program reads `$.`; other programs pay one bool test per line. TestCompileCost: 05_word_count and 116_cuba_web unchanged, 64_observable +1 compiled function (rbNoteLineNo, reached through `gets`).
- **`library/English` 22 → 24 of 27; `core/io` 370 → 376 (its `$.` examples).** Left: `alias_spec`'s `(1 / 0 rescue $ERROR_INFO).backtrace`, a call on an `Exception | Integer` union in spec code (decision 415, user code's union rule); `$LAST_READ_LINE`'s blockless placeholder (decision 421); and `$_`, which MRI keeps per method frame, still not built (issue #147: decidable at compile time as a hidden local of the method that calls gets).
- **Proof:** `testdata/run/io_argf_stdin.rb` (`$.` before and after `$stdin.gets`, ARGF's own count, `$NR`/`$INPUT_LINE_NUMBER`; a compile error without this decision); `library/English`.
