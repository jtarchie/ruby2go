# Decision 317

**A module's instance variables are discovered from its own methods; a prelude parameter may take its type from the program's calls** (amends 147, 183; 2026-10-19). Decision 147 made an undeclared module ivar a compile error because module methods were not dry-run for discovery. They are now (`discoverIvars` takes non-generic modules; `readsUnassigned` and `ivar` treat a module in discovery as a class: a read before any write is nil and the write that follows declares the ivar `T?`), so `# @rbs @x: T` in a module body is optional, as in a class; a module ivar only ever read still needs the annotation (`objects.txtar` `module_ivar_untyped`). With it, a prelude def can leave a parameter to decision 146 inference (the per-parameter `# @rbs` form with that parameter omitted): `Observable#add_observer(observer, fn = :update)` types `observer` as the join of what the program's calls pass (`Display | Recorder` in example 64), the `{ observer => fn }` literal types `@observer_peers`, and `notify_observers`' `observer.send(fn, *args)` is a decision 316 switch over those classes' names. Its `%x{ rbSendByName(...) }` body is gone. A prelude parameter no call types is untyped with decision 183's warning, as a user def's is, so this form belongs only where every caller is user code.
- **Why:** the 2026-10-19 research (memory `untyped-sources-2026-10-19`): one `untyped` prelude parameter put 741 dispatchers and 2,487 Dyn wrappers into a 40-line program. Typing from use is what the closed world is for (decision 146); the prelude was the one place it did not reach. Rejected: a new marker type in prelude sigs (the unannotated form already means "from use"), and keeping `untyped` with a per-call cast (the Hash's key type is the observer's).
- **Measured:** example 64 (`gen`): functions 10,693 → 3,063, `rbDyn` dispatchers 741 → 61, `rbAs` casts 1,325 → 488; TestCompileCost 64_observable 27,087 → 7,209 compiled functions, 5.8 → 1.4 s wall, 1,128 → 350 MB RSS (05_word_count and 116_cuba_web unchanged).
- **Proof:** `object_test.rb` `ModuleIvarTest#test_discovered` (an undeclared counter, an Array built on first use, a nil-until-written read), example 64 against MRI, `objects.txtar` `module_ivar_untyped` (read-only stays an error).
