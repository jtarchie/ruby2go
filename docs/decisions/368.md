# Decision 368

**Rule:** A Regexp literal's `u`, `e` or `s` flag is kept in its options (FIXEDENCODING, `fixed_encoding?`, `==`) but not shown by `inspect`; `re.match(str, pos)` sets `$~` as `re.match(str)` does.

**Sixth batch of #114** (2026-10-24). *See also decisions 171, 191, 364.*

- **Fixed-encoding flags.** rb2go's literals dropped `/u` (and EUC-JP's `/e`, Windows-31J's `/s`), so `/needle/u.fixed_encoding?` was false. `rubyRegexFlags.fixed` now appends the flag to the Regexp's opts: `options` has MRI's 16 (FIXEDENCODING), `fixed_encoding?` and `encoding` read it, `/a/u == /a/` is false as MRI's, and `inspect` and `hash` leave it out (MRI prints `/a/` and hashes them alike). Matching is unchanged: whether a pattern is fixed to UTF-8 for a binary subject (decision 352's `u8`) still comes from its source.
- **`re.match(str, pos)`** (decision 364's two-argument form) records the match for `$~` and `$1..$9` in a frame that reads them, as `genMatchSet` does for one argument.
- **Proof:** `regexp_extended_test.rb` `MatchPosLastMatchTest`.
