# Decision 280

**Go names a class generates come from one place; closed string sets are types** (#101; amends 3; 2026-10-14).
- `Class.ifaceName/ctorName/selfName/anyName/metaName/freeFunc` (plus
 `classVar`) are the only spellings of `XI`, `NewX`, `X_Self`,
 `X_Any`, `X_Meta` and `X_m`. Both the emitters and `goNames`
 (`nameGo`'s clash set) call them, so a new derived name cannot reach
 one and miss the other. Names outside `goNames` (`_Ivars`,
 `New<X>In`, `rbSend_`, `_Super_`, `rbHasIsA_`, `X_cv_name`,
 `Foo__Singleton`) are still built ad hoc: folding them in would
 change what counts as a clash.
- `valueKind` (`valueStruct`/`valueData`; `String()` keeps the
 "struct"/"data" text that appears in errors and generated inspect
 output) and `attrKind` (reader/writer/accessor) replace string
 parameters. A Struct/Data class's `valueMembers`, `valueKind` and
 `kwInit` live in `Class.value *valueSpec`.
- `nilIvars` and `ivarReadFirst` are keyed by `ivarKey{cls, name}`
 instead of `Owner.Name+"#"+name`; they are only point-queried, never
 iterated, so order cannot reach output.
- `Display`/`specChild`/`specTests` are not grouped (`Display` is also
 set for anonymous classes). `rbs.Literal.Kind` stays a string.
- No behaviour change: `gen` output is byte-identical over examples,
 testdata/run, testdata/test, every testdata/errors case and
 whole-prelude (`RB2GO_NO_PRUNE`) gen of two examples.
