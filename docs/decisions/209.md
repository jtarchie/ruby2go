# Decision 209

**Dyn wrappers stop selecting forwarders; a generic class's wrappers
are one switch; markers are class-ID switches** (#96 phases 3–4,
amends 32, 85, 87, 121). Measured on `64_observable` (every-name),
Dyn wrappers on generic types were 10.1k of its 51k compiled
functions, the forwarders their bodies selected 7.5k, and marker
stubs 2.2k.
- **One switch per generic class and batch.** Go compiles every
 method of a generic type for each instantiation, so `Array[E]`'s
 ~120 `DynX` wrappers were a shaped body plus a wrapper each, per
 element type. `emitDynName` holds a generic class's wrappers back,
 and `emitDynGen` emits each `emitDynamic` batch's as one method,
 `_DynGenN(rbDynName string, args []any) (any, bool)`: a `switch`
 over the Ruby names (private ones keyed `_name`), each wrapper body
 with `return v` rewritten to `return v, true` (`okReturns`, on the
 parsed body). The batch number keeps the method unique across
 `emitNext` rounds; a dispatcher asserts its batch's method after
 `DynX` and before the shared arms, and `false` falls through to
 `method_missing` and `NoMethodError` as a missing `DynX` did. The
 pruner parks each `case "name":` of a `rbDynName` switch until
 `rbDynName`'s dispatcher is kept (`visitSwitch`), as a wrapper
 method was kept only while selected: without that, 116_cuba_web
 went from 41k to 49.5k (a batch's late-noted names dragged in
 `Hash#to_a`'s `Array[[K, V]]` and 58 more `Array` instantiations).
 A switch left with only `default` is inlined
 (`inlineDefaultOnly`). Names Go code asserts by method (`<=>`'s
 `DynOp_cmp` in `rbCmp`, `to_json`'s `DynToJson`) keep their
 methods.
- **Wrapper bodies call the owner's free func.** Decision 121 sent a
 wrapper's call of a Kernel method to `Kernel_X[any](self, ...)`;
 now every `self.X()` a struct class's wrapper body makes
 (`plainCalls`, including the arity overloads such as `__sleep_0`)
 goes to the owner's free func: `[any]` for a universal owner,
 `[OwnerI]` for a non-generic struct class (`ownerIface`), which
 every class below it implements. Modules keep the forwarder call
 (their constraint may name `Self`), and so do class objects: a
 metaclass answers Module's and Class's methods through Go-level
 overrides (the synth `Name()`), and Go's promoted copy of a
 parent's wrapper bypasses them (`klass.name` came back empty,
 `Integer === 1` false: decision 121's failure, again). A shared arm whose body uses
 `[OwnerI](self` asserts `OwnerI` for `self`. Nothing selects the
 forwarder through an interface literal any more, so the pruner
 drops it (`64_observable`: 5,234 → 2,388 forwarders).
- **Markers.** `rbHas_RespondsX`/`_PrivateX` switch on the class ID
 for every class but `Boolean` (whose values answer TrueClass's and
 FalseClass's IDs): a marker method on each primitive was kept as a
 pruned stub wherever the assertion was.
- **Measured** (compiled functions; peak compile RSS of `main` with
 `-dwarf=false`, same machine and load): `64_observable` 50,855 →
 36,131 and 1,948 → 1,726 MB; `116_cuba_web` 40,856 → 34,782;
 archive 155 → 122 MB. Peak memory follows the count only weakly:
 the same program compiles in 2,296 MB with DWARF and 1,455 MB with
 `-l` too, so debug info and inlining move it more than the
 wrappers did.
- **Found, not done:** Go generates a wrapper for every method a
 struct gets by embedding its parent (`super_Foo_`), used or not:
 10,120 of `116_cuba_web`'s compiled functions, 8,937 of them for
 names the subclass's own interface does not declare. Replacing the
 embedding with a named field and explicit `_Ancestor()` accessors
 (prototyped) cut `64_observable` by only 1.7k and 3% RSS, and
 `116_cuba_web` then needs explicit `_ClassOf` and inherited attr
 readers; not pursued.
*See also decision 294:* an Array of the class's own bare parameter (Set#to_a) gets a wrapper.
