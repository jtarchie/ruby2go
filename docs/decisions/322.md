# Decision 322

**An annotated class-body ivar write declares the class object's ivar** (amends 99's `# @rbs self.@x: T`; 2026-10-19). `@refs = {} #: Hash[Symbol, Integer]` (rbs-inline) or `@refs = T.let({}, T::Hash[Symbol, TypeReference])` (Sorbet, Homebrew's `CacheStore`) directly in a class body was a load-time statement whose ivar only `# @rbs self.@refs: T` could type: user code got "has no known type", gem code an untyped class-object ivar and dynamic calls on everything read from it (`cache_store.rb`: 10 roots). `collectBody` now records such a write as the `self.@x` declaration (`classBodyIvar`); the statement still runs at load time as before. An unannotated write stays a plain statement.
- **Measured:** brew `info wget`: dynamic-call warnings 1,795 → 1,769 (ivar roots 66 → 50), functions 59,850 → 59,836; output equals MRI.
- **Proof:** `object_test.rb` `BodyRefsTest`; `testdata/boot` `DemoRefs` (Sorbet form).
