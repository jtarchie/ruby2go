# rugaroo design record

The goals of rugaroo and the numbered decisions that bind it, one file each in
[decisions/](decisions/) (`decisions/NNN.md`; "decision N" in code and docs means
that file). How it got its shape, with the first worked examples: [history.md](history.md).
For installing and using rugaroo, see the [README](../README.md).

I want to compile a subset of Ruby to Golang. The runtime of Golang supports
enough that I believe it to be possible.

Requirements:

- use this type syntax (https://github.com/soutaro/rbs-inline,
  https://github.com/soutaro/rbs-inline/wiki/Syntax-guide)
- we should be able to support `class`, `module`, `includes`, and inheritance

Anti-goals:

- we don't need to support eval or `define_method` **at runtime**. Class-based
  virtual dispatch on `self` **is** required — inheritance doesn't work
  without it (see [01_inheritance](../examples/01_inheritance/)).
  *Amended (#82):* a gem that builds methods at boot (`define_method`, a
  string `eval`) is evaluated by MRI **at compile time** instead (decision
  161), and the compiled binary still never runs either. Programs with no
  gem require never invoke Ruby at compile time, so the WASM playground is
  unaffected.
- *Amended:* reflective dispatch (`send`, `method_missing`, `const_get`,
  `constants`) is supported, generated from the closed world rather than
  looked up at run time: typed code never pays for it, calls on `untyped`
  values do, and the compiler warns at each one (decisions 28–33,
  [docs/dynamic-dispatch.md](dynamic-dispatch.md)).

I want to support all the native types of Ruby as Golang primitives, but with
methods. These are ideas, and not limited to or the strict implementation.

New ones take the next number. One that amends an older decision says so, and the

## Layout

```
rugaroo.go              public API: embeds the prelude + sig/gems, calls the compiler (Compile, CompileWithGems)
stubs.go              PreludeStubs: the generated prelude/go/0_stubs.go (decision 154; `rugaroo stubs`)
usercode.go           UserCode: the part of Compile's output that came from the user's file, for display
cmd/rugaroo/            CLI: rugaroo build|run|gen|test|stubs|web, like go build|run|test
                      (test.go: the minitest runner; web.go + web.html: the playground server)
cmd/rugaroo-wasm/       the compiler built for a browser (js/wasm), for the static playground (decision 102)
cmd/rubyspec/         runs ruby/spec directories under rugaroo; mock.go + mspec.rb adapt mspec (decision 127)
internal/compiler/    Ruby → Go: declarations, types, codegen. expr.go and model.go are split by topic
                      into expr_*.go / model-topic files (see the directory); compiler.go has the pipeline
internal/rbs/         the RBS type-syntax subset the compiler understands (stdlib-only leaf)
internal/boot/        gem load phase under MRI at compile time: boot_hook.rb + find_gems.rb run
                      the program's requires and report what the source does not show (decision 161)
prelude.rb            core library entry point; require_relatives the core prelude/*.rb
prelude/              core library, written in Ruby, compiled by the same transpiler; a lib file
                      (json.rb, csv.rb, net_http.rb, webrick.rb, ...) loads only on a literal
                      `require` (decision 155; the map is internal/compiler/libs.go)
prelude/go/           package-level Go helpers for the prelude, next to the .rb whose methods use
                      them; 0_stubs.go (gitignored) type-checks them (decision 154)
sig/                  vendored RBS: sig/*.rbs for libraries (decision 110), sig/gems/<gem>/ embedded
                      for gem programs (decision 160)
benchmarks/           rugaroo vs MRI workloads for scripts/benchmark
scripts/              dev tools: benchmark, census (what generated Go spends functions on),
                      rubyspec-coverage, gen-unicode-normalize, design-index, deploy-web.sh, topbanana.*
examples/NN_*/main.rb  one feature per program; runs on MRI unchanged
testdata/run/*.rb     what output itself shows (puts/print, exit, crashes, stdin): print-and-compare
testdata/test/*_test.rb  behaviour checks, one minitest file per area: MRI must pass, rugaroo must match
testdata/errors/*.txtar  compile-error and warning cases
testdata/{multi,boot,traced}/, mt_trace.rb  multi-file, gem-boot and trace-oracle fixtures
rugaroo_test.go         the integration suite (below); cost_test.go (compile cost), fuzz_test.go
docs/design.md        this file; docs/decisions/NNN.md: one decision each; docs/history.md: how it got its shape; docs/dynamic-dispatch.md: the reflection / `untyped` dispatch plan (decisions 28-33)
Gemfile               rbs, rbs-inline, and webrick (the HTTP examples' MRI server)
.golangci.yml         lint config for this repo (depguard enforces the import direction)
.golangci.generated.yml  lint config the tests apply to the generated Go
```

`go test ./...` is the oracle. It fails fast unless `ruby` ≥ 4.0, `bundle
install` has been run, and `golangci-lint` is on PATH; then for every
`examples/*/main.rb`:

1. `rbs-inline --output` succeeds and `rbs validate` passes on its output;
2. the transpiled Go passes `gofmt`, `go vet`, `go build` and
   `golangci-lint` (with `.golangci.generated.yml`);
3. its stdout and exit code equal `ruby main.rb`.

Examples that `require "net/http"` (or any library) get the matching
`rbs -r net-http` flags, so their annotations validate against the
library's signatures.

Each example covers one feature; add one whenever the transpiler grows
something the others don't exercise. There are no golden Go files: MRI's
output is the only expectation, and the generated Go is inspected with
`go run ./cmd/rugaroo gen main.rb` when needed.

`TestRun` holds `testdata/run/*.rb` to the same MRI comparison but skips the
rbs and lint gates, so each file costs one `go build`. `TestMinitest` runs
`testdata/test/*_test.rb` with `--seed 1`: MRI must pass each file (else the
test is wrong), and rugaroo's output must equal MRI's apart from timings
(decision 81). `TestErrors` compiles
each case in `testdata/errors/*.txtar` and checks the `# error: text` /
`# warning: text` lines it declares. A `# skip: reason` line marks a known
failure in either; `RUGAROO_RUN_SKIPPED=1` runs them anyway.
